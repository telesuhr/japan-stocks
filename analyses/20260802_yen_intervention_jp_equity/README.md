# 円買い介入・円高ショックの後、日本株はどうなるか

**結論: 事前登録 H1〜H3 を全て棄却。①介入は円高を持続させない（翌日88%が円安に戻し、d20の平均は −0.16%＝ほぼゼロ）。②「円高＝日本株安」は d1（−0.44%）だけの現象で、d20 は +2.27%・勝率66%（2008年除くと +3.47%、t=2.96、勝率70%）＝むしろ買い場。③輸出株が劣後するどころか d20 で内需を +2.95pt 上回る（t=2.07、輸出劣後はわずか15%）——ただしこれはベータ回復の交絡と見るのが妥当。**
**⚠️ 最大の含意は平均でなく尾部: 8件の介入のうち円高が定着したのは2件だけで、そのうち 2024-07-11 は d20 −17.91%（令和のブラックマンデー）。今回は「介入が効いてしまう」条件が過去例より揃っている。**

## 目的・背景

2026-07-30〜31、日米が**円買い協調介入**を実施したと報じられた（協調は1998-06以来28年ぶり）。
推計6兆円超、USDJPY 163.66 → NYクローズ 157.40（−3.8%）。
「協調だから効果が持続する」「円高だから日本株は下がる」という2つの通説を検算する。

## 解釈

**「円高だから輸出株を売る」は少なくとも10日以上のホライズンでは逆効果**、というのが表面的な読み。
ただし**そのまま信じるべきではない**。交絡が明確にあるため：

**円高ショックの大半はリスクオフで発生する**（2008年金融危機、2020-03 コロナ、
2024-08-01 日銀利上げ＋米雇用ショック）。リスクオフでは高ベータの輸出株（電機・機械・精密・輸送）が
内需（陸運・電気ガス・食品・銀行）より大きく叩かれ、リスクオンに戻る局面で最も大きく戻す。
**このスプレッドが拾っているのは為替感応度ではなく、ベータの往復である可能性が高い。**

→ H3 の棄却は「円高で輸出株が売られる」を否定するには十分だが、
「円高で輸出株を買え」を支持する根拠にはならない。**ベータ中立化して再検証すべき**（→BACKLOG）。

## 限界・注意点（今回への外挿における致命的な点）

1. **今回の円高は介入由来であり、リスクオフ由来ではない**。検証した35件の円高ショックの大半は
   リスクオフ発の円高で、株安と同時に起きている（だから「その後戻る」）。
   **株が売られていない状態で為替だけが動く今回は、この標本と性質が異なる**。
   d20 +3.47% をそのまま今回に当てはめるのは外挿として危うい。
2. **介入イベントは n=8、協調介入は n=1**。統計的な見通しは構築不能。表は事例集として読むべきで、
   平均値に意味を持たせてはいけない。
3. **d20 −17.91%（2024-07-11）という左裾が1件で平均を支配している**。
   平均 −2.20% / 中央値 −0.60% の乖離がそれを示す。
4. **`JPY=` の日次終値はスナップの時刻依存**。7/31 の DB 値は 160.36 だが NY クローズは 157.40 で、
   日中の介入の全体像を捉えきれていない。介入日のリターンは過小評価されうる。
5. H3 は**ベータ中立化・サイズ中立化を行っていない**（上記の交絡）。
6. 介入日リストは財務省公表＋報道ベースで、**覆面介入の日付特定に誤差**が含まれうる。

## 今回（2026-08）への含意

過去例に照らすと、**「介入が効いてしまう」条件が揃っている**点に注意が要る：

- 円高が定着した2例（2022-10、2024-07）はいずれも**金融政策の転換期待と重なった**とき。
- 今回は**植田総裁が9月利上げを「排除せず」＋FRB側も利上げ示唆**＝同じ配置。
- さらに**協調介入**（単独より当局の本気度が高いというシグナル）。

その2例の株式リターンは **+3.64% と −17.91%** に割れており、**n=2 では方向を決められない**。
決定的な違いは「円キャリーの積み上がり具合」で、2024-07 は巻き戻す玉が大量にあった。
→ **見るべきは日経の値動きではなく、キャリー巻き戻しの兆候**（後述）。
