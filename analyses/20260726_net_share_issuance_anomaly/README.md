# 自社株数減少（net share issuance, NSI）アノマリー検証 (BACKLOG #25)

## 目的・仮説（教訓5: 検証前に宣言）
外部文献 Pontiff-Woodgate (2008) / Japan pre-registered study (Pac-Basin Finance J. 2025) の
**net share issuance アノマリー**を日本株で検証する。バイバック・レジーム（2024年自社株買い9兆円→
2025年+50%）が構造的追い風になっている前提。

- **H1**: 分割調整後のネット発行済株数（`ShOutFY − TrShFY`）が YoY で**減少**した銘柄
  （＝自社株買い・消却を実行）は翌1年アウトパフォームする（Long）。
- **H2**: **増加**した銘柄（＝公募増資・希薄化）はアンダーパフォームする（Short）。
- **棄却条件**: L/S net Sharpe < 0.8、または IS/OOS 符号反転、またはサイズ中立化で消滅。

会計系（accruals #23・バリュー #22）と低相関の分散寄与を期待（事前確率: 中）。

## データ
- `fin_summary`（FY本決算, 2016-2026, 連結JP/IFRS/US + 単体JP）payload の `ShOutFY`（期末発行済株数・
  自己株含む）・`TrShFY`（期末自己株数）。ネット株数 = ShOutFY − TrShFY。
- `stocks_daily`（2016〜, adj_close リターン・turnover_value 流動性・`close/adj_close` 比で分割検出）。
- YoY NSI 観測: **31,658件**（分割調整・±60%クリップ後）。年3,600〜3,800件。

## 手法
- **分割調整（必須）**: 生の株数YoY変化は株式分割（中立）と真の発行/消却を混同（生標本の95%点+40%・
  max 114倍は分割）。区間内分割係数 = ρ(前期末)/ρ(当期末)（ρ=close/adj_close）で前期株数を当期ベースに
  揃え、`nsi = net_cur / (net_prev × split) − 1`。調整後は中央値0・5%点−3.5%・95%点+5.8%と正常化。
- **年次L/Sポートフォリオ**: 毎年7/1に、過去400日以内に開示された最新FYでNSIを算出、ADV(60日)≥5億の
  流動性ユニバースをクインタイル分割。**Q1(株数減少)Long − Q5(増加)Short** 等加重、1年保有→翌7/1リバランス。
  Formation 2018〜2025（各年 N≈610〜720）。
- **コスト**（教訓2）: L/S往復8bpsを各リバランスで1回控除（年次＝低回転でコスト影響は僅少）。
- **サイズ中立版**（教訓3）: log時価総額でNSIを回帰した残差でクインタイル化。
- **IS/OOS**: IS〜2021 / OOS 2022〜。
- **年率化**（教訓2）: 連続保有バスケットの実日次リターン系列でSharpe（オーバーラップ増幅なし）。

## 所見・結論 → ✗ 単独戦略は採用見送り（弱アノマリー確定・サイズ交絡）

1. **方向は仮説どおり**: 希薄化銘柄(Q5 +3.4%)は株数減少銘柄(Q1 +11%)を明確にアンダーパフォーム。
   NSIアノマリーの符号は日本でも生きている（H1/H2の向きは正しい）。
2. **だが取引可能L/Sとしては弱すぎる**: 生NSIでも net Sharpe **0.50**（t=1.40, 有意でない）、
   昇格基準2.0に遠い。単調でない（Q4が最大）。
3. **効果の大半はサイズ・プレミアムの化身**: サイズ中立化で Sharpe **0.28** に半減し、**IS期は−0.09と
   符号反転**。純粋な発行ミスプライシングαではなく、小型株バイアスが主因。
   → **バリュー(#22)・accruals(#23)と完全に同型**。米国の会計・発行アノマリーは日本へ弱くしか移植せず、
   残るのはサイズ、という教訓の3例目。
4. **上昇は2022年以降に集中**（図右）＝直近レジーム限定の可能性。OOS>ISは頑健性でなく recency。
5. **分散寄与での救済も不成立**: 単独Sh0.28（サイズ中立・IS≈0）の sleeve は、既存バスケットと無相関でも
   寄与が小さい。#22（バリューSh0.56・ρ−0.13で合成改善なし）と同じ理由で、相関の深掘り以前に採用水準外。

**使い道（知見として残す）**: 「希薄化（増資）銘柄は明確に弱い」は事実 → **銘柄選択の除外スクリーン**
（増資・希薄化銘柄を買い候補から外す）として有効。自社株買い実行(Q1)は割安バリュー(#22 PBR<1×高ROE)や
決算イベント系と重ねる質フィルタ候補。単独のL/S戦略としては却下。

## 限界・注意点
- 分割検出は close/adj_close 比ベース。稀に併合(逆分割)や無償割当で誤差が残りうる（±60%クリップで緩和）。
- ネット株数は「自己株除き」だが、金庫株の消却 vs 保有の区別まではしていない（実行済み消却なら
  ShOutFY自体が減る＝より強いシグナルの可能性 → 未検証）。
- Formation は年1回7/1固定。FY末が3月以外の銘柄は開示ラグが不均一（400日窓で吸収）。
