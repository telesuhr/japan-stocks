**期間**: 2016-05-10 〜 2026-05-22 (**10年, 2,452営業日**)

## 目的

ロングショート (前回) と寄付ギャップフェード (前々回) は10年検証で却下となった。
ユーザー提案の **「RSI / MACD などテクニカル指標を使ったシステムトレード」** が長期で機能するか検証する。前回の教訓 (短期Sharpeに騙されない) を踏まえ、**最初から10年で評価**する。

## 3. 解釈・示唆

### 3.1 なぜMA25/75 が機能するか
1. **日本株はトレンドが持続する** — Buy&Holdですら平均Sharpe +0.51。市場全体が上昇バイアス
2. **MA cross は「方向性検出」として優秀** — 25/75 程度の中期MAは「ノイズ除去」と「タイミング検出」のバランスが良い
3. **取引頻度が低い (年5-10回, 保有約100日)** — 取引コストが累積しない
4. **DC で確実に降りる** — トレンドが切れたら撤退するため、深いDDを回避できる

### 3.2 戦略の弱点
- **レンジ相場で連敗** (2019-2023年)
- **DD -44%** はBHの-150%より浅いが、年単位で含み損を抱える期間が長い
- **MA cross の遅行性** — トレンド転換時に出遅れる

### 3.3 BHとの比較
| 指標 | Top3 MA戦略 | BH 7銘柄平均 |
|---|---:|---:|
| 累積 | +284.6% | +330% |
| Sharpe | **+3.49** | +0.77 |
| MaxDD | **-44.3%** | -150%以上 |

→ **絶対リターンはBHに僅か劣るが、リスク調整後リターン (Sharpe) は4.5倍**。MA戦略の真価はDDの浅さにある

## 4. 限界・注意点

- **N=46 取引 (Top3 10年)** は少ない。Sharpe推定の標準誤差大きい (SE ≈ 0.5程度)
- **生存バイアス**: 7銘柄はすべて2016-2026で生き残った企業。倒産銘柄は対象外
- **シグナル発生は前日終値ベース**, 約定は翌日寄付Open。約定スリッページは8bpsに含まれている前提
- **MA cross は遅行指標** — 急変動相場では大きな含み損
- **配当再投資未考慮** — 累積リターンは値動きのみ (実際の総合リターンはより高い)
- **2019-2023 のレンジ相場は5年連続マイナス気味** — 心理的に耐えられるか要検討

## 5. 結論

✅ **MA25/75 ゴールデンクロス順張り戦略は 10年検証で生き残った本物のエッジ**

## 6. 次のアクション候補

優先度高:
1. **ユニバース拡張** — 非鉄7銘柄以外でも機能するか検証 (半導体・銀行・小売)
2. **トレンドフィルタ** — TOPIX/日経の長期トレンドに沿った時のみエントリで、レンジ相場を回避できるか
3. **複数MA組合せ** — 25/75 + 50/200 の二重シグナルでセレクティビティ向上
4. **RSI<30 反発ロングとの組合せ** — 別ロジックなので相関低い → ポートフォリオ多様化

優先度中:
5. **配当再投資込み** で adj_close ベースの再評価
6. **ボラ調整 (ATR)** — 各銘柄のATRに応じてポジションサイズを調整
7. **ETF/インデックスでの再現性** — 個別銘柄リスクを除いてもアルファが残るか
