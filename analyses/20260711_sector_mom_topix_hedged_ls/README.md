# セクターMOM等加重 + TOPIX ヘッジ L/S

## 目的・仮説

前回サイクル（20260706_sector_rotation_promotion）で確認した事実:
- 17業種 等加重 ADV≥10億 セクターMOM L3K1 → TOPIX超過 Sharpe +2.07 (t=6.50、IS 3.03 / OOS 1.51)
- **問題**: Long-only絶対リターンは Sharpe +1.51 だが最大DD -23.1%（2020-03、フルベータ）

**仮説**: このシグナルを「等加重セクターバスケット LONG + TOPIX等額 SHORT」のL/S構造にすると、
ダウンサイドリスクが大幅低減され、リスク調整後リターンが改善する。

具体的にテストすること:
1. L/S 構造の絶対Sharpe・MDD が Long-only を上回るか
2. ヘッジコスト（TOPIX ETF借入 ≈ 1%/年 = 8.3bps/月）を加味しても超過αは残るか
3. 既存バスケット（PED/PEAD/レーザー/銀行）との月次相関（低相関なら分散寄与あり）
4. IS（〜2021-06）/ OOS（2021-07〜）で一貫しているか

## データ

- `stocks_daily`: adj_close, turnover_value（2016-01〜2026-07）
- `symbol_master`: sector17_nm（業種分類）
- `index_daily` code='0000': TOPIXリターン（ヘッジ対象）
- 前回分析の月次リターン系列: `../20260706_sector_rotation_promotion/strategy_monthly_excess.csv`
- 既存バスケット日次収益: `../20260531_portfolio_daily_sharpe/sleeve_daily_returns.csv`（相関計測用）

## 手法

1. 毎月末の前月リターンで17業種をランク付け（等加重・ADV≥10億フィルタ）
2. 上位3業種の翌月リターンを LONG（等加重）
3. 同額の TOPIX を SHORT（ヘッジ）
4. コスト:
   - LONG側: 片側10bps × 月次入替率（前回と同一）
   - SHORT側: TOPIX ETF借入コスト 8.3bps/月（年率1%仮定）
5. 月次非重複リターン系列、√12年率化
6. IS（2016-07〜2021-06）/ OOS（2021-07〜2026-06）分割

## 結果（主要指標）

コスト: Long 片側10bps/月入替 + Short TOPIX 10bps/月(年率1.2%相当)

| 指標 | Long-only(前回) | L/S net(今回) |
|---|---|---|
| Sharpe (IS) | +1.19 | **+1.38** |
| Sharpe (OOS) | +1.86 | **+1.35** |
| Sharpe 全期間 | +1.51 | **+1.37** |
| 最大DD | -23.1% | **-7.5%** |
| 弱気レジームSh | -0.82 | **+0.04** |
| TOPIX下落月平均 | -2.20% | **+0.97%** |
| 既存バスケット平均相関 | - | **+0.09** |

**下落耐性が劇的に改善**: TOPIX下落月 (n=39) でも avg +0.97%, Sh=+1.35
**弱気レジーム** (TOPIX 12M-、n=25ヶ月): Long -0.82 → L/S +0.04（ほぼニュートラル）
**MDD**: -23.1% → -7.5% に3分の1以下
**既存バスケットとの相関**: lasertec +0.33, bank +0.15, eneos -0.06, vwap -0.06 → 平均 +0.09（ほぼ無相関）

## 所見・次アクション

**採用判断: ⭐⭐ 候補（バスケット補完枠）— 昇格基準(Sh≥2.0)未達だが分散価値あり**

- 単独 Sharpe (1.37) は採用基準 2.0 未達 → 単独採用は見送り
- しかし既存バスケットへの低相関(+0.09)で**組み合わせ分散効果が大**
- MDD-7.5%・弱気レジーム安定は既存戦略(PED/PEAD=イベント集中)の補完に有効
- IS/OOS 一貫(IS+1.38 / OOS+1.35) → 過学習の懸念低

**実装課題**:
- 月次リバランスで数十銘柄のLong + TOPIX ETF(1306等)空売り → 個人には重い
- セクターETF(1615等)でバスケット近似できればシンプル化可能

**次のアクション**:
1. バスケット組み込み時の全体Sharpe計算（相関+0.09の分散効果を定量化）
2. セクターETF近似の可能性検証（ETFの実際の超過リターンと等加重バスケットの乖離）
3. 採用はユーザー判断待ち — 現況バスケットが6戦略で分散済みのため優先度は低
