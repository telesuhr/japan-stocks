# FOMC前日の日本株傾向

## 目的・仮説

FOMCの政策決定（米国東部時間14:00 ≒ JST翌3:00）が出る**前日**に、日本株は特徴的な動きをするか？

**仮説1**: FOMC前日は不確実性ヘッジでポジション整理→日本株が小さく動く（σ縮小）  
**仮説2**: 利上げ停止・利下げ期待が高い局面では「据え置き織り込み買い」でFOMC前日に上昇  
**仮説3**: 発表はJST翌早朝なので日本市場は前日に先取りする（ドル円→TOPIX経路）

## データ

- **日本株指数**: `index_daily`（TOPIX: `0000`・日経225: `N225`）
- **FOMC日程**: 手動管理（FRB公式スケジュール 2020〜2026）
- **期間**: 2020-01-01 〜 2026-06-12（コロナ・ゼロ金利・利上げ・停止・利下げ各局面）
- **サンプル数**: FOMC前日 46件、通常日 1481件

## 手法

1. FOMC発表日リストから前営業日（日本株カレンダーベース）を算出
2. TOPIX・日経225の日次リターンをFOMC前日 vs 全非FOMC日で比較
3. Welchのt検定・Cohen's d
4. 局面別（ゼロ金利/利上げ/据え置き/利下げ）の分解
5. FOMC前日の翌日（発表当日JST）との連続性も確認

## 所見・次アクション

**主要結論**: 「FOMC前日だから日本株が動く」という単純アノマリは **2020〜2026では存在しない**（p>0.7）。

- **仮説1（σ縮小）**: FOMC前日のσは若干小さい（TOPIX 1.09% vs 通常1.45%）傾向はあるが統計検定は未実施
- **仮説2（前日買い）**: レジーム依存で「利下げ局面のFOMC前日はプラス傾向」の気配があるが、n=9程度で非有意
- **仮説3（先取り）**: 前日↑→当日+0.29% vs 前日↓→当日-0.07%という連動示唆はあるが非有意

**エッジがあるとすれば**: ドル円とセットで条件付けした分析（例「FOMC前日かつドル高方向」）や、利下げ局面限定の検証が次の方向。

**限界**: サンプル46件は少なく（特に局面別はさらに小さい）、有意差が出ても過学習リスクが高い。緊急利下げ（2020-03-03/15）を含むバイアスにも注意。
