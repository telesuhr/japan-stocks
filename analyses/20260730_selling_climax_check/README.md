# selling_climax_check — 2026-07-29の出来高急増はセリクラだったか

## 目的・仮説
「出来高推移を見たら昨日(7/29)がセリクラ(selling climax)だった説」を検証。
仮説: **出来高スパイク単独ではセリクラと判定できない**。中身（ブレッドス/新高安/VIX/反転）で識別する。

## データ・手法
- テーブル: `stocks_daily`（全上場・売買代金/値下がり比率/20日新高安/出来高比）＋ `macro.daily_ohlcv`（VIX先物 `VXc1`・`SOX`）
- 期間: 2026-07-13〜07-30（確定は7/29まで。7/30は当日集計途中の可能性）
- セリクラ・スコアカード5条件で判定＋半導体11銘柄の個別チェック（`code4`: 8035/6920/6323/6758/6857/4062/6723/6963/4005/6976/7735）

## 結果（主要指標）

### ✗ 広い市場: セリクラではない（＝rotation climax）

| セリクラの条件 | 7/29の実際 | 判定 |
|---|---|---|
| 出来高急増 | **売買代金13.8兆円（今週最大）・vol 1.44x** | ✓ ここだけ合致 |

- **出来高13.8兆の正体は投げ売りでなく「ローテーションの大商い」**。新高値831本＝バリュー/金融側に
  資金がドカンと入った量。growth→valueの資金移動が最大化した日 = **rotation climax**。
- セリクラは「VIX30＋出来高2-3倍＋9割投げ→急反発」が同時に来る日。今回は**出来高以外どれも不成立**。

  一日で投げ切る climax ではなく、**進行中の高出来高の分散売り(distribution)**。枯渇していない。

## 所見・示唆
- **「昨日セリクラ→反発期待でキープ」はデータ的に支持されない**。半導体の崩れは枯渇しておらず継続中。
  しかも直後(7/30引け後)に東エレク決算＝次の分岐。→ 「確信の無い半導体系を先に落とす」判断を補強。
- **本物のセリクラの型**（次回のために）: ①売買代金の急増だけでは不十分 ②値下がり85-95%
  ③新安値が数千・新高値を圧倒 ④VIX 30+ ⑤投げ後の急反転、が**同時**に必要。
- **rotation climax の識別**: 出来高急増＋新高値と新安値が"両方"急増＝資金が一方から他方へ激しく
  移動する転換点。今回は growth→value（[20260729_value_rotation_laggards](../20260729_value_rotation_laggards/)と整合）。
