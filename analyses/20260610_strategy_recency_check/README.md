# 採用戦略の足元エッジ確認 (2026-06-10 再実行)

## 目的・仮説

[20260531_strategy_recency_check](../20260531_strategy_recency_check/) の再実行（データ+10日、最新〜2026-06-09）。
採用6戦略が足元でエッジを保っているかを 90/180/365日の複数窓で確認する。

前回からの改善: 前回判明した「一律往復20bpsコストがイントラ戦略でCRITICALアーティファクトを
生む」問題を踏まえ、**最初から gross と複数コスト（イントラ戦略は 4/10/20bps）で評価**する。

判定の一次情報は **絶対Sharpe・符号・t統計量**（IS比は年率化方式ミスマッチがあるため割引く —
[20260531_strategy_sharpe_audit](../20260531_strategy_sharpe_audit/) 参照）。

## データ・手法

- `Dashboard_CC/strategy_oos_monitor.py` の oos_* 関数を再利用（`sharpe_from_trades` をフックして
  生トレード系列を捕捉 → 複数コストで再計算）
- 年率化 = per-trade Sharpe × √(245/hold_days)
- 窓: 直近90 / 180 / 365日

## 所見

1. **6戦略中5戦略は足元で明確にエッジ生存**。特に pre_earnings_drift は90日窓で
   Sharpe 2.10 (t=8.2) と前回チェック(5/31: 1.63)から**加速**。
2. **bank_absorption は弱体化トレンドから回復**。前回180日0.83→今回1.14、90日は1.76・勝率67%。
   「要監視」は維持するが停止の必要なし。
3. **eneos_vwap_trend だけが実質死亡圏**。シグナル自体は反転していない（gross正）が、
   直近90日 gross +9.3bps/trade は薄く、現実的コスト10bpsで Sharpe -0.09。
   365日では gross Sh3.02 と見えるのは過去の貯金。**直近ほど悪い単調劣化パターン**であり、
   前回の「最低確信度・要コスト実測」から一段階格下げが妥当。
4. vwap_morning_meanrevert は n が薄い(90日17回)ものの全窓・全コストで Sharpe 3〜6。健在。

## 限界・注意点

- earnings_pead の90日 (Sh1.04, t1.6) は単体では有意でない。n=119と十分なので
  「弱い四半期」の可能性があり、次回チェックで180日が1.5を割るなら警戒。
- lasertec は90日n=3で判定不能（仕様上の低頻度）。
- IS比での判定は年率化方式ミスマッチのため使わない（絶対Sharpe・t・符号で判定）。
