# 大口空売り残高開示ドリフト（Short Interest Disclosure Drift）

## 目的・仮説（検証前に宣言 — 教訓5）

金商法に基づく大口空売り残高報告（発行済株式の≥0.5%、報告者名付き、取引日の**2営業日後**に
JPX公表）を使い、個別銘柄の総空売り残高（全報告者合算）から将来リターンを予測できるか。

**対立する2つの仮説:**

| ID | 仮説 | 予想 | 理論的根拠 |
|----|------|------|-----------|
| H1 | **情報優位ショート説（level）** | 総空売り残高が高い銘柄は将来アンダーパフォーム → SHORT高SI/LONG低SI | 機関の空売りは情報優位（Boehmer-Jones-Zhang 2008）。0.5%超を開示する大口=Goldman/MS等 |
| H2 | **踏み上げ説（change）** | 空売り残高が急増した銘柄は買い戻し圧力で将来リバウンド → LONG急増SI | 空売りは必ず買い戻す=将来の買い需要。急増直後は踏み上げリスク |
| H3 | **イベント study** | 大口ショート新規/急増の開示"後"に有意なドリフトがあるか（d1/d5/d20） | 公表2営業日ラグで先読み回避、開示翌日寄成エントリー可能 |

**棄却条件:** L/S コスト後 OOS Sharpe < 0.3、または IS/OOS で符号反転（過学習）

## データ

| テーブル | 内容 |
|----------|------|
| `public.jquants_short_sale_report` | 大口空売り残高開示（94万行, 2021-01〜2026-07, 3762銘柄）。`(disc_date, code, ss_name)` / `shrt_pos_to_so`=対発行済比率 / `calc_date`=残高基準日 / `prev_rpt_ratio`=前回比 |
| `public.stocks_daily` | 調整後OHLCV（リターン計算・ADVフィルタ） |
| `public.symbol_master` | 業種17分類（セクター中立化） |

- 期間: 2021-01〜2026-06 / IS: 〜2023-06 / OOS: 2023-07〜
- ユニバース: ADV≥5億円

## 手法

- **総空売り残高再構成**: 各(code, 報告者)の最新 `shrt_pos_to_so` を calc_date≤T で前方補完し銘柄別合算
- **公表ラグ厳守**: `disc_date`（公表日）到達後の情報のみ使用 → 翌営業日寄成エントリー（先読み禁止・教訓1）
- **L/S**: 月次クロスセクション、上位/下位20%、コスト8bps/月控除（教訓2）
- **セクター/ベータ中立チェック**（教訓3）、IS/OOS分割（教訓4）、生スプレッド検算（教訓5）

## 所見・次アクション

**結論: 主要仮説（情報優位ショート）は棄却。踏み上げ方向に弱いエッジありだが採用基準未達。**

1. **情報優位ショート説は日本では不成立** — 大口空売り残高（≥0.5%開示）が高い/増えた銘柄を
   ショートしても勝てない（むしろ H2 は t=-2.6 で逆効果）。米国の Boehmer-Jones-Zhang とは逆。
   日本では踏み上げ（買い戻し圧力）が優勢。
2. **踏み上げ（急増SI→Long）は本物だが弱い** — 価格モメンタムと直交した独立シグナルで
   IS+1.18/OOS+0.69・低バスケット相関+0.17。ただしセクター中立でOOS 0.26に減衰、t≈1.7-2.0で
   統計的に境界。**単独採用不可**（昇格基準 Sh≥2.0 に遠く及ばず）。
3. **次アクション**:
   - H2b を「決算・カタリスト」条件で層別すれば踏み上げが集中するか（H-D派生: 決算×高SI）
   - 踏み上げの右裾を積極的に取る設計（等加重でなく高SI×低流動性に集中）は別途検証の価値
   - 弱候補として BACKLOG に残す（バスケット補完の可能性は低相関ゆえゼロではない）
