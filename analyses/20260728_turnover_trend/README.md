# turnover_trend — 日本株 売買代金の推移（2023〜2026）

## 目的・仮説
「最近、日本株の売買代金が随分増えた」体感を数字で確認する。
仮説: 2026年に入って売買代金が構造的に増加している（レンジ上抜け）。

## データ
- テーブル: `public.stocks_daily`（全上場銘柄・JQuants確定）
- 期間: 2023-01 〜 2026-07（2026-07は18営業日時点の月途中）
- 定義: **売買代金 = Σ(close × volume)** を全銘柄・日次で合計 → 月次で「1営業日あたり平均」に集約（単位: 兆円）

## 手法
- 月ごとに `SUM(close*volume)` と営業日数を集計し、`1日平均 = 月合計 / 営業日数`。
- 12ヶ月移動平均を重ねてトレンドを可視化（`result.png`）。
- ※バックテストではないためコスト・Sharpe等は非該当（市場環境の記述統計）。

## 所見・示唆
- **仮説は支持**。2023〜2025は 3〜6兆円のレンジだったのが、**2026年に 10〜13兆円へと倍以上にジャンプ**。年平均で2025比 +75%。
- **加速の起点は2026-02**（9兆円台）、**5〜6月に一段ジャンプ**（11〜13兆円）。12ヶ月移動平均も2026年に入って明確に上向き傾斜へ変化。
- **7月の下落局面でも11兆円と高止まり** → 薄商いの下げではなく、**出来高を伴った活況の中の調整**。同時期のセリクラ検証（VIX<19・投げ売りなし）とも整合し、「投げ売り一巡」ではなく**セクターローテーション**という解釈を補強する。

## 限界・注意点
- **母集団**: `stocks_daily` 全上場銘柄の合計。東証プライム公表の売買代金（ヘッドライン値）より母集団が広く、**水準は高めに出る**。推移・倍率のトレンドは正確だが、絶対額を東証公表値と直接比較しない。
- 2026-07は月途中（18営業日）集計。
- 記述統計であり売買シグナルではない（レジーム判定の補助材料）。
