# 米国下落→翌日日本反発→その翌日の日本株傾向

## 目的・仮説

「米国が下落した翌日に日本株が反発する」というのはよく観察されるパターン。
その**さらに翌日（D+2）**の日本株（TOPIX）に傾向はあるか？

**仮説A（リバウンド継続）**: 米国の下落が一時的なら日本の反発は2日続く  
**仮説B（行き過ぎ修正）**: 反発が過剰だった場合、翌日は反落する（mean reversion）  
**仮説C（中立）**: 一度日本がUSショックを消化したら翌日は通常の相場に戻る

## データ

- **米国市場**: `macro.daily_ohlcv` symbol=`ESc1`（E-mini S&P500先物）
- **日本市場**: `index_daily` code=`0000`（TOPIX）・`N225`（日経225）
- **期間**: 2016-05-10〜2026-06-12（約10年、2466営業日）
- **アラインメント**: 各日本営業日 D_jp1 に対し直前の米国営業日 D_us を特定

## 手法

1. シグナル条件: ESc1リターン(D_us) < 閾値 かつ TOPIX リターン(D_jp1) > 0
2. D_jp2（D_jp1の翌営業日）のTOPIXリターンを集計
3. vs ベンチマーク（非シグナル日のD+1リターン）でWelch's t検定
4. 閾値別（any / <-0.5% / <-1% / <-2%）・米国下落幅別ビン分析

## 所見・次アクション

**主要結論**:「米国↓→翌日日本↑→その翌日」には**有意なエッジなし**（大半は p>0.5）。

ただし**米国が-2%超の大幅下落**に限ると、D+2は+1.29%・勝率69%・p=0.093と弱い傾向が出る。

- **仮説A（継続）が部分的に支持されるのは大幅下落時のみ**: -2%超の急落は1日では消化しきれず、翌々日まで自律反発が続く可能性
- **軽微な下落（-1%未満）はD+2にわずかなマイナス**: 小さな反発は行き過ぎ修正気味かもしれない
- **n=13は小さすぎる**: -2%超のサンプルが2016〜2026年で13件しかなく、COVID急落等のイベントドリブンな外れ値を含む可能性が高い

**取引可能性**: p=0.093はIS水準でも閾値に達しておらず、コスト（往復10bp）を考えると単独では取引不可。大幅急落後のリバウンド延長として「方向感の参考」程度に留める。

**次アクション候補**:
- 大幅急落イベント（VIX急騰と組み合わせ）での深掘り
- D+2だけでなく D+3, D+5 まで追うウィンドウ拡張
- セクター別（輸出株 vs 内需）での差を見る
