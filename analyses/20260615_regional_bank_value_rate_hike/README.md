# regional_bank_value_rate_hike — 利上げ局面の「出遅れ地銀(低PBR)」はワークするか

## 仮説（教訓5: 仮説先行）
日銀の利上げ（マイナス金利解除 2024-03〜）で銀行は利ざや改善→再評価。地銀は解散価値割れ(PBR<1)が多く、
出遅れた低PBR地銀ほど後から本源価値へキャッチアップする＝利上げレジームで地銀バリュー効果が出るはず。
ただし低PBRは万年割安(バリュートラップ)の恐れもあるので、地銀の中で低PBR vs 高PBRの前向きリターン差で検証。

## データ・手法
- ユニバース: 銀行業(sector33)から メガ(Core30) / 大型(Large70=ゆうちょ・りそな・トラスト) / 日銀 を除外 = **地銀73行**。
- 月末リバランス。**PBR = 月末調整後終値 / 直近開示BPS(disc_date≤月末, point-in-time)**。先読み無し（教訓1）。
- 流動性: 直近20日平均売買代金 ≥ 0.3億（地銀は薄いので緩め）。PBR3分位で割安Q1/中位/割高Q3。
- ベンチ: 地銀等加重(セクター内中立) と TOPIX。コスト: long-only 月次入替 往復20bp控除（教訓2）。
- レジーム: pre(〜2024-02)/hike(2024-03〜)。hike内 IS(〜2025-06)/OOS(2025-07〜)。
- 補助: 価格出遅れ(6カ月リターン下位)版、低PBR×ROE(質)版も比較。

## 結果（コスト後・年率/SR）

| 戦略 | 全期間 | 利上げ後 | IS | OOS |
|---|---|---|---|---|
| **低PBR×ROE(割安×質)** | 33.5%/SR1.6 | **42.8%/SR1.8** | 19.9%/SR1.0 | **76.1%/SR3.0** |
| 割安Q1(低PBR) | 33.0%/SR1.6 | 41.1%/SR1.7 | 20.7%/SR1.0 | 70.9%/SR2.8 |
| 地銀EW(ただ全地銀を買う) | 29.7%/SR1.5 | 36.4%/SR1.6 | 16.2%/SR0.8 | 65.9%/SR2.6 |
| 割高Q3(高PBR) | 26.0%/SR1.4 | 28.7%/SR1.4 | 13.1%/SR0.8 | 51.6%/SR2.1 |
| 価格出遅れ(6M下位) | 27.1%/SR1.5 | 28.6%/SR1.5 | 14.3%/SR0.8 | 49.4%/SR2.3 |

**割安Q1 − 割高Q3 スプレッド(地銀内の純バリュー効果)**: 利上げ後 +12.4%/年 SR1.72(勝率70%)、IS +7.6%(SR1.0)・OOS +19.3%(SR2.8)＝**IS/OOS両方プラス**。

**文脈(セクターβ)**: 地銀EW vs TOPIX の月次超過は 利上げ前+0.47% → **利上げ後+1.89%**。地銀そのものが利上げで対TOPIXを大きくアウトパフォーム。

## 結論
1. **ワークする。ただし精度が要る**: 効くのは「**低PBR(バリュー出遅れ)**」であって「**価格出遅れ(6カ月で上がってない)**」ではない。価格出遅れは地銀EWに負ける（上がってない銘柄は理由があって上がらない）。**"出遅れ"を株価でなくPBRで定義すること**がキモ。
2. **最大の駆動力はセクターβ**: ただ地銀を等加重で持つだけで利上げ後+36%/年。バリュー傾斜(低PBR)はそこに+5%/年、ROE(質)の上乗せでさらに+1〜2%/年。**「地銀を持つ」が8割、「割安×質を選ぶ」が2割**。
3. **質オーバーレイが効く＝バリュートラップ回避**: 低PBR×高ROEが単純低PBRを上回る(利上げ後42.8% vs 41.1%、OOS 76% vs 71%)。低PBRでもROEマイナスの銘柄(例: 東和銀行 ROE-27%)は除外すべき。
4. **割安Q1−割高Q3がIS/OOS両方プラス**＝地銀内のバリュー効果は単なる相場でなく持続的。

## 限界・注意（重要）
- **巨大な銀行ブル相場の一回性**: 利上げ後の地銀+36%/年はマイナス金利解除という構造的再評価の産物で、再現性は限定的。絶対リターンは割り引くこと。検証できるのは「割安が割高に勝つ」相対関係(これはIS/OOS頑健)。
- サンプル短い(利上げ後27カ月・OOS11カ月)・単一レジーム・地銀の合併消滅によるサバイバーシップ未補正。
- 最割安帯は超薄商い小型(鳥取0.5億/高知0.4億/トマト0.3億)＝執行困難。**取引可能性で絞る必要**。
- 利上げが一服/逆回転すれば優位は剥落。BOJ会合(6/15-16)前後は「噂で買い事実で売り」に注意。
