# ORB戦略 包括検証

**実施日**: 2026-07-04  
**スクリプト**: `run.py`  
**出力**: `phase1_scan.csv`, `phase2_grid.csv`, `result.png`

## 目的・仮説

オープンレンジブレイクアウト（ORB）が日本株で有効かを包括的に検証する。

- 仮説: 寄り付き後の短期レンジをブレイクアウトした方向に順張りするとエッジがある
- 観察時間・エントリー窓・TP/SL・方向によってパフォーマンスが変わるためパラメータグリッド探索で最適解を把握
- IS(学習期間)で過学習していないかをOOS(評価期間)で確認

## データ概要

| 項目 | 内容 |
|---|---|
| 対象銘柄 | 東証プライム 日次売買代金上位30銘柄 (平均≥10億, 200日以上) |
| IS期間 | 2024-06-01 〜 2025-06-30（約13ヶ月）|
| OOS期間 | 2025-07-01 〜 2026-07-03（約12ヶ月）|
| コスト | 片道4bps（往復8bps）|
| データソース | JQuants 1分足 (stocks_intraday) |

## 手法

```
レンジ = 9:00〜9:XX の最高値/最安値
エントリー = レンジをブレイクした方向に成行 (9:XX〜entry_end_h:00 の間)
決済 = TP (利食い) / SL (損切り) / 強制 (15:00)
```

## 解釈・示唆

### なぜSL 0.5%が効くか

ORBのエッジは「ブレイクアウト直後の勢い」にある。エントリー後に0.5%以上押し返されたらそのブレイクは失敗（フェイクアウト）と判断して即撤退するのが合理的。SL 1.5%まで引っ張ると損失が大きく勝率が必要以上に下がる。

### エントリー窓は11時まで

9:20以降でブレイクがなければ9:20のレンジを超えるほどの方向性が出ていないと判断し待つ。9時台のボラの高い時間帯にエントリー窓を広く保つことで発動回数と品質のバランスを取る。

### 5m vs 20m レンジ

- **5分レンジ**: 発動頻度が高く安定 (Sh>0率94%)。勢いを早めに定義
- **20分レンジ**: ピーク高いが銘柄依存大（79%）。寄り付き後の完成した値動きを使う

### Short方向のエッジ

20m/11h/SL0.5%/Shortがベストコンボ (OOS Sh 1.04)。20分かけて形成した高値ゾーンをブレイクアップした後に失速して戻す動き（寄り付きのギャップアップ組の利確）を捉えているとみられる。

## 推奨パラメータ

### 安定運用向け (ロング中心)
```
range_end_m=5, entry_end_h=11, profit_pct=0.02, stop_pct=0.005, direction=long
→ OOS Sh >0率: 94%, 平均Sh ~0.35+
```

### アグレッシブ (ショート混在)
```
range_end_m=20, entry_end_h=11, profit_pct=0.02, stop_pct=0.005, direction=short
→ OOS Sh 最大 1.04, ただし銘柄選択が重要
```

### 絶対条件
- **SL は 0.5% に固定** (これだけで全組合Sh>0率100%)
- **エントリー窓は11時まで** (10時切りは-4割の劣化)

## 実運用可能性の評価

### 肯定要素
- OOS平均Sh 0.3〜0.5 はコスト（4bps）込みで安定してプラス
- SL 0.5%固定でSh>0率100% — パラメータリスクが低い
- 1日1回、シンプルなルール

### 懸念点
- 単銘柄Sh ~0.5〜1.0 では standalone では弱い（pre_earnings_drift単体よりは劣る）
- スリッページ: ブレイクアウト成行注文は実際には高値/安値から数bps滑る可能性あり
- 流動性上位30銘柄でも、全銘柄に毎日入ると約30エントリー/日 → ポジション管理が必要

### 総合判断

**ORBに統計的エッジはある（採用検討レベル）** だが、単体戦略としては Sharpe がやや物足りない。
以下のいずれかを条件に採用を検討:

1. **銘柄フィルタ**: ORB相性の良い銘柄（フジクラ・ディスコ・川崎重工・三菱重工等）に絞る
2. **他戦略との組合せ**: pre_earnings_drift などのイベント戦略と組み合わせ、ノーシグナル日に補完
3. **方向性フィルタ**: 市場全体の方向性（日経寄り付き方向など）を見てロング/ショートを絞る

## 限界・注意点

- IS期間が2024-06開始のため約13ヶ月と短め（stocks_intraday データ開始が2024-05-10）
- 285Aはキオクシア上場が2024-12月頃のためIS N=54と少なく、OOS結果(Sh 2.55)は過大評価の可能性
- グリッドサーチ(216組合)なのでOOS結果も多少の過学習あり。独立期間での追加検証を推奨
- ブレイクアウト判定を1分足HighでやっているためBar内での実際の約定価格とズレあり

## 次のアクション候補

1. **銘柄特化ORB**: フジクラ・ディスコ・三菱重工などORB効果が高い銘柄に絞ってより深く検証
2. **方向性フィルタ**: 日経先物寄り付き方向 or 前日騰落でロング/ショートを制限
3. **ORB + PED組合せ**: 決算前ドリフト銘柄でORBが発動した場合に限定（ダブルシグナル）
4. **実運用テスト**: SL 0.5%/TP 2%/5m/11h/Long の組合せで小額から試運用（1〜2銘柄）
