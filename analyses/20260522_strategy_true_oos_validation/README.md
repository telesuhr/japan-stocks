# 真のOOS検証 — 戦略昇格判断のための選択バイアス排除

**日付**: 2026-05-22
**目的**: テクニカル戦略 (MA25/75, RSI<30) を strategies/ に昇格させる前の最終検証

## 設計の意図

前検証 [20260522_strategy_robustness_extension](../20260522_strategy_robustness_extension/) では「マルチ戦略 Sharpe +3.08」など強いエッジを発見したが、**銘柄選択を10年全期間のSharpeで決めていた**ため、選択バイアス (look-ahead bias) が残っていた。

本検証では `strategies/README.md` の昇格ワークフローに従い、**真のOOSテスト**を実施:

| 期間 | 役割 | 内容 |
|---|---|---|
| **IS** (2016-01-01〜2020-12-31, 5年) | 銘柄+戦略選別 | 各銘柄でMA25/75とRSI<30を比較し、IS Sharpe ≥ 2.0 をクリアする組合せを採用決定 |
| **OOS** (2021-01-01〜2026-05-22, 5.5年) | 評価のみ | IS で決定した銘柄+戦略をそのまま適用、何も再選別しない |

パラメータ (MA 25/75, RSI 30/50) は事前固定 (過剰最適化回避)。
