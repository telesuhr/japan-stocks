# earnings_pead × 会社予想ガイダンス改定 — 決算ギャップ買いはガイダンスで選別できるか

**結論: 事前登録した仮説 H1〜H4 は全て ✗ 棄却（改定の「方向」は無関係、rho=+0.018 p=0.50）。
ただし事後探索で「改定の大きさ」が効くことを発見（|改定率|≥20%: +3.87% vs <20%: +0.99%、
t=3.59、IS/OOS両方で独立に再現）。採用中 earnings_pead のフィルタとして
Sharpe +2.10→+2.63 / MDD −47%→−35% だが、事後仮説のため採用前に再検証が必須。**

- 実行: `run.py`（v1・修正開示ベース）→ `run_v2.py`（v2・決算短信の会社予想ベース／**こちらが本体**）

## 1. 目的・仮説（検証前に固定 — 教訓5）

採用戦略 **earnings_pead**（決算翌日ギャップ+7%以上 → 当日15:30引成Long → D+5引成、SL−5%、
Sharpe +2.19）に対し、「決算と同時に会社が業績予想をどちら向きにどれだけ改定したか」で
フィルタをかけると改善するかを検証する。

**着想の根拠 — 既出2件が正面から矛盾している:**

| 既出 | 主張 |
|---|---|
| 採用戦略 earnings_pead | 大幅ギャップは**買い**（ドリフトが取れる） |
| [20260613_earnings_forecast_revision_drift](../20260613_earnings_forecast_revision_drift/) | 最大級の上方修正(Q5)は寄り後に**アンダー**（overshoot-reversal） |

→「大幅ギャップ」かつ「大幅上方修正」の銘柄でどちらの力が勝つのかは未検証だった。

| ID | 仮説 | 予想 | 棄却条件 |
|----|------|------|----------|
| H1 | 同時に上方改定した決算ギャップはドリフトが強い | 上方群 > 据置・下方群 | 差の t<2 |
| H2 | ただし最大級の上方改定は overshoot-reversal で消える | 改定率に対し**逆U字** | 単調でも逆U字でもない |
| H3 | ギャップアップなのに下方改定/据置 = 材料出尽くし | 最弱 | 最弱でない |
| H4 | 最良層フィルタで earnings_pead の net Sharpe が改善 | Sharpe +0.3以上 | 改善 +0.3 未満 |

**事前登録した棄却条件**: 「層別間の差が t<2、**かつ**最良層のSharpe改善が +0.3 未満なら
フィルタ無効として棄却」。

## 2. データ・手法

| 項目 | 内容 |
|---|---|
| 期間 | 2016-05 〜 2026-07（10年3ヶ月） |
| シグナル | `fin_summary` の決算開示（D−1 15:00以降 or D 9:00前）→ D寄りギャップ ≥ +7% |
| 流動性 | ADV20（`turnover_value` 20日平均）≥ 5億円 |
| 執行 | D 15:30 引成 Long → D+5 15:30 引成。SL −5%（安値が初めて割った日で約定） |
| コスト | 往復 4bps（片側2bps）控除 |
| 年率化 | **日次バスケット系列**（保有中ポジションの等加重日次リターン）で √252。重複保有を正しく処理 |
| IS/OOS | IS 2016-2022 / OOS 2023-2026 |
| 先読み | 改定はD−1引け後の開示 → D 15:30 エントリー時点で既知。**ルックアヘッドなし** |

**n = 2,657 シグナル**（10年）。

### v1 の失敗と v2 での修正（重要）

- **v1**: ガイダンス改定を `earnings_forecast_revisions`（doc_type=`EarnForecastRevision`）から取得
  → これは**「予想修正の単独開示」だけ**で、決算ギャップ事象の **8%（208/2,657）しかカバーしない**。
  母集団が足りず、✗という結論の信頼度が低い。
- **v2**: `fin_summary.payload` の **`FOP`（当期 CurFYEn の会社予想営業利益）** と
  **`NxFOP`（次期 NxtFYEn の会社予想営業利益）** から、
  「ある決算期(fy_end)に対する会社予想の時系列」を銘柄ごとに構築し、各開示での前回比変化率を
  ガイダンス改定率 `guid_pct` とした。→ **カバレッジ 8% → 55%**（改定観測 109,951件）。
  - 例: Q1決算のFOPは、直前の通期決算の**NxFOP**（次期予想）と比較される。melt して
    fy_end 単位で並べることでこの接続を自動処理している。
  - 残り45%が「不明」なのは、前回予想が存在しない（初回ガイダンス）・FOP欄が空・
    非連結のみ開示 等による。

## 3. 結果

### 3-1. 事前仮説は全滅（改定の「方向」は効かない）

1トレードあたり net リターン(%)、往復4bps控除:

| 層 | n | 平均 | 中央 | 勝率 | t | SL率 | IS | OOS |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 下方 −10%超 | 30 | **+5.16** | +1.70 | 60.0% | +2.04 | 30.0% | +4.68 | +5.64 |
| 下方 −10%以内 | 20 | +0.79 | +2.06 | 65.0% | +0.79 | 30.0% | +0.49 | +1.33 |
| 据置(±0.5%) | 786 | +1.12 | −0.94 | 43.6% | +3.10 | 37.8% | +0.74 | +1.55 |
| 上方 +20%以内 | 283 | +0.73 | −0.59 | 46.3% | +1.73 | 35.3% | −0.68 | +2.02 |
| 上方 +20%超 | 347 | +3.62 | −0.74 | 47.0% | +4.69 | 45.0% | +2.93 | +4.80 |
| 不明 | 1,191 | +2.15 | −1.04 | 45.5% | +7.00 | 41.3% | +2.72 | +1.34 |

- **H1 ✗**: 上方(n=630) +2.32% vs 下方(n=50) +3.41%、差 **−1.09pt t=−0.66 p=0.51**。
  予想と**符号が逆**でしかも有意でない。
- **H2 ✗**: 改定率 vs net の**順位相関 rho=+0.018 p=0.495**（n=1,466）＝完全にゼロ。
  逆U字でも単調でもない。層別の恣意性を排除した連続量の検定なので、これが最も決定的。
- **H3 ✗**: 「下方改定＝出尽くしで最弱」は**逆**。下方−10%超が+5.16%と全層で最高（ただし n=30）。
- **H4 ✗**: 下記のとおりフィルタで改善しない。

### 3-3. 【事後・探索的】効くのは「方向」でなく「大きさ」

層別平均が据置(+1.12) < 小幅上方(+0.73) < 大幅上方(+3.62) と非単調に見えたため、
**事前登録していない**仮説「方向ではなく改定の**大きさ**（＝企業が出した情報量）が効く」を検証した。
データを見た後の仮説なので、**IS/OOS両方で独立に再現するか**を唯一の合格条件とした。

### 3-4. 副産物: 現行 earnings_pead の10年独立再現

戦略READMEの実績は 2024-01〜2026-05・n=1,244・Sharpe +2.19。
本検証は**2016-2026・n=2,657 に拡張しても Sharpe +2.10（IS+2.33 / OOS+1.67）**で生存を確認した。
別実装・別期間での独立再現なので、この戦略の頑健性を裏付ける。

ただし分布の性質に注意:
- **勝率 46%・中央値 −0.77%**。平均は**右裾（利食いなしの青天井ホールド）で稼ぐ**分布。
- **SL −5% の発動率 39%**。損切りが頻繁に効いている前提の戦略。
- 日次バスケットの **MDD −47%** は大きい（等加重フル投資前提。実運用は10ポジ上限・
  各100万円なのでこの数字そのままではない）。

## 4. 解釈

- **方向は既にギャップに織り込まれている**。決算翌日に+7%飛んでいる時点で「良いニュース」
  という事実は価格に入っており、会社が上方改定したか下方改定したかを重ねても情報がない
  （rho=+0.018）。[20260613](../20260613_earnings_forecast_revision_drift/) の
  「ニュースは寄りで完了」と完全に整合する。
- **残るのは「どれだけ大きなニュースだったか」**。会社予想を±20%以上動かすのは、
  企業自身が事業環境の変化を大きいと認めた場合＝**不確実性の解消量が大きいイベント**であり、
  市場が織り込むのに時間がかかる。これは PEAD の本質（情報の緩慢な織り込み）と整合する。
- 逆に「予想はほとんど動かさないのに株価は+7%飛んだ」ケースは、期待先行・需給・
  ショートカバー等で説明され、**中身が薄いので続かない**（小改定 +0.99%、
  特に0.5–5%層は−0.84%とマイナス）。
- 「下方改定なのに+7%ギャップ」が+5.16%と最高なのは、n=30と小さいが解釈可能:
  **悪材料出尽くし＋大きな情報更新**の組み合わせ。方向ではなく大きさが効く説と矛盾しない。

## 5. 限界・注意点

1. **3-3 は事後仮説（post-hoc）**。本サイクルで方向ベースの層別を6通り・フィルタを7通り
   試した後に見つけたもので、**多重検定のバイアスがかかっている**。IS/OOS独立再現という
   ガードは掛けたが、これは事前登録した検証ではない。
   → **採用前に「|改定率|≥20%」を事前登録した上で `/backtest-validation` を通すこと。**
2. **閾値20%は目視で選んだ**。50%+ が+6.77%と最良なので、閾値の最適化余地＝過学習余地がある。
   閾値感度（10/20/30/50%）を振って安定性を見ていない。
3. **カバレッジ55%**。残り45%の「情報なし」を提案フィルタに含めているが、これは
   「小幅改定だと判明したもの」を除外しているだけで、情報なし群自体は単独 Sharpe +2.48 と良好。
   ただし「情報なし」の発生が銘柄・時期に偏っているかは未確認。
4. **MDD −47%（現行）／−35%（提案）はいずれも大きい**。日次バスケットは等加重フル投資前提で、
   実運用の10ポジ上限・固定金額とは異なる。実運用MDDの推定は別途必要。
5. `guid_pct` は**営業利益**ベース。赤字→黒字転換など前回予想が0以下のケースは除外している
   （`prev_guid > 0` 条件）。これらは最も情報量が大きいイベントである可能性があり、
   取りこぼしている。
6. セクター中立化・サイズ中立化は未実施。[20260531_pead_enhanced](../20260531_pead_enhanced/) で
   PEADのセクター中立化は Sharpe を下げる（0.38→−0.24）と判明済みだが、
   「大改定」層がセクターに偏っていないかは未確認。

## 6. 次のアクション候補

| 優先 | アクション |
|---|---|
| 高 | 「\|ガイダンス改定率\|≥20%」を**事前登録して再検証**（閾値感度10/20/30/50%・セクター偏り・赤字転換の扱い） → `/backtest-validation` |
| 中 | 通れば `strategies/earnings_pead/signal_check.py` にフィルタを追加（`fin_summary.payload` の FOP/NxFOP から前回予想比を算出するロジックが必要） |
| 中 | 同じ「大きさ」軸を **pre_earnings_drift**（採用#1）にも当てられるか（決算前は改定が未知なので不可。代わりに過去の改定ボラティリティで代用できるか） |
| 低 | 赤字→黒字転換（prev_guid ≤ 0）の別枠検証。情報量最大のイベント群を取りこぼしている |
