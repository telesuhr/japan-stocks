# ETF配当金捻出売りの需給インパクト

## 目的・仮説

ETFの配当金支払いにあたり、受益者への分配原資を確保するために信託銀行がポートフォリオを売却する
「ETF配当金捻出売り」が市場に与える影響を定量化する。

**背景**: 2026年7月8日および10日の大引けで合計約1兆5000億円規模の売りインパクトが試算されている。

**仮説:**
1. 捻出売りの決算日（大引け）に向けて先行売り圧力が高まる（D-3〜D-1）
2. 売りイベント翌日以降に需給の反転（買い戻し・バリュエーション修正）が起こる
3. 売り規模が大きい年ほどインパクトが大きい

## データ

- テーブル: `index_daily` (TOPIX: 0000, 日経225: N225)
- ETF配当金捻出売り推定日: 毎年6〜7月（本決算配当の支払い月）
- 期間: 過去5〜10年分の同イベント前後

## 手法

1. 過去のETF配当金捻出売り推定日（決算日）を収集・整理
2. 各イベント前後 D-5〜D+5 のTOPIXリターンを集計
3. 売り推定規模別（大/中/小）のインパクト比較
4. 2026年7月8日・10日イベントへの示唆を導出

## 結果（主要指標）

対象: 2019〜2025年のETF捻出売り推定決算日 13イベント

| タイミング | 平均リターン | t値 | 解釈 |
|---|---|---|---|
| D-3 | -0.211% | -0.99 | 弱い先行売り |
| D-2 | -0.021% | -0.09 | ほぼフラット |
| **D-1** | **-0.474%** | **-2.34** | ★ 有意に近い先行売り |
| D+0 | +0.273% | +0.90 | 当日は意外にもプラス |
| D+1 | +0.044% | +0.19 | 反転効果は軽微 |
| D+2 | +0.302% | +0.99 | 若干のリバウンド |

- **累積 D-3〜D-1**: -0.707%（3日前から前日にかけて約0.7%下落）
- **累積 D+1〜D+3**: +0.479%（翌日以降は微弱なリバウンド）

売り規模別 D+0 リターン:
- 小規模（〜5000億）: 平均 +1.17%
- 中規模（5000〜7500億）: 平均 -0.03%
- 大規模（7500億〜）: 平均 -0.20%

## 所見・次アクション

### 主要発見

**「先回り売り」は実在する: D-1のt値 -2.34 は統計的に有意水準に近い（n=13でt閾値≈2.18）。**

- 捻出売り自体は大引けに集中するため、**場中の売り圧力は前日（D-1）に出やすい**
- 当日(D+0)は意外にもプラス — 大引けの売りは価格に織り込まれ、翌日以降は小幅リバウンド
- ただし翌日(D+1)のリバウンドはt=0.19と弱く、「翌日に買い戻す」ほどの有意なエッジはない
- 売り規模が大きいほど当日リターンが悪化（大規模-0.20% vs 小規模+1.17%）

### 今週への含意（2026年7月）

| 日付 | イベント | 期待値 |
|---|---|---|
| 7/7（月）| 7/8イベントのD-1 | ⚠️ 売り圧力（-0.47%相当） |
| 7/8（火）| 捻出売り本番 〜6000億 | やや中性〜弱（大引け注意） |
| 7/9（水）| 7/8翌日 / 7/10のD-1 | 弱い反転 + 再度D-1売り圧力 |
| 7/10（木）| 捻出売り本番 〜9000億（大規模） | やや弱（-0.20%相当） |
| 7/11（金）| 7/10翌日 | 軽微なリバウンド期待 |

### 限界・注意点

- サンプルn=13と少なく、各年の相場環境（強気/弱気）の影響を受ける
- ETF決算日の正確な日付は公開情報に基づく推定であり、誤差あり
- 2026年の売り規模（6000億・9000億）は今年の相場水準で変動する可能性
- 今年はマクロ不確実性（関税・FRB）が高く過去パターン通りにならないリスクあり

### 結論

「**D-1を売り、D+1以降に戻す**」戦略には統計的な根拠が一定程度ある。ただしエッジは小さく（-0.47%）、単純にTOPIXをショートするよりも、ETF比率の高い大型株（トヨタ・ソニー・三菱UFJ等）でのショートを7/7〜7/9に検討するのが実用的。
