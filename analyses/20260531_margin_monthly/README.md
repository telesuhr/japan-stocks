# 信用残ファクター 月次リバランス版

> **結論: 月次リバランスでもエッジなし。short_chg は IS強(Sharpe1.48)→OOS急失速(0.40)のレジーム罠。**
> margin_ratio は月次で符号逆転しマイナス。信用残ファクターはいずれの保有期間でも実用不可。

## 1. 目的

前段(週次)でコスト前Sharpe 0.41 の弱いシグナルが存在した `margin_ratio`。
週次コスト40bps > 生スプレッド12bps で実行不可。
→ **月次リバランス(コスト10bps)** に変更すれば実行可能域に入るか検証。

## 2. データ・手法

- 月次月末サンプリング: 63ヶ月, 1,146銘柄, 30,322行
- 信用残: `jquants_margin_interest` 月末値（±14日 merge_asof）
- フォワードリターン: 20営業日後TOPIX超過リターン
- ファクター: margin_ratio, long_chg, short_chg, net_chg
- 中立化モード: なし / セクター中立 / サイズ中立 / セクター+サイズ中立
- 分位: 5分位（月次はサンプル少ないため）, コスト: 10bps/月
- IS: 2021-2023 (34ヶ月) / OOS: 2024-2026 (27ヶ月)

## 3. 結果（セクター中立版）

| ファクター | IS Sharpe | OOS Sharpe | ALL Sharpe | t値(ALL) |
|---|---:|---:|---:|---:|
| margin_ratio（信用倍率） | -0.08 | -0.60 | **-0.26** | -0.59 |
| long_chg（信用買増） | -0.90 | -0.50 | -0.89 | -2.00 |
| **short_chg（信用売増）** | **1.48** | **0.40** | **0.92** | **2.07** |
| net_chg（需給変化） | -1.18 | -1.63 | -1.38 | -3.10 |

## 4. 主要発見

### margin_ratio は月次で符号逆転

週次: 高margin_ratio → 翌週プラス(生+12bps)
月次: 高margin_ratio → 翌月マイナス(-8.6bps/月)

**週次と月次でシグナル方向が逆転**。週次では短期モメンタム（信用買いが活発な銘柄が続伸）が
働くが、月次では「信用買い残が積み上がった銘柄は戻り売り圧力で下落」する需給の重しが
優勢になる。保有期間によってシグナルが逆転するため実用不可能。

### short_chg (信用売り残増加) のIS/OOS断絶

最も有望に見えるが典型的なレジーム罠:
- **IS (2021-2023)**: Sharpe 1.48, t=2.49, 勝率64.7%
- **OOS (2024-2026)**: Sharpe 0.40, t=0.60 → 統計的信頼性ゼロ

IS期間(コロナ後回復+値がさ株ブーム)は「信用売り増=売られすぎ→踏み上げ」の
ショートスクイーズ効果が機能したが、OOS期間では失効。

### 教訓: 中立化の効果

セクター中立 vs 非中立で short_chg のALL Sharpeは 0.63→0.92 と改善するが、
IS/OOS断絶は解消されない。中立化は「業種ベータ除去」には有効でも
「レジーム依存性」は除去できない。

## 5. 結論

**第九弾⛔: 信用残月次リバランスでも実用エッジなし**

| 保有期間 | margin_ratio コスト前Sharpe | 実行可能？ |
|---|---|---|
| 週次 (前段) | +0.41 | ✗ コスト40bps > 12bps/週 |
| **月次 (本段)** | **-0.26** | **✗ 符号逆転** |

信用残ファクターは「保有期間によってシグナルが逆転する」構造的問題を抱えており、
いずれの時間軸でも安定したエッジにならない。
