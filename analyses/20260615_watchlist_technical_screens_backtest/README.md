# watchlist_technical_screens_backtest — 「今日の注目銘柄」テクニカル・スクリーンの有効性検証

Dashboard_CC の `watchlist`(📌今日の注目銘柄) が出す7スクリーンが、実際に将来リターンを生むかを検証。

## 仮説（教訓5: 仮説先行）
各テクニカル条件で抽出した銘柄を**翌営業日の寄りで買い数日保有**したとき、
**同日の流動性ユニバース等加重（=ただ流動株をロングする）を上回る超過リターン**を残すか。
newlow(52週安値) は逆に下振れ（空売り/回避のエッジ）があるか。

## データ・手法
- 母集団: 流動性ユニバース（各日 point-in-time で直近20日平均売買代金 ≥ 1億円）。`stocks_daily` の調整後株価。
- 期間: 2022-07〜2026-06（200MAウォームアップ込み、評価は2023〜）。**rows=178万・1,929銘柄**。
- entry = **T+1 寄り(adj_open)**、exit = **T+h 引け(adj_close)**、h∈{1,5,10,20}営業日。先読み無し（教訓1: 必ず forward）。
- ベンチ: 同じ entry/exit 日のユニバース等加重平均 → `abnormal = 個別 − ユニバース平均`（市場ベータを除去）。
- コスト: long-only 往復 **10bp**（片道5bp）控除（教訓2）。
- 統計: **シグナル日ごとに等加重ポートフォリオの平均超過を取り、その日次系列で t 値**（同日多発のクラスタを考慮し pseudo-replication を回避）。
- **IS(<2025-01-01) / OOS(≥2025-01-01)** 分割で過学習・レジーム依存をチェック。

## 結果（abn=超過bp / net=コスト後 / t=日次クラスタt値、IS・OOS両方を重視）

## 結論
1. **強モメンタム(20日リターン上位×MA順行)が唯一、IS・OOS両方で有意な超過リターン**（h=20でIS t=2.0/OOS t=5.6、コスト後も+83bp/OOS）。日本株のモメンタム・プレミアムは実在し、5〜20日保有で取れる。**これが一番あてになる。**
2. **52週安値ブレイクは下落継続が頑健**（h=10-20でIS・OOS両方マイナス有意）。保有なら損切り・空売り候補の警戒リストとして機能する。
3. **出来高急増・ギャップアップ・52週高値は、足元(OOS)では好成績だが IS では無効〜マイナスで符号が反転**。直近の数字は2025-26の上昇相場のベータであって安定したアルファではない。**単独シグナルとしては信用できない。**
4. **ゴールデンクロス・押し目(RSI)はコスト後にエッジ無し**（広く知られた遅行指標）。
5. **どのシグナルも翌日決済(h=1)は不可**。最低5日、できれば10〜20日の保有を前提に使う。

## ダッシュボードへの含意
- `watchlist` は「値動きの手掛かりリスト」としては有用だが、**実エッジがあるのは強モメンタム（5-20日保有）と、下落警戒の52週安値のみ**。
- volsurge/gapup/newhigh は「注目はされるが順張りエッジは不安定」と明示すべき。GC/押し目はエッジ無し。
- 短期デイトレ用途には不向き（h=1負け）。スイング(1〜4週)向け。

## 再現
`python3 run.py` → `results.csv`（全シグナル×h×IS/OOS/全）, `result.png`（h=5 累積超過リターン）。
