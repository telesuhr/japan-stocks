# 平均回帰(RSI25逆張り) ポートフォリオ化・ベータ中立・レジーム分解

> **結論: 平均回帰の「エッジ」は市場ベータの幻だった。** 日次等加重バスケット(平均34銘柄)の
> 生Sharpeは0.26だが、TOPIXベータ0.85を中立化すると**全期間でSharpe −0.36**（IS −0.37 / OOS −0.36）。
> 逆張りの銘柄選択そのものは市場平均に負けている。生リターンの正の部分は100%が「下がった株を
> 買って市場の上昇に乗っていただけ」。年別Sharpeも +2.0〜−1.3 で乱高下＝安定エッジではない。

## 1. 目的

前段 [20260530_swing_breakout_meanrev_universe](../20260530_swing_breakout_meanrev_universe/) で
MR_rsi L25 が唯一 IS/OOS 両プラス（per-trade Sharpe近似 0.26→0.55）だった。これを深掘り:

- (a) **日次等加重バスケットの実ポートフォリオSharpe**（同時保有・相関込み。per-tradeではなく実運用に近い形）
- (b) **TOPIXベータ中立化** → 純粋なαを分離（生リターンが単なる市場エクスポージャーでないか検証）
- (c) **レジーム分解**: 年別 / ボラ環境別（いつ効くか）

## 2. データ・手法

- データ: `public.stocks_daily`（分割調整済, 2016/05〜2026/05, PostgreSQL@Omen）
- ユニバース: 普通株・流動性≥10億円/日（前段と同じ）3,067銘柄
- 戦略: RSI(25)≤30 で翌日寄成Long、5営業日保有。pyramiding無し（保有中の追加シグナル無視）
- ポートフォリオ: 各日、保有中の全銘柄を等加重。entry日は open→close、以降 close→close。
  コスト往復10bpsをentry日に控除。最低5銘柄保有日のみ採用（平均34銘柄/日, 2,106営業日）
- ベータ中立: 日次 port_ret を TOPIX日次リターンに回帰、`ret − β·mret` を中立リターンとする
- レジーム: 年別Sharpe / TOPIX実現ボラ(20日)の3分位別Sharpe

## 3. 主要発見

### (a)(b) ポートフォリオSharpe: 生 vs ベータ中立

| 期間 | 生Sharpe | ann_ret | **中立Sharpe(真のα)** | maxDD(生) |
|---|---:|---:|---:|---:|
| ALL | 0.26 | +5.6% | **−0.36** | −49.7% |
| IS (2016-21) | −0.03 | −0.6% | **−0.37** | −35.0% |
| OOS (2022-26) | 0.54 | +12.3% | **−0.36** | −27.9% |

- **TOPIXベータ = 0.85**。ほぼフルロングのエクスポージャー
- **ベータ中立化で全期間マイナス**。生の正リターンは100%市場ベータの寄与
- 最大DD −49.7%（生）。逆張りバスケットは暴落で深く沈む

### (c1) 年別Sharpe（生）

```
2016 +0.70 / 2017 +1.79 / 2018 −1.33 / 2019 +1.95 / 2020 −0.97 /
2021 −0.74 / 2022 +0.73 / 2023 +1.35 / 2024 −0.11 / 2025 +0.63 / 2026 −0.34
```
- +1.95〜−1.33 で乱高下。プラス年6・マイナス年5。**安定したエッジではない**
- 下落・高ボラ年(2018,2020,2021)で大きくマイナス

### (c2) ボラ環境別（TOPIX実現ボラ20日の3分位, 生Sharpe）

| 環境 | 生Sharpe | 中立Sharpe | ann_ret |
|---|---:|---:|---:|
| 低ボラ (5-13%) | +1.14 | +0.47 | +18.2% |
| 中ボラ (13-17%) | +0.53 | +0.14 | +9.4% |
| 高ボラ (17-65%) | **−0.39** | **−1.36** | −10.9% |

- **低ボラ環境でのみ機能**。高ボラ（暴落・混乱期）では生・中立とも明確にマイナス
- 「平均回帰は穏やかな相場で効き、荒れ相場で逆回転する」教科書通りの性質

## 4. 解釈・示唆

1. **前段の「IS/OOS両プラス」は市場ベータだった**: per-tradeで見えたプラスは、逆張りが
   構造的にロングバイアスを持つため。**αとして取り出すと消える（むしろマイナス）**。
2. **唯一の使いどころは「低ボラ限定」**: 低ボラ環境の中立Sharpe +0.47 だけがプラス。
   レジームフィルタ（高ボラ時は停止）を噛ませれば、わずかなαは残るかもしれないが、
   単体で昇格基準(Sharpe 2.0)には全く届かない。
3. **ユーザーの直感が再び正しい**: 「再現性がない」。t値17の華々しさ → ポートフォリオ化 →
   ベータ中立、と一段ずつ剥がすたびにエッジが消えていった。
4. **3連敗の意味**: 今セッションで板シグナル⛔・ブレイク⛔・平均回帰⛔。**日本株の単純な
   テクニカル戦略には、コスト・ベータを正しく差し引くとエッジは無い**ことが繰り返し確認された。
   既存の昇格6戦略（イベント系・特定銘柄VWAP）が「単純テクニカルではない」点が逆に際立つ。

## 5. 限界・注意点

- **生存者バイアス（重要）**: `symbol_master` は上場廃止銘柄を保持していない（delisted=0）。
  ユニバースが現存銘柄に偏り、**平均回帰を過大評価する方向**にバイアス（下がり続けて廃止された
  銘柄が除外される）。それでもαがマイナスという結論は、バイアスを考えるとむしろ強固。
- **ボラ指標の代替**: 日経VI(VXJ)がDBに無いため TOPIX実現ボラ(20日)で代替。VIとは概念が近いが別物。
- **等加重・無制約**: 日々保有数が変動（平均34、最大はもっと多い）。資金制約・1銘柄上限・
  約定インパクトは未考慮。実運用ではさらに不利。
- **ベータ中立は事後回帰**: フルサンプルβで中立化（in-sampleβ）。厳密にはローリングβが望ましいが、
  結論（中立後マイナス）の頑健性には影響しない水準。
- これはエッジ所在の確認であり、低ボラ限定運用の可能性を完全には否定しない（深掘り余地は(6)）。

## 6. 次のアクション候補

- ❌ 平均回帰の無条件ポートフォリオ運用は見送り（中立後マイナス、暴落耐性なし）
- 🔍 **低ボラレジーム限定**でのみ中立α +0.47 が残る → 高ボラ時停止フィルタ付きで再評価する価値は
  あるが、優先度は低い（単体Sharpe 2.0 には遠い）
- 🔍 **生存者バイアス補正**: 上場廃止銘柄を含むデータソース（nas_archive等）で再検証できれば、
  テクニカル戦略全般の評価がより正確になる（基盤改善タスク）
- ✅ **方針転換**: 単純テクニカルは3連敗。既存昇格戦略の系統（決算イベント・信用需給・特定銘柄の
  構造的VWAP回帰）= 「単純な価格テクニカルではないエッジ」に研究resourceを寄せるべき。
  次は JQuants固有データ（信用残・空売り比率・投資部門別）を使った戦略の検証が筋が良い。
