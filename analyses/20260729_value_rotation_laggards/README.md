# value_rotation_laggards — 割安株への資金シフトは実在するか＋乗り遅れバリュー株

## 目的・仮説
「最近、割安株に資金がシフトしてそう」という体感を検証し、正しければ**まだ上がってない
（乗り遅れ）割安株**を抽出する。

- **H1仮説**: 足元(2026-07)は割安(低PBR)が割高(高PBR)を明確に上回っている（H1には無かった現象）。
- **H2仮説**: 足元−15%超の急落で"見かけ割安"になった銘柄は、バリュー乗り遅れではなく
  グロース崩れ（売られてる側）＝除外すべき。

## データ・手法
- テーブル: `stocks_daily`（adj_close/turnover_value）＋ `fin_summary`（PIT BPS/NP/Eq）＋ `symbol_master`
- ユニバース: 全市場・**非金融**・**ADV≥3億円**・PBR 0.1〜10
- PBR = raw close / 開示BPS（`merge_asof` backwardで**先読み無しのPIT**結合）、ROE = NP/Eq
- 窓: **H1**=2025/12末→2026/6末（形成=12末）、**足元**=2026/6末→7/28（形成=6末）
- 各窓でPBR5分位のEWリターンと Q1割安−Q5割高スプレッドを比較。日次はQ1/Q5の累積も可視化
- ※方向性・資金フローの記述検証（売買シグナルの直接バックテストではない）

## 結果（主要指標）

### ✅ ローテーションは実在（足元で明確・単調）

| 分位 | H1(1→6月) | 足元(6末→7/28) |
|---|---:|---:|
| Q1 割安 | +10.9% | **+3.3%** |
| Q2 | +9.3% | +2.4% |
| Q3 | +13.4% | −0.7% |
| Q4 | +18.1% | −2.6% |
| Q5 割高 | +10.9% | **−4.6%** |
| **Q1−Q5スプレッド** | **−0.0%** | **+7.8%** |
| 市場EW | +12.5% | −0.4% |

- **H1は割安プレミアムゼロ**（むしろQ4が最強＝グロース/中位が牽引の全面高）。
- **足元はQ1→Q5が完全に単調な右肩下がり**。市場が横ばい(−0.4%)の中で**割安+3.3% / 割高−4.6%、
  スプレッド+7.8%**。**「H1に無く足元だけにある」＝レジーム転換の典型形**。
- 日次では**7/16-17（＝ビッグテックのAI設備投資懸念売り）を境に割安と割高が決定的に分岐**。
  → **正体は"バリューが買われた"より"AI/グロースが剥がれた"の寄与が大きい**（Q5−4.6%）。
  つまり今回のローテーションは**AIグロースのディレーティングの裏返し**。

### 除外した「見せかけの割安」（乗り遅れではない）
足元−15%超の急落17件は、暴落でPBRが下がっただけの**グロース崩れ＝落ちるナイフ**:
古河電工(−36%)・日東紡(−33%)・住友電工(−25%)・デンカ(−21%)…（多くがAI-DCケーブル/半導体材料）。
**"安いから買い"ではなく"ローテーションで売られてる側"。乗り遅れバリューと混同しない**（教訓: PBRだけ見ると罠）。

## 所見・次アクション
- **資金シフトは事実**。ただし**まだ約4週間の現象**で、durableなバリュー相場入りかAIグロース調整の
  一時的裏返しかは未確定。**継続の可否は今週(7/29-31)のビッグテック決算＝AI capexの答え合わせ**に依存
  （AI懸念が解消すればグロース復活で本ローテーションは巻き戻りうる）。
- **示唆**: 乗り遅れ候補は「割安×質×内需ディフェンシブ×まだ未反応」。**商社(住友商事)・食品(森永乳業)・
  ガス・建設**あたりが本命。**AI/半導体グロース(高PBR)の反対側**なので、グロース偏重ポートの
  ヘッジ／分散としても機能する。
- **限界**: (1) 1ヶ月窓で母数の割にノイズ耐性は限定 (2) 既存知見どおりPBR効果の一部はサイズ交絡
  （[20260719_pbr_below1_market_wide](../20260719_pbr_below1_market_wide/) 参照。単独L/SはSh0.64で
  昇格基準未達）。本分析は**銘柄選択スクリーン＋足元フロー確認**の位置づけで、単独売買戦略ではない。
- **次**: 乗り遅れ32銘柄の等加重を「継続ローテーション条件付き」でフォワード監視。durable化の兆候
  （2〜3ヶ月スプレッド継続）が出れば戦略候補に格上げ検討。
