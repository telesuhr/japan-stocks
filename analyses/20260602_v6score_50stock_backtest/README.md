# V6モメンタムスコア 50銘柄バックテスト

## 分析の目的・仮説

`morning_dashboard.html` に実装した V6 モメンタムスコアを、22銘柄(主戦) → 50銘柄(大型主力追加)に
拡張し、実装済みロジックそのままでクロスセクショナル L/S・Long-only の収益性を検証する。

研究 `20260531_v6score_comprehensive` の次アクション #2(ユニバース拡張 50銘柄でL/S)・#4(V6 L/S本格バックテスト)に該当。

**仮説**: ユニバースを 22 → 50 に広げると、各サイドの銘柄数が増えて L/S が分散され Sharpe が安定するはず。

> **位置づけ(重要)**: 50銘柄 L/S は既に `20260531_v6_universe50_ls`(top8/bottom8)で検証済み、
> `20260531_v6b_nonoverlap_cost` で**コスト込み・非重複の真のnet Sharpe=0.84(全)/0.25(IS)/1.55(OOS)**と判明し、
> 昇格基準2.0未達で**V6b単独実装は見送り(⛔)**になっている。本分析は「ダッシュボードに実装した V6_raw 式そのもの
> (`r20_adj + 0.5×d75×10`)・実装ユニバース・ベアゲート」を**グロス(コスト前)**で改めて確認するのが目的であり、
> 標準戦略への昇格を主張するものではない(ダッシュボードのランキング/監視ツールとしての妥当性確認)。

## スコア定義(ダッシュボード実装と完全一致)

```
r20_adj = r20 / vol20        # vol20 = 直近20日の日次リターン標準偏差(母集団std) × √252
d75     = 現値 / MA75 - 1
V6_raw  = r20_adj + 0.5 * d75 * 10
```

- N225 60日リターン < -3% で**ベアゲート発動** → ロングサイドを現金化
- 研究版 run.py とは std(母集団 vs 標本)・20日窓の取り方が僅かに異なるが、**デプロイ済みロジックを検証**するのが目的

## データ概要

| 項目 | 値 |
|---|---|
| ユニバース | 50銘柄(主戦22 + 大型主力28) / 比較用22銘柄 |
| 期間 | 2021-10-01〜2026-06-01(指標安定後から評価) |
| IS / OOS | IS: 2022-01-01〜2023-12-31 / OOS: 2024-01-01〜 |
| サンプル | 50銘柄=54,306 / 22銘柄=22,968(銘柄×評価日) |
| 保有 | 20日フォワード(A〜D) + 日次リバランス翌日リターン(E, 図示用) |
| データ | `stocks_daily`(adj_close) / `index_daily`(N225) |

## 主要発見

### ⚠ 研究版 OOS Sharpe=9.83 は過大評価だった

前研究の "OOS Sharpe 9.83" は **20日保有の重複日次サンプルを √252 で年率化**したもので、独立サンプル前提が崩れ
大きく膨らんでいた。本バックテストでは20日保有を **√(252/20)** で正しく年率化。現実的な水準は以下。

### 1. 50銘柄ユニバース

| 指標 | 全期間 | IS(22-23) | OOS(24-) |
|---|---|---|---|
| V6_raw IC mean | +0.051 | +0.012 | **+0.106** |
| V6_raw ICIR | 3.23 | 0.75 | **7.31** |
| Long-only Sharpe(上位20%) | 1.06 | 0.72 | **1.37** |
| **L/S Sharpe(上5/下5)** | **1.27** | 0.85 | **1.84** |
| L/S 平均(20日) | +4.21% | +1.96% | +7.10% |

### 2. ユニバース拡張効果(22 vs 50)

| 指標 | 22銘柄 | 50銘柄 |
|---|---|---|
| L/S Sharpe 全期間 | 1.07 | **1.27** |
| L/S Sharpe OOS | 1.54 | **1.84** |
| Long-only 平均(OOS,20日) | **+10.35%** | +7.70% |
| V6 IC ICIR 全期間 | **3.51** | 3.23 |

→ **L/S Sharpe は 50銘柄が明確に改善**(全期間 +0.20、OOS +0.30)。仮説どおり分散効果で安定。
ただし Long-only の**リターン絶対値は 22銘柄が上**(半導体・非鉄の強モメンタムに集中するため)。
IC自体は22銘柄がやや高い=主戦銘柄ほど因子が効く。

### 3. ベアゲートは機能している

日次リバランス Long-only Sharpe:

| | ゲート無 | ゲート有 |
|---|---|---|
| 全期間 | 1.94 | **2.05** |
| IS | 1.22 | **1.54** |
| OOS | 2.50 | **2.54** |

→ N225 60日 -3% 割れでロングを現金化すると、特に荒れた IS 期間(2022-23)で Sharpe が +0.32 改善。

### 4. 日次リバランス L/S エクイティ

- 累積リターン **+852%**、最大DD **-34.0%**(2021-10〜2026-06、約4.7年)
- L/S 日次Sharpe: 全 1.50 / IS **0.35** / OOS **2.35**
- IS が弱い(2022-23の急落・往来相場でモメンタムが効かない)、OOS で急伸(AI/半導体ブーム)

> **これらは全てグロス(コスト前)**。同条件をコスト込み・非重複で測った `20260531_v6b_nonoverlap_cost` では
> net Sharpe 0.84(全)/1.55(OOS)。本分析のグロス値(全1.27/OOS1.84)はそれと整合的(グロス>ネット)で、
> **単独戦略としては昇格基準2.0未達**という既存結論を覆さない。

## 解釈・示唆

1. **ダッシュボードのV6ランキング/ゲート設計は妥当**。50銘柄でL/SのグロスSharpeはOOS 1.84・全期間1.27で、因子の符号・方向は実装どおり機能する(監視・候補抽出ツールとして有用)。
2. **L/Sは50銘柄が22銘柄より安定**(全期間 +0.20、OOS +0.30)。仮説どおり分散効果。ただし**Long-onlyのリターン絶対値は主戦22銘柄が上**(半導体・非鉄の強モメンタムに集中)=守りの50/攻めの22。
3. **ベアゲートは堅牢**。下げ相場で機械的にロングを抜く効果が IS で確認でき(Long Sharpe +0.32)、過学習でなく構造的。ダッシュボードのゲート表示は正当。
4. **単独売買戦略としては非推奨**。コスト込み net 0.84(全期間)は昇格基準2.0に届かず、年別で符号反転するレジーム依存(既存⛔判定を追認)。あくまでスコア表示・ロング候補の絞り込み用途に留める。

## 限界・注意点

- IS(2022-23)の L/S 日次Sharpe=0.35 は弱く、モメンタム戦略は環境依存が大きい
- コスト未考慮(日次リバランスは売買コスト・スリッページで Sharpe が目減りする → 実運用は20日保有寄りが現実的)
- 50銘柄でも各サイド5銘柄=集中度は依然高い。個別決算ギャップのリスクは残る
- 当日終値で V6 を計算し当日終値→将来でリターンを取る(ルックアヘッドなし)が、寄りエントリーの滑りは未反映
