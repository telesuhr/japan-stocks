# 非鉄8銘柄 シングルサイド戦略 (ブレイクアウト・平均回帰)

**日付**: 2026-05-22 (同日 L/S 分析の続編)
**対象**: 非鉄金属8銘柄 (5706/5711/5713/5714/5016/5801/5802/**5803**)
**期間**: 2025-04-01 〜 2026-05-21 (273営業日)
**データ**: OMEN PostgreSQL `stocks_intraday` / `stocks_daily`

## 目的

L/S では機能しなかった戦略でも、シングルサイドにすればエッジが出る可能性を検証する。代表3戦略を並列スクリーニング:

- **A: ORB** (Opening Range Breakout, 寄付15分高安ブレイク)
- **B: 寄付ギャップフェード** (前日終値→寄付ギャップ閾値超で逆張り)
- **C: VWAP 当日平均回帰** (累積VWAPからの 1.5σ 逆張り)

## 3. 解釈・示唆

### なぜ寄付ギャップフェードが効くのか
1. **過剰反応の修正**: 寄前ニュース (米国市場・為替・個別IR) に過剰反応する寄付付値が、日中の出来高を通じて適正化されやすい
2. **大型流動株で顕著**: 住友電工 (Sharpe 7.07) /古河電工 (3.22) /フジクラ (3.20) などの売買代金大型銘柄で特に強い。これは個人投資家・短期トレーダーが寄付に集中し、その後機関の冷静な約定で戻されるパターン
3. **1.5% 閾値が境界**: 閾値が低すぎる (≤1.0%) とノイズ、高すぎる (≥2.5%) とサンプル不足。1.5% に明確なエッジ境界

### L/S 失敗との対比
| 項目 | L/S (前回, `H2`) | シングルサイド (今回) |
|---|---|---|
| エントリ条件 | グループ内ギャップ相対ランク (top1/bottom1) | 個別 \|gap\| ≥ 1.5% |
| Sharpe (8bps) | **-1.07** | **+2.10** |
| 違いの原因 | グループ内相対値はノイズ多, 毎日エントリで取引コスト累積 | 過剰ギャップ銘柄に絞ることでシグナルS/N比向上 |

### ORB が機能しない理由
- 寄付15分のレンジが狭く、ブレイクの「騙し」が多い
- 1日1回のエントリで取引数は多いが (1,843trades), per-trade のエッジが小さい
- 唯一フジクラ (+0.02 Sharpe) だけ僅かに踏ん張る (AIテーマ追風)

### VWAP 当日回帰が壊滅する理由
- **非鉄銘柄は当日トレンドが続く** (= 平均回帰しない)
- これは前回のクロスセクションモメンタムでも同じ示唆。**「平均回帰」を狙うべきでなく「順張り」が筋**
- VWAP上抜けで順張りロング戦略 (= 逆ロジック) の方が有望な可能性 → 次回検証候補

## 4. 限界・注意点

- **N=139発火日** (Top5) は短く、Sharpe推定の標準誤差は ±0.4 程度。真のSharpeは +2.5 ± 0.4
- **執行モデル甘い**: 寄付Open価格で約定可能と仮定。実際は寄付板の不均衡で滑る (特に大型ギャップ日)
- **ギャップ閾値の選択バイアス**: 1.5% は事後的に最適に見えたが、out-of-sample で再評価必要
- **半期サンプル**: 2026H1 は 33営業日と短く、Sharpe +6.00 は過大評価リスク
- **寄付板の流動性**: 8bps 片道は機関ベース前提。寄付の薄い板で 8bps は楽観的かも

## 5. 次のアクション候補

優先度高:
1. **逆VWAP戦略** (順張り) — VWAP上抜け継続でロング、下抜けでショート。当日トレンド継続の検証
2. **ギャップ + 出来高フィルタ** — 寄付出来高が平常時の何倍か (`v_open / v_avg`) を組み合わせ、薄商いギャップを除外
3. **寄付板スリッページ調査** — JQuants の寄付Open価格と寄付直後 (9:00-9:01) のVWAP差を計測し現実コスト推定
4. **戦略統合** — 寄付ギャップフェード (今回) と前回L/S ペア戦略 (DOWA/フジクラ) を統合 → 相関低ければ Sharpe 改善

優先度中:
5. **時間帯分解** — 引けまで持たず、寄付後30分 / 1時間 / 2時間 / 11:30 / 12:30 などで段階的にエグジット
6. **大ギャップ日の上抜け追随** — 閾値 2.5% 超の場合は逆張りせず順張りに切替 (N=18 でレジーム特性確認)
7. **ユニバース拡張** — TOPIX非鉄全銘柄 + 電線セクター (5805 SWCC, 5807 東京特殊電線等)
