# 前場暴落 → 後場リターン分析

**実施日**: 2026-06-04
**データ期間**: 2024-11-01 〜 2026-06-03 (383営業日)
**対象銘柄**: 流動性ADV≥100億円・151銘柄
**件数**: 47,511件 (銘柄×日)

## 分析の目的・仮説

前場が大きく下落した日に、後場で回復するのか継続して下落するのか。
逆張り(回復)と順張り(継続)のどちらが支配的かを検証する。

## 手法

- 前場リターン: 9:00 始値 → 11:29 終値
- 後場リターン: 12:30 始値 → 当日最終バー終値 (15:20〜15:35)
- 前場リターンをバケット別に分類し、後場リターンの平均・勝率・t統計量を計算
- 個別銘柄レベル(全銘柄プール) + 市場集計レベル(等ウェイト平均)の両面で検証

### 線形回帰

- 回帰係数 β = -0.030 (前場-1%あたり後場+0.030%)
- R² = 0.0020
- p値 = 5.2e-22
- 相関係数 r = -0.044

弱い逆張り特性が統計的に有意。ただし説明力(R²=0.002)は極めて低い。

### 市場集計レベル (n=383営業日)

前場-2%以下は期間中3日のみ(N少すぎて判断困難):

|---|---|---|---|
| 2026-04-02 (トランプ関税ショック) | -2.68% | -0.34% | 継続下落 |

| 2025-04-07 | -2.16% | -1.80% | 継続下落 |

前場-1〜-0.5%では後場+0.081%(勝率57.1%)と逆張り傾向。

## 解釈・示唆

**個別銘柄で前場-3%超の大崩れは後場に回復圧力がある**。
メカニズムとして考えられるのは:
1. 前場の過剰売りに対する自律反発(平均回帰)
2. 外国人勢の前場売りに国内勢が後場で拾う構造
3. ただし勝率は49.4%で50%以下 → 平均は引き上げられているが中央値は0%。一部の大きな回復日が平均を押し上げている(外れ値効果)

**≥+3%の前場急騰後の後場反落(-0.156%, t=2.90)も有意**。前場の過熱が後場で剥落する。

**市場全体が崩れているときは継続の印象**:
市場集計でn=3という少数だが、3日中2日(67%)が後場も下落。トランプ関税ショック・2025-04-07は継続。市場全体パニック時は個別の逆張りが効かない可能性。

## 限界・注意点

1. **期間が20ヶ月と短い**: 市場集計での前場-2%以下はn=3。個別銘柄の≤-3%は1,422件と十分だが、市場暴落日の検証は別途必要
2. **中央値が0%**: 平均を引き上げているのは一部の大回復日(外れ値)。実際に取引するとコスト後に消える可能性
3. **コスト考慮なし**: 往復コスト4〜8bps程度。+0.222%は十分大きいが、前場-3%は流動性が悪化しているケースも多い
4. **前場リターンの定義**: 9:00始値→11:29終値(前場内のみ)。前日終値からのギャップは含まない
5. **R²=0.002**: 前場リターンだけでは後場をほぼ予測できない。他の変数との組み合わせが必要

## 次のアクション候補

1. **市場環境別の分類**: VIX高/低、前日の海外市場の方向で分けると、「本物の暴落日」と「軽い下落日」で後場挙動が違う可能性
2. **勝率が50%以下の謎**: 平均+0.222%なのに勝率49.4%。一部の大きな回復が引き上げている → ヒストグラムで確認
3. **前日との連続性**: 前日も下落していた場合の翌日前場→後場 vs 急落1日目の違い
4. **実取引可能性**: 11:30前場引け直後エントリー → 15:20前後場引け前手仕舞いの往復コスト込みシミュレーション
