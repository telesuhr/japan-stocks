# EDINET 大量保有 機関集積 → ドリフト検証 (institutional accumulation drift)

## 目的・仮説（教訓5: 検証前に仮説を固定）

**仮説**: EDINET大量保有報告(5%超)で、**機関が保有を積み増す銘柄はその後アウトパフォーム**、
減らす銘柄はアンダー。前回の機関ショート検証(売り手)の**買い手側の鏡**。
`jquants_short_sale_report`(売り手の足跡)に対する `edinet_large_holdings`(買い手の足跡)。

**最初からサイズ調整＋コスト込**(本セッションの作法)。**留保**: filerにパッシブ/インデックス
(BlackRock/野村AM等)・証券自己(商品在庫の在庫ヘッジ)が混じり、これらは非情報の機械的変化＝シグナルを希薄化。

## データ
| 用途 | テーブル | 期間 | 備考 |
|---|---|---|---|
| シグナル | `edinet_large_holdings` | **2024-06〜2025-10(連続17ヶ月)** | ※2025-11〜2026-03はAPI 429で欠損 |
| 価格 | `stocks_daily` (adj_open/adj_close) | 同 | 分割調整済 |
| ベンチ | `index_daily` サイズ別(0040/0041/0043/0045) + `topix_weights` | 同 | サイズ調整 |

**シグナル**: `(code, submit_date)` ごとに `COALESCE(ratio_change, holding_ratio)` を合算
= **net_holding_change**(保有割合の正味変化pp, 新規5%超は新規保有率を加算)。10,845イベント・2,331銘柄。

## 手法
- **タイミング(先読み排除)**: エントリ=submit_dateの**翌営業日寄り**。保有5/10/20/40日(機関集積の遅効性も見る)。
- **サイズ調整超過**: 銘柄(寄→引+h) − サイズ別指数(同)。サイズ=topix_weights(非TOPIXはSmall代用)。
- **層別**: net_holding_change 五分位(Q1=大幅減 … Q5=大幅積み増し) × 保有h。新規5%超 subset も別途。
- **戦略**: Q5(積み増し)中立ロング + Q1(減)中立ショート、翌寄りh日。**コスト往復20bp(教訓2)**。IS(〜2025-02)/OOS分割。

## 所見・次アクション

**直線的仮説(積み増し→上/減→下)は棄却。だが"買いの順方向"の片鱗は初めて見えた。**

1. **U字＝方向でなく活動量**: Q1(大幅減)もQ5(大幅積み増し)もその後アウト(+167/+125bp/20d)、Q3(無変化)だけフラット。つまり**「大口5%保有者の動きがあった銘柄」は方向に関わらず超過**＝イベント選別/注目効果。直線的なロングショートは成立しない(短い側Q1が上がるので戦略は−42bpで負け)。

2. **★唯一の有望シグナル＝新規5%超**: 機関が新規に5%を超えた銘柄は **+394bp/40日(サイズ調整)** と強い正のドリフト・**ロングオンリー**(踏み上げリスク無)。本セッションで初めての"買いで取れそう"な片鱗。

3. **⚠️ ただし重い留保（過信禁物）**:
   - **期間が2024-06〜2025-10の17ヶ月＝ほぼ一方的な強気相場**。サイズ調整はしたが粗く、**小型グロース/モメンタムの残差**が+ドリフトを膨らませている可能性大。
   - **モメンタム未制御**(機関は上昇後に5%入りしモメンタム継続、の疑い＝前回ショート検証の教訓)。
   - filerにパッシブ/証券在庫ヘッジ混入(留保どおり)。**API 429でデータが5ヶ月欠損**し全期間でない。

**判定: △（直線仮説は棄却・U字＝活動効果。ただし新規5%超のロングオンリー+394bp/40dは本セッション初の"買い"の有望lead。強気相場17ヶ月＋モメンタム未制御で確証には程遠く、要 (a)モメンタム制御 (b)欠損埋めて全期間＋複数レジーム (c)同ユニバース無条件baselineとの差分）**

**次アクション**: (a) 新規5%超を **prior_mom制御**で再検証 (b) 欠損埋め全期間 (c) アクティブ機関に純化。 → **(a)(c)を `run_v2.py` で実施。下記。**
