# options_iv_regime_gate — 日経225オプションIVレジームゲート

## 目的・仮説

`options_n225`（2016/05〜、9.9M行、IV/建玉つき）はこれまで未活用。個別戦略ではなく、
**既存スイング戦略バスケット（ロングバイアス）のポジションサイズを制御するレジームゲート**としての有効性を検証する。

仮説（事前に固定。グリッドサーチはしない — 教訓5）:

1. **H1: プットスキューの急拡大は下落リスクの先行指標**
   機関のヘッジ需要（OTMプット買い）が先行するため、スキュー（OTMプットIV − OTMコールIV）の
   z-scoreが高い局面では、その後5〜20日の指数・大型株リターンが悪化する。
2. **H2: IVターム構造の逆転（期近ATM IV > 期先ATM IV）はストレス局面の同時〜先行指標**
   平常時はコンタンゴ（期近<期先）。逆転時はロングエクスポージャを落とすことで
   ドローダウンを回避できる。
3. **H3: ATM IVの急上昇（5日変化のz-score高）も同様のリスクオフシグナル**
4. これらのゲートは、既存のV4/V5で使っている価格ベースゲート（N225 R60 < -5%）よりも
   **早く・情報量多く** 反応する（オプション市場は価格下落の前にヘッジが入る）。

期待される使い方: シグナル発火時にバスケットのエクスポージャを 1.0 → 0.5（複合時 0.25）に縮小。
リターン向上ではなく **Sharpe改善・MDD縮小** が成功基準。

### Point-in-Time 注意（重要）

JQuantsのオプションデータは **T日の settle が T+1日17:00バッチで到着**（updated_at で確認:
date=6/8 の行が 6/9 17:06 更新）。よって T日データから作る指標は **T+2日のリターンから適用**
（`shift(2)`）。価格ベースのR60ゲートは T日終値で計算可能なので `shift(1)`（現実の運用ラグに合わせ、
ゲート間でラグは揃えない）。

## 手法

1. 日次×限月で集計（OI上位2限月=月物を採用、dte 7〜120日）:
   - ATM IV: モネーネス 0.975〜1.025 の Put/Call IV 平均
   - スキュー: Put(モネーネス0.90〜0.96) IV − Call(1.04〜1.10) IV（期近）
   - ターム: ATM IV(期近) − ATM IV(期先)。正=逆転
   - IV5日変化、実現ボラ20日(N225)、VRP = ATM IV − RV20
2. z-score: 252日ローリング（min 126日）
3. 予測力診断: z-scoreの五分位 × 先行5/20日 N225リターン、Spearman IC
4. ゲートバックテスト（対象: N225ロング / EW22バスケットロング、コスト: エクスポージャ変化×5bps）:
   - G1: skew_z > 1.5 → 0.5
   - G2: ターム逆転（>0）→ 0.5
   - G3: iv_chg5_z > 1.5 → 0.5
   - G_combo: 発火ごとに半減（下限0.25）
   - 比較: ゲートなし / 既存型 R60<-5%ゲート
5. 評価: 全期間 + 前半(〜2021)/後半(2022〜) 分割で Sharpe・MDD・年率の安定性確認

|---|---|---|---|---|
| skew_z | +0.110 | +0.108 | +0.38% | +1.85% |
| term | +0.099 | +0.140 | +0.68% | +2.09% |

**ICは全て正** — 恐怖シグナル高 → その後20日リターンは「良い」（リバウンド・リスクプレミアム）。
当初仮説H1（スキュー高→リターン悪化）は方向としては**棄却**。
ただしゲートの目的はリターン予測ではなくボラ回避であり、こちらは機能した（下表）。

## 所見・次アクション

### 所見

1. **G13（スキューz>1.5 OR IV5日変化z>1.5 で半減）が最良**。リターンをほぼ落とさず
   （16.2→16.0%）、ボラ -2.9pt・MDD -31.8→-23.4% と純粋なリスク削減として機能。
   前半/後半の両方でSharpe改善しており、レジーム依存（教訓: 曜日効果の罠）の兆候なし。
2. **既存型の価格ゲート（R60<-5%）はSharpeを悪化させる**（0.78→0.67）。下落を確認してから
   切るため底値圏でexpoを落とし、リバウンドを取り逃がす。IVゲートはトリガが短命
   （z-scoreは数日で減衰）なので復帰が速く、この欠点がない。これが本質的な差。
3. **ターム逆転(G2)は単体では発火が長すぎて**（expo 0.79）リターンを削りすぎる。不採用。
4. ICが全て正であることから、逆に「恐怖ピーク後のロング」（atm_z/vrp Q5の fwd20 +2.4〜2.9%）
   という**リバウンド・エントリー戦略**の種にもなる。

### 限界・注意点

- ゲート発火日のリターン差は日次ボラの構造（高IV期=高ボラ・平均リターン横ばい）による
  もので、Sharpe改善 +0.12 はt検定的に圧倒的な差ではない。実弾はバスケット適用で判断。
- G13の閾値1.5は事前固定だが、G13という組み合わせ自体はG2の結果を見て事後選択
  （G1/G3単体でも改善は同方向なので頑健性はある）。
- JQuantsオプションデータのT+1夕方着ラグは shift(2) で織り込み済み。
