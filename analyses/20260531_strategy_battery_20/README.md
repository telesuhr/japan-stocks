### 有望候補2本 (要深掘り検証)
- **#18 増配ドリフト**: 配当予想の上方修正 → 20日で市場超過+146bps、勝率55%、IS/OOS一貫。
  決算イベント系 (我々の唯一の生存領域) の新軸。**ただし開示イベント自体に+90bps程度の
  正バイアス疑い (#17で上方/下方とも+90bps) → 「増配 vs 据置/減配」の対照群で増分を確認すべき**。
- **#19 FX→輸出株リード**: 前日USDJPY変動 → 翌日輸出株 (予測ρ0.144 > 同時ρ0.069)。
  オーバーナイトFX (米セッション) が翌日寄りに遅延反映。**大幅な円安/円高翌日に輸出株を
  寄り買い/売りするタイミング戦略として、コスト込み・銘柄拡張・IS/OOSで深掘り余地**。
