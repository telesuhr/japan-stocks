# V6スコア 50銘柄 クロスセクショナル L/S 検証

## 分析の目的・仮説

前研究 [`20260531_v6score_comprehensive`](../20260531_v6score_comprehensive/) で
`r20_adj` (ボラ調整モメンタム) が最強因子と判明したが、22銘柄では L/S 各サイド3銘柄しかなく
統計パワーが不足していた。

**仮説**: auKabu PORTFOLIO_ALL の50銘柄に拡張し、各サイド8銘柄でL/Sを組成すれば、
クロスセクショナルアルファがより明確になり、IS期間でも有意なエッジが確認できる。

検証スコア:
| スコア | 定義 |
|---|---|
| V4 | M + T + 0.5·S (現行ダッシュボード) |
| V6a | r20_adj (ボラ調整モメンタム単独, 連続値) |

## 解釈・示唆

1. **ボラ正規化が決定的**: 生のモメンタム `r20`/`M` はIS期間のクロスセクションで負のICだが、ボラで割った `r20_adj` はIS=0.28・OOS=7.90と正に転じる。半導体・非鉄など高ボラ銘柄が混在するユニバースでは、ボラ調整なしのモメンタムは「単に動きが大きい銘柄」を選んでしまう。

2. **長期トレンド(d75)の補完効果**: V6a (r20_adj単独) → V6b (+0.5·d75) で全期間Sharpe 4.17→4.65に改善。短期モメンタムと長期トレンドの組み合わせが頑健。

3. **L/Sで市場β除去後もアルファが残る**: IS(2022急落相場)でもL/S Sharpe=2.64・t=3.68。Long-onlyの弱さ(前研究)は相場環境βで、クロスセクショナルなアルファは別途存在することが確定。

4. **50銘柄化の効果**: 22銘柄→50銘柄で各サイド3→8銘柄。t値が大幅に上昇(全期間t=10.06)し、結論の信頼性が向上。

## 限界・注意点

- 日次1/20均等配分の累積は「オーバーラップ保有の擬似シミュレーション」。実際の建玉管理・約定コスト・空売り調達コストは未反映。
