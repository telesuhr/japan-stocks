# 台湾外国人フロー → 翌日 日本半導体 リードラグ検証

## 目的・仮説（教訓5: 検証前に仮説を固定）

**仮説**: 日本の半導体を売買しているのと同じグローバル外国人投資家が、台湾(TSMC等)でも動いている。
台湾は「銘柄別×投資家種別の日次売買(T86)」を**当日大引け後(14:30 JST)に公表**しており、これは
**日本の翌営業日が始まる前**に判明する。したがって **台湾の外国人ネット買い(日 t) は、日本半導体の
超過リターン(日 t+1) を正に先行予測する** のではないか。

**反証仮説 / 交絡(教訓1・3)**: 台湾フローも日本半導体も、共通の世界的半導体センチメント
(夜間の SOX/NVDA) に同時反応しているだけかもしれない。その場合、台湾フローは **SOX の翌朝寄り** を
代理しているだけで、SOX を制御すると独自の予測力は消えるはず。→ **SOX オーバーナイトを必ず制御する**。

## 手法

- **タイミング(ルックアヘッド排除)**: 日本 day D は **寄り(adj_open)で建て・引け(adj_close)で手仕舞い**(日中・オーバーナイト無し)。
  シグナルは **tw_date < D の最新の台湾フロー**(台湾 D-1 大引けは JST 14:30 で日本 D 寄り前に既知)。`merge_asof` で休場ズレを吸収。
- **超過リターン**: 半導体バスケット(等加重)の寄→引 − TOPIX の寄→引 = 市場中立リターン。
- **シグナル**: TSMC 外国人ネットの 60日 z-score(主)、半導体バスケット z 平均(頑健性)。
- **検証**:
  1. 単変量: z五分位ごとの翌日超過の平均、相関。
  2. 多変量 OLS: `excess[D] ~ TSMC_z + SOX_overnight[D] + excess[D-1]`(SOXとモメンタムを制御して独自寄与を見る)。
  3. 戦略: z 上位ターシル時に 中立ロング(バスケット−TOPIX)を寄→引。**コスト往復10bp込み(教訓2)**。
  4. **IS(2023-2024) / OOS(2025-2026) 分割**で頑健性確認。

## 結果（主要指標）

サンプル: **n=805日 (2023-02-27〜2026-06-12)**。

**① 単変量: 仮説どおり単調**
| TSMC z 五分位 | 1(売り) | 2 | 3 | 4 | 5(買い) |
|---|---|---|---|---|---|
| 翌日 半導体超過(bp, 寄→引) | **−4.9** | +2.5 | +3.8 | +13.9 | **+13.4** |

Q5−Q1 = **+18.3bp**、corr(z, excess)=0.050。台湾で外国人が売った翌日は日本半導体が市場をアンダー、買った翌日はアウトパフォーム。

**② OLS（交絡制御＝最重要・教訓1）** `excess[D] ~ TSMC_z + SOX_overnight + excess[D-1]`
| 説明変数 | 係数(bp) | t値 |
|---|---|---|
| **TSMC_z** | **+11.6** | **2.63** |
| SOX_overnight | −1252 | −6.46 |
| excess[D-1] | −1061 | −3.06 |
| const | +9.7 | 2.22 |

R²=0.073。**SOXオーバーナイトを制御しても TSMC_z は有意に正(t=2.6)** → 台湾フローは「SOXの代理」ではなく**独自の先行情報**を持つ。反証仮説を棄却。
（SOXが負＝SOX高の翌朝は日本半導体が寄りで織り込み済→寄→引でフェード。過去の[SOX+3%業種スクリーン](../20260612_sox_up_sector_screen/)・[ギャップ集約]知見と整合）。

## 所見・次アクション

- **統計的には本物**: SOX・モメンタムを制御しても台湾外国人フローは翌日日本半導体を有意に先行予測(t=2.6)。「同じグローバル外国人が台湾→日本を同方向に動かす」仮説を支持。**教訓1(同時反応)を正面から制御した上で生き残った**点が価値。
- **ただし収益化はレジーム依存（要注意）**: IS(2023-24)はnetマイナス、OOS(2025-26)はSharpe1.80と強い。**OOS>ISは過学習ではない**が、エッジが**直近のAI半導体相場に集中**しており全天候ではない。現レジームの持続が前提。
- **ベースラインの含意**: 日本半導体は寄→引で恒常的にフェード(−4.3bp/日)＝「寄りで買われ引けで垂れる」。台湾買い越しシグナルはこのフェードを反転させる日を選別している。
- **次アクション**:
  1. OOS集中の原因切り分け — 2025〜の半導体ボラ上昇/出来高で説明されるか(エッジの源泉がボラなら縮小しうる)。
  2. シグナル改良 — TSMC単体でなく半導体バスケットz平均(`basket_z`)、value換算、連続ポジション(∝z)で頑健性。
  3. 韓国KRX(Samsung/Hynix=メモリ)を足して台湾(ロジック/ファウンドリ)と直交させると説明力が上がるか(要 KRX credential)。
  4. 個別銘柄差 — メモリ(SUMCO/信越)とSPE(東エレ/レーザーテック)で台湾フロー感応度が違うか。

**判定: ⭐⭐（統計的に有意・SOX制御後も生存。ただし収益はOOS/直近レジーム集中で全天候ではない）**
