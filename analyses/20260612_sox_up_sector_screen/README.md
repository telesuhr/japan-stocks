# SOX大幅高の翌日、寄ってから取れる業種はあるか（探索的スクリーニング）

## 目的
昨晩SOX+7.9%。半導体は寄りギャップで取り切られると判明済（[sox_surge](../20260612_sox_surge_jp_nextday/)）。
では「こんな日に寄ってから買って上がりやすい業種」が他にあるか、17業種を横断スクリーニング。
**注意: これは仮説先行でなく探索＝データマイニング**。多重検定(17業種)にBonferroni α=0.05/17≈0.003で厳しく見る（教訓5）。

## データ
- `stocks_daily` プライム全銘柄を sector17 で日次等加重（gap=前夜→寄、intraday=寄→引）、2020-2026
- イベント: SOX+3%の翌日本営業日 143日

## 所見・次アクション

**結論: 「こんな日に寄ってから買って上がりやすい業種」は無い。全17業種で寄→引はマイナス（or ゼロ）。**

1. **Bonferroni有意(★)はゼロ**。p<0.05の「弱」シグナルは全て**マイナス側**（買ってはいけない側）。
   プラス方向に有意な業種は一つも無い＝探索しても「寄り後に取れる業種」は出てこない
2. **上げは例外なくギャップに集約**（全業種でギャップ+、寄→引-）。教訓1どおり、SOX高への反応は
   寄り付きで完結し、寄ってから買うのはどの業種でも遅い
3. 最も「マシ」なのは**電気・ガス(寄→引ほぼゼロ)**だが、これは「上がる」のではなく
   「SOX高に連れずギャップも小さい(+38bp)から寄り後も下げない」ディフェンシブ性。食品も同様の性質
4. 最も寄り後に崩れるのは**自動車(-22.6bp)・情報通信(SBG等-18bp)** = ギャップで大きく上げた分、利確に飲まれる
5. **実務的含意（今日6/12）**: ギャップアップで始まったら、どの業種でも「寄ってから買い増し」は不利。
   全面的に**寄り高は利確・サイズ削減の場**。消極的にディフェンシブ(電気ガス/食品)へ逃げる手はあるが
   「上がる」期待ではなく「連れ安しにくい」だけ。今週の一連の結論（日中タイミングにエッジ無し）と一貫
6. 限界: コスト未控除（控除すればさらに悪化）。「寄りで買って数日持つ」マルチデイは別検証（本件は当日寄→引）
