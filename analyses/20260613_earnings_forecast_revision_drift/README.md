# 業績予想の修正後ドリフト検証 (earnings forecast revision drift)

## 目的・仮説（教訓5: 検証前に仮説を固定）

**仮説**: 営業利益の**上方修正**(特に大幅)は、開示後 数日〜2週間の**正の超過リターン(ドリフト)** を生む。
下方修正(減益警告)は逆。PEAD(決算後ドリフト)のガイダンス改定版。新DBソース
`public.earnings_forecast_revisions`(2016〜18,224件)で初検証。

**反証/落とし穴(教訓1)**: リターンの大半は**開示直後のギャップ(取引不可)**に集約され、寄り後の
**取れるドリフトは小さい/消える**可能性(台湾フロー検証と同じ構造)。引け後開示(全体の83%)は翌日寄りが
最速エントリ＝**寄りギャップは取れない**。よって「ギャップ(取引不可)」と「寄り後ドリフト(取引可)」を必ず分解する。

## データ
| 用途 | テーブル | 期間 | 備考 |
|---|---|---|---|
| イベント | `public.earnings_forecast_revisions` | 2016-05〜2026-06 | direction(up/down)・`rev_op_pct`(営業利益改定率)・disc_time |
| 価格 | `public.stocks_daily` (adj_open/adj_close) | 同 | 分割調整済 |
| ベンチ | `index_daily` TOPIX(0000) | 同 | 市場超過 |

## 手法
- **タイミング(先読み排除・教訓1)**: エントリ=開示時刻の**次の寄り**。引け後(≥15:00,83%)/ザラ場→翌営業日寄り、寄り前(<09:00)→当日寄り。
- **分解**: ①announcementギャップ = 開示日終値→エントリ寄り(**取引不可**) ②ドリフト = エントリ寄り→+h日終値(**取引可**)。各々TOPIX超過。
- **層別**: 方向(up/down) × `rev_op_pct`の大きさ(ターシル) × 保有h(1/3/5/10日)。
- **戦略**: 大幅上方を中立ロング(株−TOPIX)・大幅下方を中立ショート、翌寄りエントリ5日保有。**コスト往復20bp込(教訓2: 中小型混在で高め)**。
- **IS(〜2022)/OOS(2023〜)** 分割。決算近接(PEAD重複)の影響もチェック。

## 所見・次アクション

**仮説は明確に棄却。「上方修正を買う」は10年一貫で負ける（IS/OOSとも）。**

1. **ニュースはギャップに集約（教訓1の典型・台湾検証と同型）**: Q5は寄りで**+501bp**ジャンプ＝織り込み完了。引け後開示83%なので、この寄りギャップは**取引不可**。取れる「寄り後ドリフト」は逆に**全分位マイナス**で、Q5(大幅上方)が**−90bp/5日**と最も垂れる＝好材料の寄り高をフェードする動き。

2. **⚠️ ベンチマーク交絡（重要・要追検証）**: 寄り後ドリフトが**全分位で一律マイナス**(中位Q3でも−47bp)なのは、**修正を出す銘柄が中小型に偏り、大型加重のTOPIXに対し恒常的にアンダー**しているサイズ要因の疑いが濃い。つまり水準のマイナスは「修正効果」でなく「size負け」。**相対(分位間)で見るべき**: 共通分を除くと Q5−Q1=**−42bp**＝大幅上方ほど(下方より)その後弱い、が残るシグナル。次アクション: ベンチをTOPIXでなく**サイズ/セクター/自己平均**に変えて再検証。

3. **唯一の弱い順方向**: 大幅下方(Q1)はその後も下げ続ける(ショートQ1 net+28bp・勝率56%・IS/OOS整合)。ただし個別株ショート(逆日歩・踏み上げ)＝実務リスク高く、エッジも小さい。

4. **「フェード」読み**: 結果を素直に使うなら「大幅上方修正の寄り高は戻り売り場(短期)」。ただし個別株ショートでありサイズ交絡も混じるため、**単独戦略にはしない**。フィルタ/サイジング材料止まり。

**次アクション**: (a) サイズ調整ベンチで再検証し交絡を除去 (b) 改定の"サプライズ"を事前コンセンサス乖離で定義 (c) PEAD分離。 → **(a)を `run_v2.py` で実施。下記。**

## v2: サイズ交絡を除去して再検証（`run_v2.py`）

ベンチを2つの size-clean 版に置換: **(A) 横断de-mean**(各イベントのドリフト−同月の全修正銘柄平均・100%カバー・先読み無) と **(B) TOPIXサイズ別指数**(Core30/Large70/Mid400/Small を銘柄サイズに合わせ控除・2016〜フル履歴)。

**五分位 寄り後5日 超過(bp)**
| Q | vs TOPIX(v1) | **de-mean(A)** | **サイズ指数(B)** |
|---|---|---|---|
| Q1 大幅下方 | −48 | −1 | −7 |
| Q2 | −27 | **+15** | **+16** |
| Q3 | −47 | +3 | −8 |
| Q4 | −51 | +7 | −18 |
| Q5 大幅上方 | −90 | **−27** | **−63** |

**結論（v1を更新）**:
1. **サイズ交絡は本物だった**: 一律 ~−50bp の水準は除去で消失(Q1/Q3 がほぼ0へ)。v1の「全分位マイナス」の大半は**修正銘柄が中小型偏重→大型加重TOPIXにsize負け**だった。v1の留保は正しかった。
2. **しかし"大幅上方の戻り"は生き残った**: Q5は de-mean **−27bp** / サイズ指数 **−63bp** と、**2つの独立ベンチ＋IS/OOS**で一貫して**サイズ同類をアンダー**。**逆U字**(Q2小幅上方 +15bp が最良 → Q5大幅上方が反転)＝**最大級の上方修正ほど寄り高を作りすぎて戻す**(overshoot reversal)。経済的にも素直。
3. **素直な「上方ロング」はどのベンチでも負け**(LS net: de-mean−33 / サイズ−48、IS/OOS整合)。方向が逆だから。
4. **取れる形は反張り**: 大幅上方(Q5)をフェード(ショート) or **Q2ロング×Q5ショート**のスプレッド。グロスで de-mean+42bp / サイズ+79bp(5日)。2レグ往復~40bp控除で **netはサイズ基準で+39bp程度**まで。ただし**好材料銘柄の個別株ショート=踏み上げ/逆日歩リスク**、サイズ分類は現在snapshot流用(軽い先読み)。

**判定: △（v1の⚠️から更新。"買いの"ドリフトは無い=ニュースはギャップ完了で確定。一方サイズ調整で**「最大級の上方修正は寄り後に戻す」overshoot-reversalが2ベンチ＋IS/OOSで頑健に出現**。台湾より再現性は高いが、個別株ショート前提＋net edge控えめで単独実戦は要注意=フィルタ/反張り材料として有望）**

**次アクション**: (a) Q2×Q5スプレッドの実装可能性(借株・サイズ指数ヘッジ)を精査 (b) Q5内をボラ/時価総額で層別(過小型を除けば踏み上げ回避＆edge残るか) (c) "サプライズ"をコンセンサス乖離で定義し直す。
