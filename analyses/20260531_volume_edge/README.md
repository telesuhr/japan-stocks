# 出来高(volume)エッジ探索

## 分析の目的

「出来高にエッジはないか」の探索検証。出来高は単体アルファより条件変数になりがちだが、
未検証の角度 (出来高ショック・大商い方向・Amihud非流動性・出来高枯れ) をクロスセクションで確認。

## データ・手法

- ユニバース: 流動性上位500銘柄、stocks_daily、2021〜 / IS-OOS 2024-01
- 翌日リターンは市場(TOPIX)超過。日次クロスセクションIC + 上位/下位10% L/S
- コスト往復20bps

## 主要発見 (すべてエッジなし)

### A. 出来高ショック (vol/20日平均) → 翌日 L/S
| 期間 | IC | L/S gross/日 | Sharpe |
|---|---|---|---|
| 全期間 | +0.0006 | +0.3bps | 0.08 |
| IS | +0.0048 | +2.2bps | 0.70 |
| OOS | -0.0052 | -2.4bps | -0.54 |

→ **IC≈0、IS/OOS符号反転 = 安定エッジなし**。

### B. 大商い(shock≥2)の陽線/陰線 → 翌日市場超過
- 陽線後 -17.6bps / 陰線後 -17.8bps (方向問わず ~-18bps、勝率44-46%)
- IS/OOS一貫だが**方向性なし**。コスト後消失。
- (注: 翌日 open→close vs TOPIX close→close の計測ミスマッチによる一律バイアスを含む)

### C. Amihud非流動性 (|ret|/売買代金) → 翌日 L/S
| 期間 | IC | Sharpe |
|---|---|---|
| 全期間 | -0.0115 | 0.13 |
| IS | -0.0113 | -0.42 |
| OOS | -0.0118 | 0.61 |

→ 弱い逆符号 (流動性プレミアムと逆)、L/S net負。**エッジなし**。

### D. 出来高枯れ (shock<0.7) → 翌日
-8.1bps (勝率45.7%)。エッジなし。

### E. 出来高ショック五分位別 翌日市場超過
Q0 -8.5 / Q1 -6.1 / Q2 -5.1 / Q3 -6.2 / Q4 -9.9 bps。
→ **非単調・全分位マイナス (一律バイアス)。横断スプレッドなし**。

## 解釈

- 出来高ショック・非流動性・出来高枯れ いずれも単体ではクロスセクショナル・アルファを持たない
  (IC≈0、IS/OOS符号反転)。
- 全分位が一様に~-7bps の負バイアスは、翌日 open→close (株) vs close→close (指数) の
  計測ミスマッチによるもの。横断差 (IC/L/S) は相殺されるので「エッジなし」の結論は頑健。
- **出来高は条件変数**: 単体では効かないが、価格方向・需給・イベントと組み合わせて初めて効く。
  既存 bank_absorption (出来高≥1.5×平均 + 陰線 + 売買代金≥10億) が好例。

## 限界・注意点

- 市場中立を close→close 指数で近似 (open→close 指数が無いため)。絶対水準に一律バイアス。
- 大型500銘柄中心。中小型はボラ・出来高効果が異なる可能性。
- 翌日1日のみ評価。より長い保有での出来高効果は別途。

## 結論

**標準的な出来高単体エッジは無い ⛔**。IC≈0でIS/OOS符号反転、Amihud逆符号。
出来高はあくまで条件変数 (フィルター) であり、他シグナルとの組み合わせで価値が出る。
投資部門別フロー (柱3) と合わせ、**「周知の単純集計データ」に残存アルファは無い**を再確認。
