# 中長期・現物向け 割安株スクリーン（2026-08-14基準）

## 目的・仮説

「足元で現物で買うべき割安銘柄（中長期視点）」への回答を、印象論でなくDBから再現可能な形で出す。

|---|---|
| `20260719_pbr_below1_market_wide` | PBR<1は対市場 **+4.3%/年 (t=2.25)**。東証の資本コスト要請後に効果拡大 |
| `20260729_value_rotation_laggards` | 足元は割安>割高のローテーション局面 |
| `20260615_regional_bank_value_rate_hike` | **質(ROE)オーバーレイ**がバリュートラップを回避する |

事前仮説:

| ID | 仮説 | 棄却条件 |
|----|------|----------|
| H1 | 割安(低PBR)優位は2026年8月時点でも継続している | PIT形成→前向きリターンで Q1−Q5 が過半でマイナス |
| H2 | PBR≤1・低PER・高利回りに **質(ROE)＋増益＋赤字なし** を重ねると、単なる「安いだけ」の集団と区別できる母集団が数十銘柄規模で残る | 通過0銘柄、または通過銘柄が全て特定1業種 |

## データ

- `public.stocks_daily` 2025-07-01〜2026-08-14（最終営業日）。close / adj_close / turnover_value。
- `public.fin_summary`（`doc_type LIKE '%FinancialStatements%'`）2019-01〜。最新開示の中央値経過日数 **10日**
  ＝2026年4-6月期(1Q)がほぼ全銘柄に反映済み。
- `symbol_master`（市場区分・33業種）。対象 **3,927銘柄**。
- ローテーション検証（H1）は `stocks_daily` 2024-10〜、PIT PBRを毎月末に再構成。

## 手法

### スクリーン以前に潰した4つの計算バグ（ここが本体）

1. **BPSはFY開示待ちにしない** — payloadの `BPS` キーは四半期開示では空。
   `BPS = 自己資本 / (ShOutFY − TrShFY)` で四半期ごとに更新する。
2. **`Eq`（純資産合計）を自己資本と読み替えない** ← 最重要。`Eq` は**非支配株主持分を含む**ため、
   そのまま使うとPBRが系統的に過小になる。株主帰属分は **`TA × EqAR`（自己資本比率）**。
   検算: いすゞ7202 は Eq基準 **0.93** → 自己資本基準 **1.03**（外部公表値1.08と整合するのは後者）。
   この修正でスクリーン通過は 15→14銘柄、いすゞ・ダイセル・サカタインクスが脱落した。
3. **株式分割の補正** — 開示時点と現在の `adj_close/close` 比 `k` で1株当たり値を換算
   （BPS/EPS/DPSは ÷k、株数は ×k）。これを飛ばすと分割銘柄のPERが人為的に半分になる。
4. **PER/ROE/利回りは会社予想ベース** — `FEPS` / `FNP` / `FDivAnn`。実績PERで組むと
   すでに織り込み済みの過去利益で並べることになる。

### 抽出条件

| 層 | 条件 |
|---|---|
| 母集団 | プライム・スタンダード / ADV(60日) ≥ 2億円 / 時価総額 ≥ 300億円 / 最新開示 ≤ 120日 |
| 割安 | PBR ≤ 1.0 かつ 予想PER ≤ 13 かつ 予想配当利回り ≥ 3.0% |
| 質 | 予想ROE ≥ 8% / 過去5期に最終赤字ゼロ / FY実績が3期以上ある |
| 罠除け | 予想増益 ≥ 0 / 3ヶ月リターン ≥ −20% / 予想純利益が過去5期平均の 0.7〜2.5倍 / 配当性向 10〜90% |
| 財務 | 自己資本比率 ≥ 40%（金融はこの基準を外し ROE ≥ 7% で別枠） |

診断列として **純利益/営業利益（予想）** を出す。通常0.6〜0.75。**1.0超は特別利益・税効果・持分法などで
純利益が一過性に膨らんでいる疑い**＝表面PERが実力より低く出るため、通過しても別扱いにする。

## 所見・示唆

**1. 個別に注意が要る3銘柄（通過はしたが素直に買えない）**

- **ＴＳＩHD 3608** — 予想利回り5.5%は魅力だが、2027/2期予想は営業利益75億に対し**純利益77億**。
  純利益の増益率+103%は繰延税金資産等の一過性要因を含む可能性が高く、**実力PERは9.6より高い**。
- **日本化学工業 4092** — 純利/営利 **1.61**、1年で株価+160%、ADV22億に対し時価総額482億
  （1日で時価総額の4.6%が回転＝テーマ物色で投機化）。「割安だから放置されている」銘柄ではない。
- **日本新薬 4516** — 数字は最も綺麗（PER8.1・ROE10.3・自己資本比率85.6%）だが、**安さの理由が明確**。
  2026/3期は純利益−26.3%、2027/3期も営業利益−15.4%予想。加えて新薬候補へのFDAの慎重姿勢で
  1日−17%の急落があり年初来安値。**バリューではなくパイプライン再評価の賭け**として扱うべき。

**2. 素直な「割安×質」の中核**（純利/営利が正常域・増益・財務健全）

比較的クセが少ないのは **トヨタ紡織(3116)・稲畑産業(8098)・新日本建設(1879)・愛三工業(7283)・
三菱総合研究所(3636)**、金融では **芙蓉総合リース(8424)**。特に新日本建設は
**予想ROE12.9%・自己資本比率74.4%・予想PER7.7** と質と割安が両立している唯一の銘柄。

**3. 分散の注意**: 輸送用機器2社（トヨタ紡織・愛三工業）はいずれもトヨタ系サプライヤーで
**共通因子が強く分散にならない**（教訓3と同型）。どちらか一方に絞るのが筋。

## 限界・注意点

- **これはスクリーンの出力であって投資助言ではない**。定量条件を満たす母集団を機械的に抽出しただけで、
  事業内容・競争環境・経営陣・訴訟/規制リスクといった定性面は一切見ていない。実際に買う前に
  最低限、各社の直近決算短信と中期経営計画には目を通すこと。
- 会社予想ベース＝**経営陣のバイアス**が入る。日本企業の期初予想は保守的に出る傾向があるが、
  逆に達成困難な予想を出す会社もある。
- 財務は最新開示（中央値10日前）だが、株価は2026-08-14終値。数日の乖離がある。
- ADV 2億円以上とはいえ、日本カーバイド(316億)・エスケーエレクトロニクス(350億)・
  日本化学工業(482億)は小型で、**まとまった金額を入れると自分で値を動かす**。
- PBR<1の+4.3%/年は**分位ポートフォリオ全体の平均**。個別14銘柄がその期待値を持つ保証はない。
  この母集団の性質を取りに行くなら**まとめて等金額で持つ**のが元の検証と整合する。
