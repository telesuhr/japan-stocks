# SOX大幅高の翌日本営業日 — 「寄ってからロング」は間に合うか

## 目的・仮説

昨晩(米国2026-06-11)に **SOX +7.9%** の急反発。ユーザーの問い:
「この上げは本物で、今日の日本時間に**改めてロングを作っていい**か」。

つまり知りたいのは「米国高 → 日本株上昇」という同時方向ではなく、
**寄りを見てから（あるいは寄りで）ロングを建てて、引けまでに取れるエッジが残っているか**。
SUMMARY.md の既存知見「SOX+2%→半導体翌日ギャップ は健在だが**日中リターン(寄→引)には非適用**」を
今回のデータで定量検証する。

**仮説（検証前に固定。教訓5）:**

- H1 **ギャップで取られる**: SOX大幅高の翌日本営業日、半導体・日経は **寄りギャップ(前日引け→寄り)がプラス**。
  米国高はオーバーナイトで織り込まれる
- H2 **日中(寄→引)はエッジなし or マイナス**: 寄ってからロングを建てても引けまでに取れない
  （寄りで織り込み済み、むしろ利確売り）= **ユーザーの問いへの直接の答え**
- H3 **閾値が大きいほどギャップ大・日中の反転大**: +7.9%のような極端な日はオーバーシュートの巻き戻しが出やすい
- 教訓1: 「米国高→日本高」の同日相関は同時反応であって、寄り後の予測力とは別物

## データ

- `macro.daily_ohlcv` .SOX（米国半導体指数、2020-01〜）
- `stocks_daily` 日経ETF 1321(13210) + 半導体7銘柄
  （東エレク80350/アドテスト68570/ディスコ61460/レーザー69200/TDK67620/フジクラ58030/キオクシア285A0）
- open=寄り・close=大引け。SOXの日付Dに対し JP の翌営業日(date>D の最小)を対応付け
- イベント閾値: SOX日次 +3% / +5%（N=146 / 34）

## 手法

- ギャップ(bp) = JP open / 前日JP close - 1
- 日中(bp) = JP close / JP open - 1 ← **寄り成行ロング→引け成行手仕舞いの素のリターン**
- フル(bp) = JP close / 前日JP close - 1
- コスト: 寄り成行+引け成行で往復 4bps を日中リターンから控除
- 無条件ベースライン（全営業日）と比較して**超過分**を見る（教訓1: 単独の符号でなく条件付き超過）
- 期間前半/後半で頑健性、閾値感応度

## 所見・次アクション

**結論: 「今日、寄ってから改めてロングを作る」は過去データ上マイナス期待値。4仮説とも支持。**

1. **H1支持（ギャップで取り切られる）**: SOX大幅高の翌日本営業日、上げは寄りギャップに集約。
   半導体は+215bp（+5%翌日は+352bp）と無条件(+11bp)を圧倒的に超過。米国高はオーバーナイトで織り込み済み
2. **H2支持（寄→引はマイナス）= 問いへの直接の答え**: 寄ってから引けまでは日経-12bp・半導体-26bp、
   コスト後-16〜-30bp、勝率50%未満。**寄りで買うと平均的に負ける**
3. **H3支持（極端ほど巻き戻し大）**: SOX+5%翌日（=昨晩の+7.9%が属する側）の半導体日中は
   **-80bp・t=-2.11で有意なマイナス**。極端高の翌日ほど寄り後の利確・巻き戻しが強い
4. 教訓1の典型: 「米国高→日本高」は真だが、それは**前夜に起きる同時反応**。寄り後の予測力ではない

**実務的含意（今日6/12の行動）:**
- 昨晩のSOX+7.9%を「ロングで取る」なら、それは**前日の日本引けで仕込むべきもので、もう手遅れ**
- 今日が寄り高で始まるなら、新規ロングを建てる場面ではなく、**むしろ既存ロング（SBG等）を
  寄り高で軽くする好機**（昨日来の「戻りでサイズを落とす」方針と完全に一致）
- 今日はメジャーSQで需給が特殊。寄りの価格形成が歪む可能性があり、なおさら寄り新規は不利
- 限界: 本検証は「寄り成行→引け成行」の当日完結。「寄りで買って数日持つ」マルチデイ・ドリフトは
  別物（既存のSOX+2%→翌日ギャップ戦略は前日引け仕込みで健在）。当日寄り後エントリーに限った結論
