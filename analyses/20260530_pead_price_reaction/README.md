# 決算PEAD（価格反応モメンタム）クロスセクション検証

> **結論: PEAD（決算後の継続ドリフト）は方向としては存在するが、L/Sのエッジは弱い。**
> 決算で大きく買われた銘柄は翌々日以降も続伸、売られた銘柄は続落する（概ね単調なモメンタム）。
> 「勝者Long/敗者Short」のベータ中立L/Sが20営業日保有・コスト20bps後で **年率Sharpe ~0.38
> （IS 0.37 / OOS 0.40で一貫、コスト後プラス）**。今セッションで初めてコスト後・ベータ中立・
> IS/OOS一貫を満たしたが、Sharpe0.4は昇格基準2.0に遠い。方向の存在確認に留まる。
>
> ※注記: 初版で「リバーサル・Sharpe1.0」と誤記。分位テーブルを誤読し方向を逆に取った。
>   一次データ(quantile_drift.csv)では明確にモメンタム継続。本版で訂正（下記「検証の教訓」）。

## 1. 着想（6連敗の総括から）

教訓「全員が同時に見るシグナル(テクニカル/指数イベント)は裁定で消える。取れるのは情報・反応に
時間差があるもの」。決算は全銘柄同時に出ず消化に時間差→ドリフトが残りうる。既存昇格
earnings_pead はファンダ・サプライズ＋大窓Long(+7%)に限定。本分析は未開拓の
**全決算の価格反応を10分位に分けたクロスセクションを、構造的ベータ中立L/Sで検証**。

## 2. データ・手法

- `fin_summary`(決算日 disc_date / 時刻 disc_time, 83%引け後) + `stocks_daily`(adj) + TOPIX
- 2021-2026、流動性≥10億円。PEAD観測 **11,305件・1,015銘柄・1,022エントリー日**
- 反応日 react: 引け後発表は翌営業日、引け前は当日。car0 = react日 open→close TOPIX超過
- **エントリー = react翌営業日(react+1)寄り**（反応を観測してから入る＝look-ahead無し）
- ドリフト = react+1 open → react+1+H 引け のTOPIX超過(bps)、H=5/10/20
- 各エントリー日で car0 を10分位 → 翌H日ドリフトをクロスセクションL/S(q9−q0)
- コスト往復20bps、IS(2021-2023)/OOS(2024-2026)

## 3. 主要発見

### 分位別ドリフト（コスト前bps, q0=決算で最も下落 → q9=最も上昇）

| 分位 | car0 | d20ドリフト |
|---|---:|---:|
| q0（暴落） | −6.5% | **−57.6** |
| q2 | −2.2% | −55.8 |
| q5 | +0.3% | +48.6 |
| q8 | +3.5% | +32.2 |
| q9（急騰） | +7.1% | **+68.8** |

→ **概ね単調なモメンタム継続（PEAD）**。決算で買われた株は続伸、売られた株は続落。
   ノイズはあるが両端(q0/q9)が明確に符号一致。

### PEAD L/S（q9 Long − q0 Short, コスト20bps後）

| 保有 | グロスbps | ネットbps | 勝率 | Sharpe | IS | OOS |
|---|---:|---:|---:|---:|---:|---:|
| 5日 | +37 | +17 | 49% | 0.17 | −0.31 | 0.55 |
| 10日 | +70 | +50 | 56% | 0.38 | −0.09 | 0.77 |
| **20日** | **+130** | **+110** | 53% | **0.38** | 0.37 | 0.40 |

→ **20日保有が最も安定**（IS 0.37 / OOS 0.40 で一貫）。短期(5/10日)はISでマイナスとブレる。

## 4. 解釈・示唆

1. **PEADは実在するがクロスセクションL/Sでは弱い**: 方向（勝者継続）は明確だが、20日Sharpe0.4。
   既存 earnings_pead（大窓+7%Long, Sharpe2.19）が強いのは「極端なサプライズに絞る」から。
   **全決算を平等に10分位化すると薄まる**＝エッジはサプライズの大きさに集中している。
2. **既存戦略との整合**: 両方ともモメンタム方向で、PEADの存在を独立に再確認。本分析の価値は
   「方向の頑健性確認」と「弱さの定量化（絞らないと薄い）」。
3. **過去の平均回帰(#3)との違い**: あちらはベータ中立化で消えたが、本シグナルは
   決算イベント条件付きL/Sでコスト後・IS/OOS一貫プラスを維持。条件付きが効いている。
4. **昇格基準には遠い**: Sharpe0.4。改良（極端分位への集中＝既存pead方向）が要る。

## 5. 限界・注意点

- **日次クロスセクションが薄い**: 1日あたり中央値3銘柄。10分位化に≥20銘柄/日を要求するため、
  実際にL/Sを測れたのは決算ピーク期の204日のみ。決算が集中する5月/8月/11月/2月に偏る。
- **observation数11,305は決算総数10万件の一部**: 流動性ゲート＋分位成立日のみ。中小型は除外。
- **react+1寄りエントリー**: 当日初動〜翌寄りのギャップ（最も濃いPEAD部分）は捨てている。
  既存 earnings_pead が引け(react当日15:30)から取るのと対照的。初動を取ればもっと強い可能性。
- **多重カウント**: 20日保有で同一銘柄の決算が重なる期間の重複は未補正。
- **検証の教訓（初版の誤り）**: 初版は /tmp実験のQ0-Q9（符号逆）の負値を見てパニックし
  「リバーサル」と誤記した。一次データの分位テーブル(q0=−58bps, q9=+69bps)を最初に
  確認すれば明白にモメンタムだった。**集計のL/S方向は、必ず分位テーブルの両端の符号で
  人間が確認してからラベルを付ける**。

## 6. 次のアクション候補

- ✅ **極端サプライズへの集中**: 全分位でなく q9（上位）/q0（下位）の極端帯だけ、かつ
  car0の絶対値が大きいものに絞る → 既存 earnings_pead の強さ(Sharpe2.19)に寄せられるか
- ✅ **初動(react当日)を含めて取る**: react当日引け→react+1〜のフルPEADを測り、捨てている
  初動ドリフトを回収。エントリー執行（引成）の現実性込みで
- 🔍 ファンダ・サプライズ(OP実績 vs 会社予想FOP)と価格反応car0の一致でフィルタ
- 🔍 セクター中立化、多重カウント補正後の実ポートフォリオSharpe
- 既存 earnings_pead/pre_earnings_drift の拡張（除外セクター見直し・保有期間最適化）の方が
  昇格には近道かもしれない（本分析は「絞れば効く」ことを示した）
