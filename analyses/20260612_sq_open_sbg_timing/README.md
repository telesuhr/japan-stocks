# メジャーSQの寄り方向 と SBGを寄りで売るか待つか

## 目的・仮説
今日(2026-06-12)はメジャーSQ。問い: ①SQの寄りは下になりやすいか ②SBGを寄りで売るべきか待つべきか。
- 仮説A: メジャーSQの寄りに一貫した下方バイアスは無い（SQ値は清算値で需給は事後）
- 仮説B: ギャップUP日のSBGは寄り後に巻き戻す（SOX検証と整合）→寄り直後は弱含む

## データ
- `stocks_daily` 1321: メジャーSQ日39回(2016-2026, 3/6/9/12月) vs 通常金曜 vs 全営業日
- `stocks_intraday` SBG(99840) 2024-05〜2026-06: 寄り基準の時刻別累積リターン（全日 / ギャップUP+1%日）

## 結果

### (A) メジャーSQ日の寄り方向 (bp)
| | n | 寄りギャップ | 寄→引 | ギャップ<0率 |
|---|---|---|---|---|
| メジャーSQ日 | 39 | **-19.9 (t=-0.84)** | +10.6 | 46% |
| 通常の金曜 | 462 | +1.3 | -0.7 | 42% |
| 全営業日 | 2463 | +5.8 (t=2.83) | +0.6 | 44% |

→ SQ日は全営業日平均(+5.8bp)より寄りが約25bp弱含む**弱い傾向**はあるが**統計的に非有意(t=-0.84)**。
  ギャップ<0率46%もコイントス。むしろSQ日は寄→引が+10.6bpとプラス気味。

### (B) SBG 寄り基準の時刻別累積リターン (bp)
| 時刻 | ギャップUP日(n=184) | 全日(n=510) |
|---|---|---|
| 09:30 | **-10.1** | -3.8 |
| 10:00 | -2.2 | +1.1 |
| 11:30 | +5.5 | +5.4 |
| 13:30 | +7.2 | +3.1 |
| 15:00 | +14.8 | +7.8 |

→ ギャップUP日は**寄り直後(09:30)に-10bp弱含み**、その後じわ戻して引けが最高(+14.8bp)。
  ただしSBG日次std≈690bp・n=184でSE≈30-40bp。**+14.8bpはt<0.5でノイズ＝有意なタイミングエッジは無い**。
  唯一の弱シグナルは「寄り直後の利確売りで09:30が弱い」点（SOX検証の極端高翌日マイナスと整合）。

## 所見・次アクション

**結論: SQ寄りの下げバイアスも、SBGの寄り後タイミングも、賭けられるほどの有意性は無い。**

1. **①への答え**: メジャーSQの寄りは「全日平均より弱含む弱い傾向」止まりで非有意。
   「SQだから寄りで売ると損」という強い根拠は無い（ギャップ<0は46%でコイントス）
2. **②への答え**: SBGを寄りで売るか待つかで取れる差は、SBGの日次±数%の前では誤差レベル。
   強いて言えば**寄り直後09:30の最初の投げ（-10bp）だけは避ける**価値がある程度。
   どうしても気にするなら寄り成行のド寄せを避け、前場後半〜引けにかけて**分割**で出す
3. **本質**: 「いつ売るか」を最適化してもSBGのボラの前では無意味。決めるべきは**「いつ」でなく「どれだけ売るか」**。
   日中タイミングにエッジが無いのは、今週の検証(寄り前/板/前場/SOX)すべてと一貫
4. 限界: SBG分足は2024-05〜でメジャーSQ実数は8回のみ→(B)は全日/ギャップUP日で代用。SQ当日固有の挙動は別
