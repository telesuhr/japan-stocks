# eneos_vwap_trend 劣化診断 — 「CRITICAL」の正体は壊れでなくコスト前提

## 背景

足元エッジ確認 (本フォルダ README) と OOSモニタで eneos_vwap_trend が
Sharpe -1.27 (90日) / -1.21 (180日) と「CRITICAL」判定。当初「シグナル崩壊・停止すべき」と
判断しかけたが、原因を分解した結果 **訂正** する。

## 診断 (ENEOS 50200, 9:30 VWAP乖離≥±50bps → 同方向 → 引け決済)

### 期間×サイド (gross、cost 4bps控除後)
- IS(〜25-08): L n14 +9.4bps / S n25 +11.1bps / 計 +10.5bps
- OOS(25-08〜): L n34 +19.1bps / S n31 +12.3bps / 計 +15.8bps
→ **両期間・両サイドでプラス。シグナルは反転していない**。

### 月次平均ret (bps)

→ 概ねプラス。悪いのは 2025-12 と 2026-05 の2ヶ月のみ (ボラ起因のドローダウン)。

## 結論 (訂正)

**eneos_vwap_trend は「壊れて」いない**。
- シグナルは反転しておらず gross は全窓プラス (Sharpe 1.25〜2.92)。
- OOSモニタの「CRITICAL -1.27」は **モニタの一律往復20bpsコスト前提**によるアーティファクト。
  戦略本来の 4bps では net +6.8bps (90日) とプラス。
- ただし **直近の薄さは事実**: 90/180日の gross ~10.8bps は 365日の 21.9bps より薄く、
  現実的コスト ~10bps では **ほぼ収支トントン**。最も薄利・コスト感度が高い戦略。

## アクション (訂正後)

1. **停止/archiveはしない** (シグナル健在)。だが **最低確信度・要注意**として扱う。
2. **ENEOS実取引コストの実測** (intraday単一銘柄の往復スプレッド+手数料)。
   10bps超なら recent は実質トントン → サイズ縮小 or 閾値引き上げ検討。
3. **OOSモニタのコスト前提を戦略別に修正** (一律20bpsは流動性高い単一銘柄intradayには過大。
   これが eneos を不当に CRITICAL に見せた。他のintraday戦略=vwap_morning も同様の影響を受けうる)。

## メタ教訓

OOSモニタの一律往復20bpsコストは、保有期間・銘柄流動性・売買形態が異なる戦略を
同一基準で評価するため、**薄利・高頻度・intraday戦略を不当に低く見せる**。
戦略別コスト前提が必要。判定は「絶対gross Sharpe + 現実的コストでの net」を見るべき。
