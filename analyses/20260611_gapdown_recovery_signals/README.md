# ギャップダウン日の日中回復を「寄り前変数」で分類できるか

## 目的・仮説

「前夜の米国株が悪く、日本も下げるだろうと思った日に、日中切り返して上げる」
（例: 2026-06-11 寄り後-1,800円→引け+38円）パターンを、**寄り前(9:00 JST以前)に
観測可能な変数**で見極められるかを検証する。

**仮説（検証前に固定。グリッドサーチはしない＝教訓5）:**

- H1 **ADR乖離**: 日本株ADRバスケットの前夜リターンが米SOX指数より底堅い日ほど、日中回復しやすい
  （米国市場参加者が既に「日本株は売られすぎ」と判定している）
- H2 **ギャップの深さ**: ギャップが深いほど日中の戻り（寄り→引け）が大きい（過剰反応の巻き戻し）
- H4 **過熱解消度**: 前日終値の25日線乖離が低い（過熱が解消済み）ほど日中回復しやすい
- H5 **円の方向**: 前夜にドル円が円安方向なら日中回復しやすい（輸出株の押し目買い）

※ H3（悪材料の性質: 米固有 vs 系統的）は jp-news の蓄積が浅く今回は対象外（将来拡張）。

## データ

| 項目 | ソース | 期間 |
|---|---|---|
| 日経225 OHLC | `index_daily` code=`NK225D` | 2020-01〜2026-06-04（ADR制約で2020起点） |
| ADR 17銘柄 | `macro.daily_ohlcv` ADR_* | 2020-01〜 |
| SOX指数 | `macro.daily_ohlcv` .SOX | 同上 |
| ドル円 | `macro.daily_ohlcv` JPY= | 同上 |

- イベント: 日経の寄りギャップ（open / 前日close - 1）≦ **-1.0%**
- アウトカム: 寄り→引けリターン（oc_ret）。`oc_ret > 0` を「日中回復」と定義
- 特徴量はすべて日本の寄り前に確定する値のみ（直近の米営業日データ）

## 手法

- 各特徴量を中央値で2分割し、回復率と平均oc_retの差を t 検定
- 特徴量と oc_ret の Spearman 相関
- 複合スコア（有利側に出た特徴量の本数 0〜4）でのバケット比較
- 頑健性: 前半（2020〜2022）/ 後半（2023〜2026）分割

## 結果（主要指標）

- イベント: **189件**（2020-02-25〜2026-06-11、ETF1321のギャップ≦-1%）
- 無条件ベースライン: **回復率52.9% / 平均oc_ret +0.07%** — ギャップダウン日の日中はほぼコイントス
- 指数プロキシ注意: `index_daily` の NK225D/F は夜間込み先物でギャップが消える（std 0.26%）
  ため、**現物寄り板を持つETF1321**（std 1.12%）を使用

| 仮説 | 有利側-不利側 oc_ret差 | t | Spearman ρ | 判定 |
|---|---|---|---|---|
| H1 ADR乖離（底堅い） | -0.00% | -0.03 | -0.05 | **棄却** |
| H2 ギャップ深い | +0.04% | -0.25 | +0.08 | **棄却** |
| H4 過熱解消済み | +0.12% | -0.67 | +0.08 | 棄却（方向は合うが有意性なし） |
| H5 円安方向 | -0.14% | -0.80 | -0.10 | **棄却**（前半は有意に逆방향 t=-2.33、後半+で符号反転） |

- 複合スコア(0〜4)も単調性なし（score0: +0.23% / score4: -0.01%）、score≥3 vs ≤1 の差 +0.05% (p=0.79)

## 所見・次アクション

**結論: 「下げるはずの日に上げる」を寄り前の価格系変数で見極めることはできなかった。4仮説とも棄却。**

1. 最重要の発見はベースライン自体: ギャップダウン≦-1%の日の寄り→引けは**平均+0.07%・回復率53%のコイントス**。
   寄り板オークションが前夜の悪材料をほぼ正しく織り込んでおり、「織り込みすぎ/不足」を
   ADR・ギャップ深さ・過熱度・円方向では事前に判別できない
2. H5（円安→回復）は2020-22年に**有意に逆**（円安なのに戻らない）→ 23年以降は正。
   為替と株の関係がレジームで反転する（円安=リスクオン期 vs 円安=金利差・インフレ警戒期）ことの再確認
3. 2026-06-11のような日を「事前に」当てる方法は本検証の範囲では存在しない。
   残された道は (a) **寄り後の早期判定**（寄り30分の戻り方→後場継続。ただし
   [20260604_zenba_kouba](../20260604_zenba_kouba/) で勝率50%以下と既知）、
   (b) **悪材料の性質**（米個別企業固有 vs 系統的、H3）を jp-news 蓄積後に検証、
   (c) 予測を諦めポジションサイズで対処する
4. 教訓1の好例: 「今日は戻った→理由は押し目買い意欲」という事後説明は常に可能だが、
   事前に観測可能な変数には乗っていなかった
