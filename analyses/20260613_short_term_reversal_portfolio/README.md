# 20日短期リバーサル 分散ポートフォリオ検証 (short-term reversal portfolio)

## 目的・仮説（教訓5: 検証前に仮説を固定）

**仮説**: 直近20日の勝者はその後アンダー、敗者はアウト（短期リバーサル）。市場中立で
**敗者ロング/勝者ショート**のバスケットを組むと正のリターン。
前回の機関ショート検証の副産物（`prior_mom20` が t=−25.3＝今セッション最強の統計効果）を正面から、
**ちゃんとした分散ポートフォリオbacktest**（per-event平均でなく日次P&L）で検証。

**最大の論点（教訓2）**: リバーサルは**高回転**。グロスで効いても**コストで死ぬ**のが定番。
ターンオーバー×コストを必ず引いて**ネットSharpe**で判定する。素直に効くか＝市場効率性の試金石。

## 手法
- **ユニバース(survivorship回避)**: 各リバランスで**トレイル60日売買代金 上位500**を時変選定（生存バイアス無）。流動性を絞り bid-ask bounce由来の偽リバーサルを抑制。
- **シグナル**: トレイル20日リターン（**直近1日skip**でマイクロストラクチャ除去）。
- **構築**: 週次リバランス、**ボトム5分位ロング / トップ5分位ショート**、等加重・ドル中立、5日保有。
- **コスト**: リバランス毎の実ターンオーバー × 片側10bp を必ず控除。**0/5/10/15/20bpで感応度**も出す。
- **評価**: 日次P&L → 年率/Sharpe/最大DD/年間回転率/**コスト後損益分岐bp**。**IS(〜2022)/OOS(2023〜)**。

## 結果（主要指標）

ユニバース1,200コード・2017-2026・週次・売買代金上位500・敗者ロング/勝者ショート・市場中立。

| | 年率 | Sharpe | 最大DD | 勝率 |
|---|---|---|---|---|
| **グロス** | **−1.95%** | **−0.11** | −50.6% | 49% |
| ネット(10bp/片側) | −5.81% | −0.31 | −70.0% | 48% |
| IS(〜2022) ネット | −1.39% | −0.08 | −41% | |
| OOS(2023〜) ネット | −13.4% | −0.68 | −62% | |

- 年間ターンオーバー≈37回、**損益分岐は片側−5.2bp**＝**正のコストでは黒字化不可能**（グロスで既に負け）。
- コスト感応度: 片側0/5/10/15/20bp で Sharpe −0.11/−0.21/−0.31/−0.42/−0.52（**0bpでも負け**）。

**流動性3層の裏取り（`verify_universe.py`・グロス）**
| 層 | グロス年率 | Sharpe |
|---|---|---|
| 超大型(1-300) | −3.2% | −0.16 |
| 大中型(401-700) | +0.2% | +0.01 |
| 中小型(701-1300) | −4.9% | −0.33 |

→ **どの層でもゼロ〜マイナス**。小型で強まりもしない＝「流動性層の話」ですらなく、取引可能なクロスセクション・リバーサルのエッジは**存在しない**。

## 所見・次アクション

**仮説棄却。取引可能な20日リバーサルは無い＝日本の流動株は1ヶ月horizonで効率的。**

1. **グロスで既に負け**: 敗者ロング/勝者ショートはどの流動性層でもゼロ〜マイナス。むしろ超大型/中小型では弱い**順張り（モメンタム継続）**寄り。コストで決定的にアウト（ネット−5.8%/年）。

2. **t=−25.3 の正体が判明（重要）**: 前回ショート分析で `prior_mom20` が t=−25.3 と出たのは、**(a) 空売り報告された選別ユニバース（高ボラ・小型寄り）で (b) サイズ調整した"残差"リターン**を測っていたため。**生のクロスセクション・ポートフォリオに直すとエッジは消える**。＝**巨大なt値 ≠ 取引可能なエッジ**。回帰の有意性は「選別標本×残差測定×大標本」の産物で、ドル中立バスケットの実損益とは別物だった。

3. **本セッションの総括的教訓**: 台湾フロー/業績修正/機関ショート/本リバーサルと、**4つの"強いシグナル"が全て、コスト込み・サイズ調整・取引可能ユニバースで詰めると蒸発**。日本の流動株はこれらのhorizonで概ね効率的。**収集したデータの価値は「厳密に棄却できる土俵を作った」こと**。

**判定: ✗（取引可能な20日リバーサルのエッジ無し・グロスから負け。t=-25.3は選別標本×残差×大標本の統計的産物で、ドル中立バスケットでは消失＝"有意≠取引可能"の教科書例）**

**次アクション**: (a) 残差(サイズ・セクター中立)リバーサルを**選別せず**広域で組めば残るか（ただし高回転でコスト壁は不変）(b) リバーサルでなく**1〜3日の超短期**ならイントラ的に別の話（板/ティック領域＝TechChart/auKabu側）(c) ここまでの4棄却を踏まえ、次は"効率的でない領域"（イベント・需給の非対称・板）に検証をシフト。
