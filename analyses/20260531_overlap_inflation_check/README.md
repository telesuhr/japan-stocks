# オーバーラップ過大評価は V4/V5 でも同じか

## 分析の目的

[`20260531_v6b_nonoverlap_cost`](../20260531_v6b_nonoverlap_cost/) で V6b の日次オーバーラップ
L/S Sharpe=4.65 が非重複だと 0.84 に激減した。これが **V6b固有の問題か**、それとも
**V4/V5を含む全スコア共通の年率換算アーティファクトか** を切り分ける。

## 仮説

保有H日のリターンを「日次サンプル」として √252 で年率化すると、
正しい √(252/H) に対し **√H 倍** 過大評価される (H=20 → √20≈4.47倍)。
→ V4/V5/V6 すべて同じ倍率で盛れているはず。

## 手法

- ユニバース50銘柄、Long-only、保有20日、同一サンプル
- (a) 日次オーバーラップ ×√252  vs  (b) 非重複20日(offset=0) ×√(252/20)
- V4 (M+T+0.5S≥2) / V5b (M+0.5S≥2) / V6b (r20_adj+0.5d75 上位30%)

## 主要発見

| スコア | (a)日次OL ×√252 | (b)非重複 ×√(252/20) | 比率(a/b) | √20理論 |
|---|---|---|---|---|
| V4 | 3.90 | **0.74** | 5.28 | 4.47 |
| V5b | 4.08 | **0.78** | 5.25 | 4.47 |
| V6b | 4.48 | **0.83** | 5.40 | 4.47 |

→ **3スコアとも非重複だと 0.7〜0.8 に収束。比率は全て約5.3で一致**
→ **過大評価は V6b 固有ではなく、全スコア共通の年率換算アーティファクト**

## 解釈

- 比率の主成分 √20≈4.47 は純粋な年率換算の誤り。日次サンプルの20日リターンを
  独立日次観測とみなして √252 を掛けると √20 倍盛れる。
- 残りの ×1.2 程度は、スコアが緩やかにしか動かず建玉が持続するため生じる
  追加の系列相関 (年率換算以外の非独立性)。全スコアで一様。
- **結論: V4/V5/V6 の「日次エントリーで高Sharpe」は全て同じ幻**。
  正しく測ると Long-only 非重複 Sharpe は 0.7〜0.8 (市場β込みでこの程度)。

## 過去分析への影響 (要訂正注記)

- [`20260531_v4score_daily_entry`](../20260531_v4score_daily_entry/) の日次 Sharpe (V4 4.48, V5b 5.77 等) は
  すべて √252 年率換算によるオーバーラップ過大評価。実力は ÷5前後。
- [`20260531_v6score_comprehensive`](../20260531_v6score_comprehensive/) の Long-only Sharpe も同様。
- いずれも「相対比較 (どのスコアが優れるか)」には使えるが、**絶対水準 (Sharpe2.0判定) には使えない**。

## 限界・注意点

- 非重複は offset=0 単一位相のみ → n少なくノイズあり (大きさの桁感の確認用)
- Long-only は市場βを含むため、純アルファはL/Sでさらに低い (v6b検証参照)

## 結論・教訓

**保有H日戦略のSharpeは必ず √(252/H) で年率化する、または非重複サンプルで測る。**
日次/週次エントリーのオーバーラップ系列に √252 を掛けると √H 倍盛れる。
昇格判定(Sharpe≥2.0)は絶対水準なので、この換算ミスは致命的 (4.5倍の過大評価で偽陽性)。
