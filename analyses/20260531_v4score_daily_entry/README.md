# V4/V5 スコア 日次エントリー検証

## 分析の目的

既存の backtest_v5.py は週次(金曜)エントリーで設計されている。
「毎営業日スコアを計算してエントリー」した場合に改善するか検証。

## データ概要

| 項目 | 値 |
|---|---|
| ユニバース | 22銘柄 (半導体14 + 非鉄金属8) |
| 評価期間 | 2021-01-01 〜 2026-05-31 |
| IS | 2021-01-01 〜 2023-12-31 |
| OOS | 2024-01-01 〜 2026-05-31 |
| サンプル | 26,253 (銘柄×評価日) |

## 主要発見

### A. 日次 vs 週次 Sharpe

| スコア | 頻度 | n | Sharpe |
|---|---|---|---|
| V4 (M+T+0.5S) | 日次 | 10469 | 4.48 |
| V4 (M+T+0.5S) | 週次(金) | 2110 | 4.36 |
| V5b (M+0.5S≥2) | 日次 | 6807 | 5.77 |
| V5b (M+0.5S≥2) | 週次(金) | 1395 | 5.34 |

→ **日次エントリーが週次を僅かに上回る (+0.12〜+0.43 Sharpe)**
→ エントリー機会が約5倍になる割にパフォーマンス差は小さい

### B. IS/OOS スプリット (日次)

| スコア | IS Sharpe | OOS Sharpe |
|---|---|---|
| V4 | 0.59 | 6.90 |
| V5a | 2.38 | 7.78 |
| V5b | 2.05 | 7.95 |

→ **IS(2021-2023) でSharpeが低い**: 2022年急落相場でモメンタムが機能しにくい
→ OOS (2024-2026) AI/半導体ブームで強くなる → 相場環境依存の可能性

### C. 曜日別効果 (V4)

| 曜日 | Sharpe |
|---|---|
| 月曜 | 4.66 |
| 火曜 | 4.58 |
| 水曜 | 4.55 |
| 木曜 | 4.27 |
| 金曜 | 4.36 |

→ **曜日差はほぼない** (最大差 0.39)。月曜が若干高いが誤差範囲

### D. スコア分布

- スコア-5付近でも +5.23% リターン → **スコアが市場βを拾っている可能性**
- 高スコア(4.5, 5.0)でリターン最大 (6.63%, 7.58%)
- スコア 0 付近が最低 (1.84%)

### E. スコア変化効果

スコア変化ゼロ (=維持) が最高 Sharpe=4.84 → 「持続するモメンタム」が本質

## 解釈

1. **日次 vs 週次**: 差が小さいことは「金曜リバランスに特別な優位性はない」を意味する
2. **IS弱さ**: V4/V5 の IS Sharpe が低い原因は 2022 年の急落相場。2023年は回復。
3. **スコア分布の逆説**: 低スコア(-5)でも高リターンは 2024-2026 の全面高が背景
