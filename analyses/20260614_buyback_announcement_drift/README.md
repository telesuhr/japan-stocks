# buyback_announcement_drift — 自社株買い「決定」発表後の超過リターン（予備検証）

## 目的・仮説（教訓5: 仮説先行）
日本株では自社株買い発表後に**正のドリフト**が残る（米市場より非効率）という既知アノマリがある。
DataFetcher で新設した TDnet リアルタイム・ポーラー（`poll_tdnet_realtime.py`）が拾う代表イベントの
一つが自社株買い決定。これが**取引可能な形（発表は引け後が多い→翌営業日寄りで買う）**で、かつ
**サイズ交絡を排除**しても超過リターンを生むかを問う。
（前回 earnings_forecast_revision の教訓: 中小型偏重イベントは素のTOPIX対比だとサイズ負けを誤認する）

## データ
- イベント: `public.tdnet_disclosures`（TDnet 31日分 = **2026-05-14〜06-12**、3月決算後の発表ピーク期）
  - title に「自己株式の取得」を含み、`結果|終了|状況|消却|報告|訂正|変更` を含まない = 取得"決定" → **66件**（価格マッチ59件）
- 価格: `public.stocks_daily` の `adj_open/adj_close`（分割調整済）
- ベンチ: TOPIXサイズ別指数 `index_daily`（0040 Core30 / 0041 Large70 / 0043 Mid400 / 0045 Small）
- サイズ: `symbol_master.scale_cat`

## 手法
- entry = 発表**翌営業日の寄り**（adj_open）。引け後開示が多く、最初に取引可能な価格。先読み無し。
- h∈{1,3,5,10}営業日 hold → adj_close。`abnormal = 個別リターン − 同区間の所属サイズ指数リターン`
- 往復コスト = 片道5bp×2 = 10bp（寄り買い＋引け売り、long-only）を控除した net も併記
- 全体／大型(Core30-Mid400)／小型(Small・非TOPIX) で層別。t値・勝率。

- **有意なものは無し（全horizon |t|<1.3）**。素リターンは全面マイナス＝5-6月の小型株安。サイズ調整で超過は中立〜やや+に。
- 長め（+10d）で超過 **+172bp（t=1.3, net+162bp）** と既知アノマリと整合の"気配"。だが n=47・単一窓では**ノイズと区別不能**。
- 短期（+1〜3d）はむしろマイナス寄り。即時の織り込みは速く、初動を翌寄りで買っても取れない。

## 所見・次アクション
- **結論: 予備的には inconclusive（取引判断には不十分）**。方向は弱く正・既知アノマリと矛盾しないが、
  - n≈47-59、**単一窓・単一レジーム**（2026年5-6月のみ）、+20d は先行データ不足で測れず、IS/OOS 不能。
  - 「統計的に弱い気配 ≠ 取引可能」（本基盤の繰り返しの教訓）。**今この証拠で自社株買いを買う根拠は無い**。
- **本筋＝前進蓄積**: TDnet保持は31日のため過去を遡れない。`poll_tdnet_realtime.py` が日次で発表を保存し始めた
  ので、**3-6ヶ月で300-600件・複数レジーム**が貯まる。その時に本検証（サイズ調整・コスト込み・IS/OOS）を行う。
- 改善案（本番時）: ①取得**規模**（発行株数÷時価総額＝バイバック・イールド）で層別＝大型プログラムほど効く仮説、
  ②ToSTNeT-3即時買付 vs 市場買付の区別、③決算同時発表か単独かの分離。規模はPDF/XBRLからの定量化が要る（未実装）。
