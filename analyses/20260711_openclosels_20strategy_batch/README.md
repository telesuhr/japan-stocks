# 寄り・引けL/S戦略 20戦略一括バックテスト

## 目的・仮説

日中監視不要で運用できるL/S戦略を体系的に発掘する。
5グループ・20戦略を3パスで検証し、採用候補を絞り込む。

**事前仮説（検証前宣言）**
- H1: ギャップ（前日比大幅乖離）は同日中にリバーサルする
- H2: 月次横断モメンタムは日本株でも有効（Jegadeesh-Titman系）
- H3: オーバーナイトリターンと日中リターンには正の相関がある（ON-LS仮説）

## データ

| 項目 | 内容 |
|------|------|
| テーブル | `stocks_daily` (adj_close, open, close, turnover_value) |
| ユニバース | ADV≥5億円 × 上場維持 → 838銘柄 |
| 期間 | 2016-05-10〜2026-06-30 |
| IS/OOS | 〜2021-06-30 / 2021-07-01〜 |
| コスト | L+S往復 8bps/ラウンドトリップ |

## 手法

- クロスセクション L/S: 上位20%ロング、下位20%ショート (等加重)
- 戦略グループ: A=同日, B=オーバーナイト, C=週次, D=月次, E/F=カレンダー/連続日
- スクリプト: `OpenCloseLS/strategies/candidates/batch_backtest_v1.py`

## 所見・採用提案

### ⭐⭐⭐ 採用推奨: A1_GapReversal_2.5pct

**戦略概要:**
- シグナル: 当日寄付きが前日終値比 >2.5% ギャップした銘柄
- ロング: ギャップダウン銘柄 (上位20%) → 当日寄成エントリー
- ショート: ギャップアップ銘柄 (下位20%) → 当日寄成エントリー  
- 決済: 当日引成 (同日L/S完結)
- 頻度: 週2〜3回のシグナル発生 (年間133日)
- **IS Sh=+1.55, OOS Sh=+1.97, OOS p<0.001**
- **実行可能: 寄り付き値でギャップ確認 → 寄成注文で同時執行**

### ⭐⭐ 採用推奨: D3_6MMomentum

**戦略概要:**
- シグナル: 前月末時点の過去6ヶ月リターン上位/下位20%
- ロング: 上位20%銘柄バスケット → 月初第1営業日寄成
- ショート: 下位20%銘柄バスケット → 月初第1営業日寄成
- 決済: 翌月末引成
- **IS Sh=+0.71, OOS Sh=+0.71 (IS/OOS同水準 = 最安定)**
- 注意: 既存バスケットとの相関 +0.63 → 分散効果は限定的

### ⚠️ 要注意・見送り: A4_VolGapDn

- IS全体=+0.31 だが 2018/2019 年は Sh=-4〜-5
- 2023以降OOS優秀 (Sh=+4〜+9) → レジーム変化の疑い
- t検定 p=0.013 → 有意だが分散大
- → データ蓄積後に再検討

## 追加検証: 前日引け情報 → 翌寄成エントリーは可能か? (2026-07-11)

**問題意識**: GapRevを実務で運用する際、前日夜に銘柄を確定してデルタバランスを
取れると理想的。前日引けまでの情報だけでシグナルを作れないか?

**結論: 不可。GapRevのエッジは「当日中」でしか生きない。**

| 前日引け確定シグナル → 翌寄成 | IS | OOS | 判定 |
|---|---|---|---|
| P1 前日CC反転→翌OC | -0.04 | -0.70 | ✗ |
| P3 前日終値位置反転→翌OC | -1.28 | -1.66 | ✗ |
| P5b 前日5%変動反転→翌OC | -0.86 | +1.21 | ✗ IS/OOS不整合(レジーム) |
| P6b 前日日中モメンタム→翌OC | -3.09 | -3.46 | ✗ |
| **本家 GapRev(当日寄→引)** | **+1.55** | **+1.97** | ✅ |
| **GapRev を翌日OCに持ち越し** | **-2.47** | **-0.61** | ✗ **崩壊** |

**2つの決定的事実**:
1. **エッジの源泉がオーバーナイトのギャップそのもの** — ギャップは寄り付いて初めて
   確定するので前日引け時点には存在しない情報。前日引け情報では代替不能。
2. **エッジは当日中で完結** — GapRevシグナルを翌日に持ち越すと +1.81→-1.31 に崩壊。
   反発は寄り〜引けの1日で終わり、翌日には続かない。

**実務含意**: 前日夜の仕込みは不可。寄り付き値を見てから当日中に完結させる必要がある。
- 案①: 寄り指値を前日夜に仕込む(自動フィルタ) → 約定後デルタ確認 → 先物ヘッジ
- 案②: 9:01-9:05に約定・ギャップ確認 → 両サイド量を揃えて成行 (デルタ制御しやすい)
- 「寄り+N分ディレイ」でのエッジ減衰は分足データで別途検証の余地あり

スクリプト: `OpenCloseLS/strategies/candidates/prevclose_signal_v1.py`
