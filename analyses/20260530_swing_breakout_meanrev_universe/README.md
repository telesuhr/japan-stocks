# 全ユニバース日足スイング: ブレイクアウト & 平均回帰 エッジ検証

> **結論: 平均回帰（zスコア25日）には統計的に実在するエッジ（t=8.2, N=6.6万）。ただしper-trade
> 年率Sharpe近似は0.3で昇格基準2.0には遠い。ブレイクアウトは全ユニバースではエッジほぼ無し。
> 次段は「分散バスケット化でポートフォリオSharpeがどこまで上がるか」。**

## 1. 目的・仮説

過去のブレイク/平均回帰分析（ORB各種・gap fade・VWAP mean-revert）は**特定セクター・少数銘柄
限定**だった。今回は **セクター不問・全上場・流動性フィルタ付き** で横断的にエッジの有無を測る。

**仮説**: 流動性のある全銘柄に対し、ブレイクアウト（順張り）か平均回帰（逆張り）の
どちらかに、コスト後でも残る日足スイングのエッジがあるか。

## 2. データ・手法

- **データ**: `public.stocks_daily`（分割調整済 adj_*, 2016/05〜2026/05, PostgreSQL@Omen）
- **ユニバース**: 普通株のみ（プライム/スタンダード/グロース、ETF/REIT除外）。
  **流動性フィルタ: トレーリング60営業日平均売買代金 ≥ 10億円/日**（前日時点, look-ahead無し）
  → 検証対象 2,654銘柄、トレード総数 230万件
- **戦略ファミリー**:
  - `BO_donchian`: close が過去 L 日 high を上抜け → 翌日寄成 Long、H 日保有（L=20,60）
  - `MR_zscore`: (close−MA_L)/std_L ≤ −2.0 → 翌日寄成 Long、H 日保有（L=10,25）
  - `MR_rsi`: RSI(L) ≤ 30 → 翌日寄成 Long、H 日保有（L=10,25）
  - 保有 H = 3 / 5 / 10 営業日
- **エントリー**: シグナル翌日の寄成（look-ahead無し）。ストップ高の日は除外
- **コスト**: 往復10bps（寄成/引成の成行スリッページ込みで保守的）
- **過学習チェック**: IS(2016-2021) / OOS(2022-2026) 分割

## 4. 解釈・示唆

1. **平均回帰には実在エッジ**: MR_zscore L25 は t=8.2（N=6.6万）で偶然ではあり得ない有意性。
   勝率51%・平均+20bps と小さいが、**符号は明確にプラスでIS/OOS両方プラス**。
2. **長い窓(25日)＞短い窓(10日)**: L25のzスコアが安定。L10は反応が早すぎてノイズを拾う。
3. **ブレイクアウトは全ユニバースで機能しない**: 順張りはコスト後マイナス。
   過去のORB分析（個別では一部機能）と合わせると「ブレイクは銘柄選別が前提」と分かる。
4. **smokeの罠を回避できた**: 流動性トップ50・直近2年では MR_zscore が年率Sharpe1.1と
   華々しかったが、全ユニバース10年では0.29に縮小。**大型・直近バイアスを排除した本来の姿**。
5. **per-trade Sharpeの低さは「分散前」の数字**: 本検証の年率Sharpe近似は1ポジション逐次保有
   前提。実際は毎日数十銘柄が平均回帰シグナルを出すため、**等加重バスケットで分散すれば
   ポートフォリオSharpeは大幅に上がりうる**。t=8の有意なエッジが分散でどこまで化けるかが本丸。

## 5. 限界・注意点

- **年率Sharpe近似が粗い**: per-trade Sharpe × √(245/hold) の単純近似。日次ポートフォリオの
  実Sharpe（同時保有・相関込み）は未算出。**次段で日次PnL系列を組んで正しく測る必要**。
- **流動性10億円ゲートでも約定インパクト未考慮**: 寄成で大量に入れると実効コストは10bps超。
- **Long onlyのみ**: 市場ベータが乗っている。TOPIX超過リターンでのエッジ分離は未実施。
- **昇格基準未達**: 現状の単純なper-trade評価では Sharpe 2.0 に届かない。分散ポートフォリオ化と
  ベータ中立化を経て初めて昇格を議論できる。
- これは**エッジの所在確認**であり採用判定ではない。

## 6. 次のアクション候補

- ✅ **MR_zscore L25 を日次等加重バスケットでポートフォリオ化** → 同時保有・相関込みの実Sharpe算出。
  これが本検証の自然な続き（per-tradeエッジは確認済み、あとは分散効果の測定）。
- 🔍 ベータ中立化（TOPIX超過 or マーケットヘッジ）で純粋なαを分離
- 🔍 流動性ゲートを30億円に上げて執行現実性とエッジのトレードオフを見る
- ❌ ブレイクアウト単純版は全ユニバースでは追わない（個別銘柄選別が要る別問題）
- 既存の昇格戦略 oversold_ma25_reversal（_archive入り）との関係整理：本検証の MR は
  より頑健（全ユニバース・10年）なので、再昇格の足がかりになりうる
