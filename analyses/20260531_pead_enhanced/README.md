# PEAD拡張検証: セクター中立化・サプライズフィルター

> **結論: PEAD Sharpe 0.38 もセクターモメンタムの幻。セクター中立化で全期間マイナスに転落。**
> 昇格基準(Sharpe≥2.0)には到達できず。価格反応ベースのクロスセクションPEADにはエッジ無し。

## 1. 目的

前段(20260530_pead_price_reaction)が示したSharpe 0.38を昇格基準2.0まで引き上げる試み。
3軸の改良を実施:
- **A 極端フィルター**: |car0|≥3%（大きい驚きに絞る）
- **B セクター中立化**: 同業種(TOPIX33)内でランク付け→L/S
- **C サプライズ一致**: OP実績 vs 前期FOP予想の符号がcar0と一致

## 2. データ

- ベース: `pead_obs.csv` (11,305件, 1,015銘柄, 2021-2026)
- セクター: `symbol_master.sector33_nm` (TOPIX33業種分類)
- サプライズ: `fin_summary.payload` の OP実績 vs 前期FOP予想ラグ差分
  - マッチ率 35.3%（fin_summaryの業績予想が無い決算回がある）

## 3. シナリオ別結果（20日保有, コスト20bps後）

## 4. 主要発見

### セクター中立化でエッジ消失（最重要）

シナリオCの結果が核心:
- **全期間Sharpe -0.24、IS -0.06、OOS -0.38で全てマイナス**
- セクターベータを除去すると、業種内では「決算で上がった株が続伸する」ではなく
  **「決算で上がった株は業種内では翌月むしろ小さく下げ、下げた株は小さく回復」**という
  **業種内ミーンリバージョン**の構造が見える

### ベースラインSharpe 0.38の解釈修正

前段で「IS/OOS一貫したPEAD」と評価したSharpe 0.38は:
- **セクターモメンタムの幻**だった可能性が高い
- 例: 決算期に半導体セクター全体が市場平均を超えてポジティブな場合、
  半導体決算株のcar0が高くなり、その後も業種ベータで続伸→L/Sがプラスに見える
- 業種内でランク付けするとこのセクターベータが消え、エッジも消える

### 極端フィルター（シナリオB）の限界

- |car0|≥3%でn_days=40日に激減→ IS期間11日しかなく統計的信頼性ゼロ
- OOS単体Sharpe 0.80は偶然の可能性が高い（t=1.23）

### サプライズフィルター（シナリオE）

- マッチ率35.3%でサンプルが500件以下に激減→ 統計パワー不足でEmpty

## 5. 解釈

第三弾（平均回帰 → ベータ中立化で全消）と完全に同じ構造:
- 表層: Sharpe 0.38の一貫したエッジ
- 実態: TOPIXの次に大きい「セクターβ」を取り込んだ見かけの利益

**決算イベントLongを「セクター内」に絞ると、好決算株は業種内では短期的に
平均回帰する(高値掴みの買い手が利確)傾向が見え、方向が逆転する。**

既存昇格済みの earnings_pead (Sharpe 2.19) が強い理由の再確認:
- あちらは「大窓+7%のLong-only + ファンダサプライズ」でセクター・規模の偏りを
  特定銘柄の極端なサプライズに絞ることで制御している
- 本分析のクロスセクションL/Sとは根本的に異なる設計

## 6. 結論

**第八弾: 価格反応PEADクロスセクションL/SはSharpe 0.38がセクターβの幻と判明。エッジ無し。**
