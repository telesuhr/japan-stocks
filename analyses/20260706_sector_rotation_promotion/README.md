# セクターローテーション MOM L3K3 昇格検証（cap-weight・33業種・下落耐性・バスケット相関）

## 目的・仮説

第三十二弾（`20260603_sector_rotation_17`）で発見したセクター・モメンタム
（trailing 3ヶ月上位3業種を月次保有、TOPIX超過Sharpe+1.49、ADV≥10億で2.09、9年連続プラス）を
**Layer 1（恒久エンジン・月次リバランス）への昇格候補として最終監査**する。

前回残した4つの疑いを潰す:

1. **cap-weight でも成立するか** — 等加重は業種内の中小型を過大評価する。実運用（大型中心・
   ETF近似）に近い時価総額加重で消えるなら「等加重の幻」であり昇格不可。
2. **33業種精密化で改善するか** — 17業種は半導体と家電、非鉄と鉄鋼が混ざる。33業種で
   純度を上げるとモメンタムが強まるか、それとも銘柄数減でノイズが勝つか。
3. **下落局面耐性** — long-only上位3業種集中はフルベータ。TOPIX下落月・下落レジームでの
   挙動と最大DDを実測（「見れない期間に大DDを食らわないか」が時間軸制約上の生命線）。
4. **既存バスケットとの相関** — 新戦略の価値は低相関寄与（第十九弾）。既存4戦略スリーブ
   （2024-11〜）との月次相関を実測。

## データ

- `stocks_daily`（月末 adj_close・close・月平均売買代金）× `symbol_master`
  （sector17_nm / sector33_nm、プライム・スタンダード・グロース）
- `index_daily` code='0000'（TOPIX）
- `fin_summary` FY実績の payload ShOutFY − TrShFY（自己株控除後株式数、disc_date as-of）→ 時価総額
- 既存バスケット: `../20260531_portfolio_daily_sharpe/sleeve_daily_returns.csv`
- 期間: 2016〜2026-06、月次非重複（√12年率化、オーバーラップの幻なし）。IS=〜2021-06 / OOS=2021-07〜

## 手法

- 業種月次リターン: 等加重（基準・前回再現）と cap-weight（前月末時価総額加重）の2系列
- MOM L3K3（17業種）・L3、K3/K5（33業種）、コスト片側10bps×入替率
- 下落耐性: TOPIX下落月の条件付きリターン・最大DD・回復月数・レジーム別（TOPIX trailing 12M 正/負）
- 相関: 月次絶対リターン vs 既存4スリーブ＋バスケット（共通期間 2024-11〜、短い点は限界として明記）

## 結果（主要指標）

全118ヶ月（2016-08〜2026-06）、コスト片側10bps×入替率、TOPIX超過、√12年率化（非重複）。

| 構成 | 全Sharpe | t | IS | OOS | 月bps |
|---|---|---|---|---|---|
| 17業種 等加重 MOM L3K3（前回再現） | **+1.50** | +4.71 | +1.52 | +1.48 | +111 |
| 17業種 等加重 ADV≥10億（前回のベスト） | **+2.07** | +6.50 | +3.03 | +1.51 | +164 |
| **17業種 cap-weight MOM L3K3** | **+0.09** | +0.27 | +0.26 | -0.01 | +6 |
| 17業種 cap-weight ADV≥10億 | -0.00 | -0.00 | +0.07 | -0.04 | -0 |
| 33業種 等加重 MOM L3K3 | +1.16 | +3.63 | +1.51 | +0.91 | +117 |
| 33業種 cap-weight MOM L3K3 | +0.09 | +0.29 | +0.28 | -0.02 | +9 |

**(1) cap-weight で完全消滅**: 時価総額加重（前月末cap、ShOutFY−TrShFY as-of）にすると
全構成で Sharpe ≈ 0。**「業種そのもの」のモメンタムは存在しない**。エッジの実体は
業種内の中小型銘柄の等加重効果（セクター条件付き中小型モメンタム）。セクターETFでの実装は不可。

**(2) 33業種精密化は改善しない**: 17業種 1.50 → 33業種 1.16。業種を細かくすると
業種あたり銘柄数が減りノイズ増。17業種が最適粒度。

**(3) 下落局面耐性なし（フルベータ確定）**:
- 絶対リターン: Sharpe+1.51、最大DD **-23.1%**（2020-03、回復8ヶ月）
- TOPIX下落39ヶ月: 戦略-220bps/月（TOPIX-327bpsより浅いが大負けは同じ）
- 弱気レジーム（TOPIX 12M-）: 絶対Sh **-0.82**、月-134bps ≒ TOPIXと同じ下げ方
- 最悪月: 2020-02 -16.5%、**2026-03 -10.7%（直近に発生済み）**

**(4) 既存バスケットとの相関（2024-11〜、19ヶ月と短い）**:
- 絶対リターン側: basket -0.08（ただしTOPIXと+0.83のフルベータ）
- TOPIX超過側: basket +0.28、lasertec +0.37 — 「ほぼ無相関」ではなく弱正相関

## 所見・次アクション

**昇格見送りを提案**。理由:
1. OOS Sharpe 1.51 で昇格基準 2.0 未達（IS 3.03 からの半減も継続確認）
2. long-onlyフルベータで下落無防備（-23% DD）。「相場を見られない」時間軸制約の
   Layer 1 に置くには最悪月-16%のテール
3. cap-weight消滅により「資金循環＝業種ローテーション」という当初仮説は誤り。
   正体は中小型の等加重モメンタムで、既検証のクロスセクションモメンタム族に近い
   （ボラ調整で改善した hi_voladj / r20_adj と同族の可能性）

**生き残った価値**:
- 等加重 ADV≥10億は全期間 Sharpe 2.07 (t6.5) で IS/OOS 両プラス。**TOPIXヘッジを付けて
  L/S 化（業種バスケット Long + TOPIX先物 Short）すれば下落耐性が作れる可能性** → BACKLOG #11
- 33業種 trailing-3m ランキングはダッシュボード補助表示として有用（発注根拠にはしない）

## 検証規律チェック

- 月次非重複×√12（オーバーラップの幻なし）/ コスト入替率連動 / 前月末cap（lookahead なし）
- IS/OOS: 2021-06 分割。TrShFY空文字はCASE+正規表現でガード
- 時価総額付与率94.7%（未付与はcap-weight系列から自然脱落）
