# 非鉄・電気機器（半導体）イントラデイ LS戦略探索

## 目的・仮説

直近6ヶ月（2026-01〜2026-06）の1分足データで「非鉄(3500)・電気機器(3650)」銘柄に
機能しているイントラデイL/S戦略を探索する。

**検証する仮説（教訓5: 仮説先行）**：
1. **ORB15**: 寄り後15分レンジのブレイク方向にロング/ショート → 引けイグジット
2. **ORB30**: 寄り後30分レンジのブレイク方向 → 引けイグジット
3. **Gap_Follow**: ギャップアップ→ロング / ギャップダウン→ショート（9:30エントリー）→引けイグジット
4. **Gap_Fade**: ギャップ逆張り（9:30エントリー）→引けイグジット
5. **AM_Momentum**: 前場（9:00〜11:30）の方向で後場（12:30〜）エントリー → 引けイグジット

**期待する非鉄・半導体の固有性**：
- ドル円・コモディティ連動が強いため、ギャップが強い方向性を持ちやすい仮説
- 半導体はSOX・NASDAQ連動で寄り方向が前日海外を反映しやすい

## データ

- テーブル: `public.stocks_intraday`（1分足、JQuants確定版）+ `public.stocks_daily`
- 期間: 2026-01-01〜2026-06-19（約120営業日）
- 銘柄: sector33 IN ('3500','3650') かつ平均売買代金≥5億円
- タイムゾーン: JST naive格納

## 手法

- 往復コスト: 4bps（片道2bps × 2）、スリッページ込みで8bps想定も別途計算
- エントリー/イグジット: 指定時刻のclose価格で成立と仮定
- リターン: signal × (exit_price / entry_price - 1) - cost
- 評価指標: 勝率、PF、SR（日次）、累積リターン（月次分解）

**出来高ビン別傾向（重要）**:
- 低出来高日 (<0.8x) → Gap_Fade が有効 (SR=0.11)
- 高出来高日 (>1.5x) → Gap_Fade は機能せず / EarlyVol_Fade・Vol_Follow が有効
- 正常日 → エッジ薄い

**板情報（aukabu）**: データ不足（2026-05-22〜で25日のみ）。Depth10 インバランスと同日リターンに弱い負の相関 (r=-0.198) あり。蓄積後に再検証要。
