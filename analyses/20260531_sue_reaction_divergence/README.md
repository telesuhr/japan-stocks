# SUE × 初動反応(car0) 乖離 → PEADドリフト検証

## 分析の目的

レポート柱2 (LLM-PEAD) の簡易版検証 (LLM不要)。レポートの主張:
「単体のSUE/LESはもはや効かないが、"高SUE × 低LES" の乖離局面でドリフトが出る」。
LES(テキストセンチメント)が無いため、初動の株価反応 car0 を LES の代理として検証する。

**仮説 (レポート)**: 業績は良い(高SUE)のに初動の値動きが鈍い/負(低car0=過小反応)
→ その後 d10/d20 で SUE方向(上)へドリフトする。

## データ・手法

| 項目 | 値 |
|---|---|
| 価格側 | `20260530_pead_price_reaction/pead_obs.csv` (car0=反応日TOPIX超過, d5/d10/d20先行bps) |
| 業績側 | fin_summary payload の OP(営業利益, 金融はOrdP/NP代替) を前年同期(同cur_per_type)比YoYで標準化 |
| SUE | 開示日ごとにクロスセクションz標準化したYoY成長率 |
| 結合 | (code,disc_date)のSUEを entry_date に as-of結合 (4日以内) |
| サンプル | 7,991 (SUE+price 両方あり) |
| コスト | 往復20bps |

## 主要発見

### A. 単体ファクターは効かない (レポート主張の追試 ✓)

| 因子 | d20とのρ | Q5-Q1 |
|---|---|---|
| SUE単体 | -0.007 (p=0.55, 非有意) | +20bps |
| car0単体 | +0.009 (p=0.41, 非有意) | +63bps |

→ **単体SUE/car0 ともに有意なドリフトなし**。レポートの「単体は裁定され尽くした」と整合。

### B. 2x2 квадрант (SUE高低 × car0高低) の d20 ドリフト — 核心

| 象限 | n | d20 |
|---|---|---|
| 高SUE×低car0 ★(レポート予測) | 2,131 | **-23bps** |
| 高SUE×高car0 | 1,864 | **+56bps** |
| 低SUE×低car0 | 2,088 | -32bps |
| 低SUE×高car0 | 1,908 | +9bps |

→ **レポートの「高SUE×低car0→上方ドリフト」は反証**。
逆に「業績◎ × 反応◎の一致」が最良(+56bps=古典的PEADモメンタム)、
「業績◎なのに反応が鈍い(低car0)」はむしろ下げる(-23bps)。

### C. 乖離 L/S (高SUE×低car0 Long / 低SUE×高car0 Short)

| 保有 | 期間 | gross | net(20bps) | Sharpe(net) |
|---|---|---|---|---|
| d20 | 全期間 | -27bps | -47bps | -0.08 |
| d20 | IS | -49bps | -69bps | -0.14 |
| d20 | OOS | +18bps | -2bps | +0.03 |

Long-only(高SUE×低car0): d20 全期間 **-73bps** (t=-1.8, 勝率43%)。

→ **乖離戦略は負ける**。レポートの想定と逆方向。

## 解釈 (なぜ反証されたか)

**car0(株価反応)は LES(テキストセンチメント)の代理にならない**。
- car0 = 市場の判定そのもの。将来リターンと直交せず、既にニュースを織り込んでいる。
- LES = テキストのトーン。数値(SUE)と直交する独立情報、というのがレポートの肝。
- 代理置換は仮説の本質を壊す。

結果 (業績◎なのに反応が鈍い→下げる) は経済的に妥当: **市場が正しく懐疑的だった**ケース。
良い数値に強い反応が伴う(一致)ときだけドリフトが続く=古典的PEAD (既存earnings_peadが捕捉済み)。

## 限界・注意点

- car0をLES代理にした時点でレポートの仮説とは別物の検証になっている (本質的限界)。
- SUEは会社予想でなく前年同期比YoYのFosterモデル型 (アナリストコンセンサス不在のため)。
- 結合サンプル7,991 (pead_obs 11,305の一部)。SUE算出に前年同期データ必須で減少。
- d20リターンの絶対値は小さく t値も弱い (SUEシグナル自体が弱い)。

## 結論

**レポート柱2bの car0代理版は反証 ⛔**。
1. 単体SUE/car0は効かない (レポート主張は正しい)。
2. だが「高SUE×低car0→ドリフト」は成立せず、逆に下げる。car0はLESの代理にならない。
3. 唯一プラスは「高SUE×高car0(一致)」+56bps=古典的PEADで既存earnings_peadが捕捉済み。

**真に柱2を検証するには TDnetテキスト + LLMセンチメント(LES)が必要**。
価格反応でのショートカットは不可と判明。LESの直交性こそがレポートの核心であり、
それ無しでは検証できない。
