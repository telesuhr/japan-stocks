# 非鉄・半導体 押し目エントリー・スクリーニング (2026-07-21時点)

## 目的・仮説
足元の急落（TOPIX 7/6→7/17 -4.5%、SOX 7/10→7/17 約-10%）で非鉄・半導体が大きく下げた。
検証済みの反発エッジに整合する「売られ過ぎ×流動性」銘柄を洗い出し、押し目エントリー候補を提示する。

**依拠する検証済みエッジ**（SUMMARY.md）:
- `oversold_rsi_reversal`（RSI<30反発, OOS Sh+6.15, 商社/自動車/半導体で検証）
- `semi_gapdn`（半導体下窓を寄成Long→当日引成, net Sh1.8）
- `lasertec_ma25_support`（MA25サポート反発, 低頻度高精度）

これは「エッジ」ではなく検証済みエッジに沿った**現時点のスクリーニング**。単独の売買シグナルではない。

## データ
- `stocks_daily`（2026-02-01〜2026-07-17）。半導体=検証済みsemi_gapdn 11銘柄、非鉄=`sector33_nm='非鉄金属'`。
- 流動性フィルタ ADV(20日)≥10億円。
- **分割ロバスト**: 直近40営業日で\|日次\|>35%の段差を分割とみなし以降のみで指標算出
  （古河電工/住友電工はMA25窓が5〜6週前の分割を跨ぎ、生adj_closeが -65〜-85% と誤表示。補正で解消）。

RSI(14)・25日MA乖離・20日高値DD・5/20日リターン・ADV を算出し、RSI昇順（売られ過ぎ順）で並べる。

## 解釈・示唆

**2つの異なる駆動要因が混在**（同一視は禁物）:
1. **AI-データセンター系**（古河電工・フジクラ・住友電工・SWCC・イビデン）: 昨年来のバブル的上昇の
   モメンタム巻き戻し。RSIは最も売られ過ぎだが、テーマ相互相関が高く分散にならない＋
   モメンタム剥落局面は落ちるナイフになりやすい。
2. **銅/材料系**（三井金属・JX金属・住友金属鉱山・三菱マテリアル）: 広範なリスクオフでの下げ。
   **COMEX銅(HGc1, yfinance, 7/20まで鮮度良好)は 6.06→6.33 と回復し6.3台で底堅く**、株の-20〜40%急落と
   明確に乖離。**銅ファンダ堅調×株だけ急落＝ミーンリバージョンの追い風**で、テーマ巻き戻し系より
   確信度が高い。当基盤の検証済みエッジ「LME銅→非鉄」のLME専用フィードは更新停止だが、
   COMEX銅は高相関の代替として利用可（あくまで代理指標である点は留意）。

**市場コンテキスト（今週の相場観）**: 高ボラ・週前半は下値バイアス、半導体は米ビッグテック決算が
振り子。RSI売られ過ぎは必要条件だが、決算前の中途で全力は落ちるナイフ。**寄りの弱さ確認・
分割エントリー・半導体はsemi_gapdn流の当日引け完結**が整合的。

## 限界・注意点
- 純粋なテクニカル・スクリーニングで、個別の売買バックテストは未実施（反発エッジは既存検証を援用）。
- 銅マクロ確認はCOMEX銅(HGc1)で代替可（LME専用フィードは更新停止・COMEXは7/20まで鮮度良好）。銅は代理指標。
