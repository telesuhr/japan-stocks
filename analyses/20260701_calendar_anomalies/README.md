# calendar_anomalies — カレンダーアノマリー一括検証

## 目的・仮説

月末月初・曜日・月別・GW・SQ・お盆等のカレンダーアノマリーが日本株50銘柄（aukabu対象）に存在するか網羅的に検証する。
あわせて 7/4 米国独立記念日シーズナリティの日本株への波及を確認する。

## データ

- `public.stocks_daily` (JQuants): 50銘柄 × 2010〜2026年  
- `public.stocks_intraday`: 50銘柄 × 2024-11〜（分足・板寄せ）
- `macro.daily_ohlcv`: ESc1(S&P500先物) 2005〜2026年
- ベースライン: 日本株 +0.114%/日（2010〜2026年平均）

## 手法

- 各アノマリーに月位置・曜日・月・暦日フラグを付与
- 銘柄平均リターンの平均(日次)を指標として集計
- 外れ値除外: |day_ret| > 20% をカット

## 結果

### A. 月末月初（BOM/EOM）効果

| 月位置 | 平均% | 勝率 | close_loc中央値 | 特記 |
|---|---|---|---|---|
| EOM-1（月末前日） | +0.193% | 51.8% | 0.595 | 高値引け傾向・先回り |
| EOM（月末） | -0.136% | 47.1% | 0.490 | 唯一のマイナス |
| **BOM（月初）** | **+0.286%** | **55.0%** | 0.523 | 最強 |
| BOM+1 | +0.169% | 49.7% | 0.509 | |
| 通常日 | +0.155% | 50.8% | 0.495 | |

**EOMリバーサルスプレッド（close_loc×翌日リターン）: +0.81%（通常日+0.04%の20倍）**

### B. 月初リバランス買いの特徴

- BOMの寄り付きギャップ: **+0.238%**（通常日+0.140%）→ 上昇は寄り前に凝縮
- 時間帯別出来高: BOMは通常日と同分布（寄り23%・引け18%）→ 当日中の特別な動きはない
- EOMで売られたセクター（機械・商社・自動車・鉄鋼）がBOMで強く買い戻される
- BOMの板寄せ（15:24→15:30）: **+0.023%** → 唯一プラス（EOM: -0.097%、通常日: -0.004%）
- BOMのclose_loc: 中央値 **0.523**（高値引け寄り） ← EOM: 0.490

### C. 7/4 独立記念日シーズナリティ（21年 2005〜2025）

| | S&P500 | 日本株（10年）|
|---|---|---|
| 7/4前5日間 | **+0.883%、67%プラス** | +0.558%、**40%プラス** |
| 7/4後5日間 | +0.523%、62%プラス | +0.396%、**80%プラス** |
| ベースライン5日 | +0.168% | +0.589% |

- S&P500: rel=-1（最終取引日）が勝率76.2%で最強。rel=-4から上昇し始める
- **日本株は逆**: 7/4前が弱く（40%）、7/4後が強い（80%）→ 波及が翌営業日にズレる
- 大きな弱気相場（2010年-5.6%、2022年-2.3%）では失敗

### 常識と逆だった結果（重要）

| 通説 | 日本株の実態 |
|---|---|
| 月曜が弱い | **火曜が最強（+0.282%、60%）**、月曜は普通 |
| セル・イン・メイ | **5月は強い（+0.229%）**、夏冬差ほぼなし |
| GW前に売られる | **GW前が強い（+0.359%）** |
| お盆は薄商いで下落 | **お盆期間は強い（+0.311%）** |
| サンタラリー=12月末 | **実体は1月最初5日（+0.572%）** |
| 3月は年度末で強い | **唯一のマイナス月（-0.077%）** |

## ON-LS戦略への示唆

1. **EOMリバーサルスプレッドが最強**（+0.81%、通常の20倍）→ 月末日のポジションサイズ増加を検討
2. **BOM当日のclose_locが高め（0.523）** → BOM引けでエントリーするとSHORTシグナルが多い、BOM+1は+0.169%と全体がプラス傾向なので注意
3. **火曜エントリー（月曜引け）が最強曜日**（勝率60%）
4. **SQ4日前・SQ3日後**が強い → SQ周辺のシグナルは注目価値あり
5. **3月が最弱月**（-0.077%） → 3月は戦略全体を抑制も選択肢
