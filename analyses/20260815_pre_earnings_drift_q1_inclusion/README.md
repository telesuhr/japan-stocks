# pre_earnings_drift への第1四半期(1Q)追加の複数年IS/OOS検証

## 背景
採用戦略 pre_earnings_drift（決算前ドリフト）は現行定義で `fq IN (本決算/第2Q/第3Q)` とし、
**第1四半期(1Q)を除外**している。2026-08-15のstrategy-healthで、直近7-8月のQ1(1121件)を
まるごと売買していないことが判明。1シーズン限定の簡易テストでは 1Qドリフトも
+0.57%/trade・t=3.13 と有意なエッジを示した（既存対象は +1.30%/t=3.61）。
→ 1シーズンはin-sample。本分析で**10年ヒストリカル・IS/OOS**で1Q追加の是非を判定する。

## 目的・仮説（教訓5: 検証前に宣言）

| ID | 仮説 | 予想 | 棄却条件 |
|----|------|------|----------|
| H1 | 既存対象(FY/2Q/3Q)の決算前ドリフトは10年通期でコスト後プラス・IS/OOS一貫（現行採用の追認） | OOS 平均net>0・t≥1.5 | OOS 平均net≤0 または t<1.5 |
| H2 | 1Qの決算前ドリフトも独立にコスト後プラスのエッジを持つ | OOS 平均net>0・t≥2.0 | OOS 平均net≤0 または t<2.0 |
| H3 | 1Q追加の統合バスケットは既存単独より日次PF Sharpe(コスト後)を改善（機会4倍の分散/機会増） | 統合 OOS 日次Sharpe ≥ 既存単独 | 統合 OOS 日次Sharpe < 既存単独 |

補助論点: 1Qは per-trade エッジが弱い場合でも「件数4倍→低タッチ運用の稼働日不足を埋める」価値があるか。

## データ
- **決算発表日**: `fin_summary`（doc_type LIKE '%FinancialStatements%'、`cur_per_type`=FY/1Q/2Q/3Q、
  `disc_date`=開示日）。2016-05〜2026-08、約10年。(code,cur_per_en,cur_per_type)で最古disc_dateにdedup。
- **株価**: `stocks_daily`（adj_open/adj_close/turnover_value）2016-05〜2026-08。
- **ユニバース**: `symbol_master` market_nm='プライム'、sector33_nm から 医薬品/陸運業を除外、
  シグナル日 turnover_value ≥ 5億円（現行定義に忠実）。

## 手法
- エントリー規則（現行 pre_earnings_drift に忠実）: signal=発表-lead営業日、entry=signal+1(寄成)、
  exit=発表-1営業日(引成)。lead: FY=5、1Q/2Q/3Q=3。turnover はsignal日で判定。先読みなし（教訓1）。
- コスト: 往復4bps（片道2bps）を控除。感度確認で10bpsも併記（教訓2）。
- 年率化/評価: per-trade統計（平均/中央値/勝率/t）に加え、**日次EWポートフォリオ収益系列の
  真のSharpe**（重複保有を日次で平均・per-trade×√252の過大評価を排除）。
- IS/OOS: IS=2016-2021、OOS=2022-2026（発表年ベース）で分割。
- 変種比較: **base(FY/2Q/3Q)** / **1Q単独** / **all(base+1Q)**。

## 所見・次アクション

**判定:**
- **H1（base IS/OOS一貫）→ ✗棄却**。base は 2018/19/22 が明確にマイナス（t−7〜−9）、IS通期でSh−0.84・累積−63%。
  **常時オンの安定エッジではなく、直近レジーム依存**。エッジは 2024→25→26 に単調強化（+0.66→+0.98→+1.43%）。
- **H2（1Q独立エッジ OOS t≥2.0）→ △条件付き**。OOS集計 t=3.93 で閾値は超えるが、年次では2024マイナス＝不安定。
  per-tradeはbaseより明確に弱く（OOS +0.276% vs +0.584%）、10bpsで+0.216%まで薄利化。
- **H3（1Q追加でPF Sharpe改善）→ ✗実質棄却**。OOS日次Sharpe 1.13→1.20 とほぼ横ばい、稼働日も173→183日で
  「薄い稼働を埋める」効果はほぼ無し（baseが既に年173日）。1Qは per-trade を薄める割に分散寄与が小さい。

**結論:**
1. **1Q追加は見送り**。弱い・同様に不安定・per-tradeを薄める・稼働日の増分ほぼゼロ。核を厚くする手段にならない。
2. **より重要な発見**: pre_earnings_drift は**10年で見ると安定エッジではない**。2018/19/22の負け年を持ち、
   現在は例外的に強い3年局面(2024-26)にある。strategy-healthの「Sh3.92の稼ぎ頭」は(a)per-trade×√252の誇張
   （honestは現局面でもSh≈1.1-1.2）(b)直近レジームのピーク、の二重で楽観的だった。
3. **low-touch核としての扱い**: 現局面のエンジンとしては有効だが**放置委任は危険**。次の一手は「1Q追加」ではなく
   **①ドローダウン/レジームガード**（連敗・トレイル悪化で縮小/停止）**②ロングオンリーβの中立化**
   （2018/2020の負けは相場βの寄与大。MDD−30%圧縮の余地）の検討。正式変更するなら `/backtest-validation`。
