# 半導体ADRリード → 翌日日本イントラ継続 vs 反転

## 目的・仮説

米国の半導体ADR（東京エレクトロン: ADR_8035）の前日変化率は、翌日の日本株の寄り付きギャップを高精度に予測する。
そのギャップが「イントラで継続するのか、反転するのか」を特定できれば、機械的な売買ルールとして使えるか？

**仮説A（ギャップ継続）**: ADR↑→日本寄り高→イントラでも上昇トレンド継続  
**仮説B（ギャップ埋め）**: ADR↑→日本寄り高→過剰織り込みで引けにかけて反落  
**仮説C（ADR幅依存）**: 小さなADR変化はノイズ（中立）、大きな変化だけ継続

## データ

- **シグナル**: `macro.daily_ohlcv` ADR_8035（東京エレクトロン米ADR）・SMH（半導体ETF）
- **ギャップ/日足**: `stocks_daily` code=80350（TEL）・40630（信越化学）
- **イントラ保有期間**: `stocks_intraday` 同上
- **期間**:
  - 日足分析（ギャップ+日中方向）: 2020-01-02〜2026-06-16（約1500日）
  - イントラ保有期間分析: 2024-05-10〜2026-06-16（約500日）
- **エントリー価格**: `stocks_daily.open`（寄付き成行き想定）

## 手法

1. ADR_8035変化率（米国D_us）→ 翌日本営業日のギャップ（open/prev_close-1）の相関・予測力
2. ギャップ方向×日中リターン（close/open-1）: 継続 vs 反転の傾向
3. ADR変化率ビン別 × 保有期間別（9:30 / 10:00 / 11:00 / 11:30 / 13:30 / 15:00）リターン
4. コスト込み（往復10bp）P&F・Sharpe
