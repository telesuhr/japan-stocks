# 投資部門別 海外フロー → 市場タイミング検証 (レポート柱3核心)

## 分析の目的

レポート柱3の主張「市場の方向性は海外投資家フローに従属。海外は数週かけてVWAP執行する
ため自己相関が強くモメンタムを生む。個人は逆張り」を検証する。

**決定的制約**: 投資部門別売買動向は en_date(週末金) に対し pub_date(翌木) で公表 = **公表ラグ約6日**。
先週の海外フローを知るのは翌週木曜。これがトレード可能性の肝。

## データ・手法

| 項目 | 値 |
|---|---|
| フロー | investor_types (TSE1st 2016-22 + TSEPrime 2022-26 stitch) 526週 |
| 指標 | FrgnBal(海外ネット), IndBal(個人), InvTrBal(投信) |
| 指数 | index_daily TOPIX (code 0000) |
| トレード可能forward | pub_date → +5/+10営業日 (公表後に初めて執行可能) |

## 主要発見

### A. 海外フローの自己相関 (レポートの「連続性」主張) ✅真

| lag | ρ |
|---|---|
| 1週 | **+0.369** (p=2e-18) |
| 2週 | +0.172 |
| 4週 | +0.107 |

符号継続率 63.5%。→ **海外フローは持続的。レポートの「数週VWAP執行・連続買い越し」は事実**。

### B. 同時相関 (海外フロー vs その週の指数リターン) ✅真・但し取引不可

ρ=+0.336 (p=4e-15)。→ 海外買い越し週は市場上昇。「市場は海外に従属」は事実。
**だが同週フローは週末まで分からず、公表は翌木 = この相関は取引できない**。

### C. 予測力【トレード可能】FrgnBal(公表時既知) vs 公表後 forward ❌ゼロ

| 期間 | 公表後1週 ρ | 買越多-売越 差 |
|---|---|---|
| 全期間 | +0.002 (p=0.96) | +0.04% |
| IS(〜21) | -0.012 | +0.05% |
| OOS(22〜) | -0.003 | **-0.19%** |

→ **公表後の予測力は完全にゼロ**。OOSは逆符号。

### D. レジーム戦略 (海外4週MA>0でTOPIX long, 公表後執行) ❌劣後

| 期間 | 戦略Sharpe | buy&hold Sharpe |
|---|---|---|
| 全期間 | 0.69 | **0.76** |
| IS | 0.32 | **0.57** |
| OOS | 1.05 | 1.00 |

→ **海外フローのレジームでindexをタイミングしても buy&hold に劣後**。

### E. 個人・投信の逆張り性 ✅逆張りは真・但し予測力なし

IndBal: 同時ρ=**-0.667** (個人は上昇時に売り=強い逆張り、レポート通り) だが 公表後1週ρ=+0.074(p=0.09)。
→ 逆張り行動は事実だが、個人フローも forward を予測しない。

## 解釈

**レポートの記述的主張は全て正しい** (海外フロー持続 ρ0.37 / 市場を動かす ρ0.34 / 個人逆張り ρ-0.67)。
**だがトレード可能なエッジはゼロ**。理由は明白:

- 同時相関(B)が示すように、海外フローと市場は同じ週に動く。
- フローは週末締め・翌木公表 (ラグ6日)。公表時点では市場は既に動き終えている。
- よって公表後forward(C/D)に予測力が残らない = 情報は公開時点で織り込み済み。

「真実だが取引不可能」の典型。信用残 (第四/九弾でコスト負け) と同じく、
**周知の公開データに残存アルファは無い**。レポートは公表ラグを完全に無視している。

## 限界・注意点

- 市場(指数)タイミングのみ検証。個別銘柄クロスセクションへの応用は別途 (但しフローは市場レベルのみで個別なし)。
- 日次でなく週次粒度。日中フロー速報 (一部速報あり) なら多少前倒せるが、本質的ラグは残る。
- TOPIX建て。日経でも結論は同様の見込み。

## 結論

**レポート柱3 (海外フロー市場タイミング) のトレード可能エッジは無い ⛔**。
記述 (持続・従属・逆張り) は正しいが、公表ラグ6日で予測力が消える。
レジーム戦略は buy&hold に劣後。**公開フローデータに残存アルファ無し**を再確認。

## 次のアクション候補

1. **出来高 (volume) 系のエッジ検証** — 出来高ショック→反転/継続、出来高×価格パターン (フローと別軸)
2. フローを使うなら日中速報 (リアルタイム性) しかないが、本質的に厳しい
3. クロージングオークション下落側Long (本物の候補) の実約定リアリズム精査に注力
