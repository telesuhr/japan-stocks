# 17業種セクターローテーション — 「資金循環」の正体はモメンタム継続(逆張りは負け)

## 分析の目的・仮説

ユーザーの問い「**どこで利確して次のセクターに向かうべきか／資金循環を見極めたい**」を
検証可能なルールに落として決着させる。正反対の2仮説を同じ厳密さで比較した:

- **(A) モメンタム継続**: 強い業種は強いまま → 上位K業種を保有、**上位から外れたら利確**して次の強い業種へ
- **(B) 資金循環(平均回帰)**: 過熱業種から出遅れ業種へ資金が回る → **過熱で利確し出遅れを拾う**

これまでの研究30+本は全て「セクター中立(業種を消す)」だったので、業種そのものを賭ける
**セクター・タイミング**は初。月次なら寄成/引成で回り、見れなくなる2ヶ月後でも運用可能＝
3層ポートフォリオの**恒久エンジン(Layer1)候補**として時間軸制約に合致する。

## 主要発見

### ✅ 1. 規範ICが全ルックバックで正 = 資金循環はモメンタム(逆張りでない)

trailing-L業種順位 vs 翌月業種リターンのクロスセクション順位相関(17業種/月):

| L | IC | t | 判定 |
|---|---|---|---|
| 1ヶ月 | +0.030 | +0.81 | 弱モメンタム |
| 3ヶ月 | +0.094 | +2.75 | **モメンタム** |
| 6ヶ月 | +0.079 | +2.47 | **モメンタム** |
| 12ヶ月 | +0.118 | +3.31 | **モメンタム** |

→ 強い業種は翌月も強い。**「過熱→出遅れ」の資金循環(逆張り)は棄却**(REV戦略は全て Sharpe 0.2〜0.4)。

### ✅ 4. 高流動性(ADV≥10億)で改善 = 小型株モメンタムの化身でない

| ユニバース | 規範IC L3 | MOM L3K3 超過Sharpe(全/IS/OOS) |
|---|---|---|
| ≥1億円/日 | +0.094 | +1.49 / +1.52 / +1.46 |

小型株プレミアムの偽装ではなく、執行可能な大型業種ローテーションとして本物。

## 解釈・示唆

1. **「どこで利確して次へ」の答え**: 過熱で売るのは誤り。**3ヶ月の相対強さ上位3業種を保有し、
   毎月見直して上位から外れたら次の強い業種へ乗り換える**(利確＝順位陥落)。日本株の資金は
   3〜12ヶ月、勝っている業種に流れ続ける(トレンド持続)。
2. **経済的妥当性**: 業種ローテーションは機関投資家のアセットアロケーション・テーマ資金の
   慣性で数ヶ月単位の持続性を持つ。1ヶ月では弱く(IC+0.03)、3ヶ月で最大化=「直近の勢い」
   より「四半期トレンド」が効く。
3. **3層ポートフォリオでの位置**: 月次リバランス・大型業種で執行軽い・9年プラス・既存6戦略
   (個別株イベント系)と被らない業種レベルの賭け=**Layer1(恒久エンジン)候補かつ低相関分散源**。
   実装ビークルは17業種ETF(NEXT FUNDS等)か各業種の流動性上位銘柄EWバスケット。

## 限界・注意点

- **超過Sharpeは1.5前後(≥1億)〜2.1(≥10億)**。≥10億の全2.09は魅力的だがOOSは1.53でIS3.03から
  減衰(両方プラスだが半減)。「全2.0超」を額面で受けず、現実的にはOOS1.5前後の戦略とみなす。
- **long-only上位3業種=フル市場β+集中**。標準偏差は高い。市場下落耐性は別途要検証(年別2020+0.21は
  COVIDでも辛うじてプラスだが薄い)。L/S(市場中立)版は Sharpe 0.7〜0.9と穏当。
- 等加重バスケット。**時価総額加重(=実ETFに近い)での再現は未実施**(ShOutFY as-of結合が必要)。
  ただし高流動性で改善する事実から、cap-weightでも生存する公算は高い。
- 生存者バイアス: symbol_masterは上場廃止銘柄を含まないが、第十二弾より日本の廃止はTOB主流で
  過大評価方向でない。業種EWでは影響軽微。
- 月次121・OOS約60ヶ月。十分だが、業種数17のクロスセクションは分散小(極端月の影響)。
