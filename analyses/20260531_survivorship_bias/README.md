# 生存バイアス補正 影響調査

> **結論: 日本市場の生存バイアスは通説より軽微。廃止候補の94%が流動性フィルターで除外され、**
> **残る9件はTOBプレミアムでむしろ+12%のリターン。「バイアスが戦略を過大評価」とは限らない。**

## 1. 問題設定

`symbol_master` に `delisted_at` が全件NULL（4,462銘柄全て「生存」扱い）。
`stocks_daily` には2021-2024年に途絶えた324銘柄が存在 → 上場廃止候補。

## 2. データ

- stocks_daily 2021-2026: 4,462銘柄, 526万行
- symbol_masterに存在しない銘柄 (=廃止候補): **313銘柄** (2021年以前から存在するもの)
- データ期間: 2021-01-04〜廃止日

## 3. 廃止候補の特性

### 流動性（日次売買代金）

| 区分 | 件数 | 割合 |
|---|---:|---:|
| ADV < 1億円 | 233件 | **74%** |
| ADV < 10億円 | 293件 | **94%** |
| **ADV ≥ 10億円（戦略対象ゾーン）** | **9件** | **3%** |

### 廃止前リターン（全体）

| 指標 | 12ヶ月前 | 3ヶ月前 |
|---|---:|---:|
| 平均リターン | **+27.3%** | +6.5% |
| 中央値リターン | +27.6% | +0.2% |

**廃止前12ヶ月のリターンがプラス**。これは日本市場の上場廃止の特徴:
- 欧米: 株価暴落 → 倒産 → 廃止（マイナスリターン）
- **日本: TOB・MBO・親会社による完全子会社化が主流** → 廃止直前にTOBプレミアムで株価が上昇

### 流動性≥10億円の廃止候補9件の特性

- 平均12M リターン: **+11.9%**（TOBプレミアムで上昇）
- これらが各戦略のユニバースに混入していたとしても、**損失ではなくむしろ利益をもたらす**

## 4. 各戦略への影響

| 戦略 | 廃止候補の暴露リスク | 実際の影響方向 |
|---|---|---|
| **平均回帰(RSI<30)** | ADV≥10億円フィルターで9件のみ混入。廃止候補はプラスリターン | **軽微（プラス方向）** |
| **PEAD L/S** | ADV≥10億円+決算イベント条件。廃止候補は決算発表しないケース多い | **軽微** |
| **信用残ファクター** | ADV≥10億円フィルターで94%除外。残る9件はTOBプレミアム | **軽微（プラス方向）** |
| **OBV中小型** | ADV 1〜500億円フィルター。廃止候補の多くは1億円未満で除外 | **軽微** |

## 5. 結論

### 想定と逆の結論

「生存バイアスで戦略が過大評価されている」という懸念は、**日本市場では欧米ほど妥当ではない**。

理由:
1. **流動性フィルターが最良の保護**: ADV≥10億円のフィルターで廃止候補の94%が除外。
2. **TOBプレミアム**: 日本の上場廃止は倒産ではなくTOBが主流 → 廃止直前に株価上昇。
3. **廃止候補がポートフォリオに入っても損失ではなくリターン貢献**になる可能性。

### 影響の方向性（正確な方向に修正）

- 過去の各戦略で生存バイアスが結果を「過大評価」した可能性は低い
- むしろ廃止候補（TOBプレミアム）を含めると一部戦略はやや改善する可能性
- **生存バイアスは今回確認した戦略群の「エッジ無し」という結論を強化しない**（弱める可能性も）

### 真のリスク: 「廃止銘柄は除外されていた」ことによる正確性の問題

- 廃止候補銘柄でのみ発生する特殊なシグナル（TOBイベント前の出来高異常等）が未検出
- このリスクは「エッジが消える」方向ではなく「イベントドリブン系への入り口」として考えるべき

## 6. 第三弾（平均回帰）の結論再確認

> 第三弾README: 「生存バイアスは平均回帰を過大評価する方向なので結論はむしろ強固」と記載

これは**修正が必要**。日本市場では廃止銘柄がプラスリターンを持つため、廃止銘柄を含めると
平均回帰戦略は改善するかもしれない（悪化しない）。ただし廃止銘柄を94%除外しているため影響は軽微。

**「エッジ無し」という結論は生存バイアス補正の有無にかかわらず変わらない。**
