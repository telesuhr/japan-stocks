## 5. 限界・注意点

- **21銘柄は全て大型上場継続銘柄** → 生存バイアスあり
- **21銘柄の選別自体に事後性** → セクター選択も含めてOOSテスト未実施
- **Sharpe>2 フィルタも事後選択** → 厳密にはIS期間でSharpe>2の銘柄を抽出してOOS評価すべき
- **配当未考慮**
- **執行は寄付Open価格仮定** → 実際はスリッページ発生
- **トヨタ・ホンダのRSI Sharpe 7-15はやや過剰評価感** → 個別ニュース・決算特異要因の可能性
