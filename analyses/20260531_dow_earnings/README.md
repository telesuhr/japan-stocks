# 曜日×決算タイミング 交差検証

> **結論: 月曜エントリー（木曜発表→金曜反応→月曜エントリー）が Sharpe 0.91 で最強。**
> **ただし n=42日・t=1.69 で昇格基準(t≥2.0)未達。有望な方向性だがサンプル不足。**

## 1. 目的

PEAD（決算後ドリフト）の前段(Sharpe 0.38)から、曜日フィルターでSharpe2.0を目指す。
「週末を挟む発表→過大反応→ドリフト大」という仮説の検証。

## 2. データ・手法

- ベース: `pead_obs.csv` (11,305件)
- `entry_date`（エントリー日 = react翌営業日）の曜日で分類
- L/S評価: 10分位 Q9-Q0、20日保有、コスト20bps後
- IS: 2021-2023 / OOS: 2024-2026

## 3. 結果（20日保有, コスト後 Sharpe）

| フィルター | n_obs | Sharpe | t値 | 解釈 |
|---|---:|---:|---:|---|
| **月曜エントリー** | 1,846 | **0.91** | 1.69 | 木曜発表→金曜反応→月曜入り |
| 金曜エントリー | 1,485 | 0.76 | 1.39 | 水曜発表→木曜反応→金曜入り |
| 水曜エントリー | 1,285 | 0.49 | 0.85 | 月曜発表→火曜反応→水曜入り |

| 期間 | n_obs | n_days | Sharpe | t値 |

IS/OOS両方で Sharpe~1.0 と一貫。ただしn_days=24/18で統計パワー不足。

## 4. 解釈

### なぜ月曜エントリーが強いか

`entry_date = 月曜` のパス:
- 木曜引け後（15:00以降）に決算発表
- **金曜反応**: 限られた取引時間・週末前の売り圧力で不完全消化
- **土日間**: 週末にアナリストが分析・見直しを行う時間
- **月曜エントリー**: 週末を経て追加的な情報処理が行われ、残存ドリフトが継続

### なぜ火曜エントリーが最悪か

`entry_date = 火曜` のパス:
- 月曜引け後に決算発表
- **火曜反応**: 週明け直後・出来高豊富で即座に価格消化が進む
- 過大反応（平均回帰）でドリフトがマイナスになりやすい

### car0（反応の大きさ）に曜日差はない

絶対平均car0がどの曜日も約±3.0%で均一。**反応の大きさではなく、その後の消化速度に差がある。**

## 5. 限界・次のアクション

**サンプル不足が致命的**: 月曜エントリーは月約4件 × 12ヶ月 × 5年 = 240件/1日分しかない。
週次L/Sを測れた日数が42日では昇格基準(N≥30 & t≥2.0)の後者を満たせない。

**有効な次のアクション**:
- 全PEAD L/Sを月曜エントリーに絞った場合の拡張（決算イベント件数を増やす観点）
- 既存 earnings_pead (Sharpe 2.19) と月曜効果の交差 = 昇格済みに月曜フィルターを追加して検証
- 5年以上の長期データで月曜エントリーを確認（n_daysを60以上に増やす）

## 結論

**第十一弾: 月曜エントリーのSharpe 0.91は有望だがt=1.69で統計的不確実（⚠️候補）**

既存昇格済みの earnings_pead (Sharpe 2.19) への月曜フィルター追加として今後検証する価値あり。
単独での昇格条件は満たさない。
