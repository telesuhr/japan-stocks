# 日中の戻りは「だまし」か「後場継続」か — 前場の戻りの質で識別できるか

## 目的・仮説

[20260611_gapdown_recovery_signals](../20260611_gapdown_recovery_signals/) で
「寄り前変数では戻る日を予測できない（コイントス）」と判明した。本分析はその続編として、
**前場中に観測できる「戻りの質」**で、戻りが後場まで継続するか・だまし（失速）かを
識別できるかを検証する。

**仮説（検証前に固定）:**

- H1 **VWAP奪回**: 前場引け時点で価格がVWAPの上にある戻りは後場も継続しやすい
  （平均的な買い手が含み益＝上値で投げが出にくい）
- H2 **出来高の伴い方**: 戻り局面（上昇分）に出来高が乗っている（up-volume比率が高い）戻りは本物
  （「下げで出来高・戻りは閑散」はだましの典型とされる）
- H3 **安値の時刻**: 朝早く（寄り直後に）安値をつけた日ほど後場継続しやすい
  （売りの正体が寄りの投げだけだった）
- H4 **戻し率**: 前場引けまでに下げ幅の半値以上を戻した日は後場も継続しやすい

## データ

- `stocks_intraday` ETF1321（日経225連動）1分足: **2024-05-10〜2026-06-11（510営業日）**
- `stocks_daily` 13210: 前日終値
- イベント: 前場安値が前日終値比 **≦-1%** まで下げ、かつ前場引けまでに下げ幅の
  **1/3以上を戻した**日（=「戻りの兆候が出ている日」だけを対象に、その質を問う）

## 手法

- 特徴量はすべて**前場引け(11:30)時点で確定する値のみ**
- アウトカム: 後場リターン = 大引け / 前場引け値 - 1
- 各特徴量を中央値分割し t 検定 + Spearman 相関、期間前半/後半で頑健性確認

## 結果（主要指標）

- イベント: **46件**（510営業日中。前場安値≦-1% かつ 1/3以上戻し）
- 無条件ベースライン: **後場継続率 52.2% / 平均後場リターン -0.18%** — 戻り兆候のある日の後場もコイントス（やや弱含み）

| 仮説 | 有利側-不利側 後場リターン差 | t | p | 継続率(有利/不利) |
|---|---|---|---|---|
| H1 VWAP奪回 | -0.25% | -0.68 | 0.50 | 43.5% / 60.9% |
| H2 出来高伴う | -0.03% | -0.08 | 0.94 | 47.8% / 56.5% |
| H3 安値が早い | -0.46% | 1.27* | 0.22 | 47.8% / 56.5% |
| H4 半値戻し級 | -0.02% | -0.05 | 0.96 | **39.1% / 65.2%** |

すべて非有意。むしろ**符号は4仮説とも逆**（「良い戻り」ほど後場が伸びない方向）で、
特にH4は「半値以上戻した日の後場継続39% vs 浅い戻しの65%」と、定説と反対の弱い示唆。

## 所見・次アクション

**結論: 前場の「戻りの質」（VWAP奪回・出来高・安値時刻・戻し率）では後場継続/だましを識別できない。4仮説とも棄却。**

1. 「VWAP上で前場を終えれば本物」「出来高を伴う戻りは本物」といった**テクニカルの定説は、
   このサンプル（ETF1321・2年・46件）では一切支持されない**。むしろ弱く逆
2. 逆方向の示唆（よく戻した日ほど後場失速）は平均回帰と整合的だが、t<1.3で採用に値しない。
   事後発見なので、検証するなら新仮説として事前登録（教訓5）
3. 3部作（[寄り前変数](../20260611_gapdown_recovery_signals/)→[板シグナル](../20260611_board_signal_eventstudy/)→本分析）の総括:
   **ギャップダウン日の日中・後場の方向は、寄り前にも・板にも・前場の値動きの質にも乗っていない**。
   この時間軸・この特徴量空間で日経（指数）はほぼ効率的
4. 限界: N=46で検出力は±0.6%程度の差まで。個別銘柄（ボラの高いSBG等）では結論が変わる
   可能性は残るが、指数レベルでの実用ルール化は断念が妥当

**実務的な含意**: 「この戻りは本物か？」という問いに日中データは答えてくれない。
答えられない問いを前提にしたポジション（戻り本物前提のナンピン等）を組まず、
サイズと撤退線で管理するのが、検証3本から導かれる一貫した結論。
