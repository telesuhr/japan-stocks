# 戦略バスケット 日次ポートフォリオSharpe

## 分析の目的

Sharpe監査 ([`20260531_strategy_sharpe_audit`](../20260531_strategy_sharpe_audit/)) で
「per-trade×√252 はstandalone年率を過大評価。正しくは日次ポートフォリオ収益系列の
Sharpe、または戦略バスケット全体の資金曲線で評価すべき」と結論した。

本分析は価格ベース4戦略を忠実に再構築し、(1)各戦略の日次ポートフォリオSharpe、
(2)等加重バスケットの合成Sharpe を測定する。**「恒久エンジンは本物か」への最終回答**。

## データ・手法

| 項目 | 値 |
|---|---|
| 対象 | eneos_vwap_trend / vwap_morning_meanrevert / lasertec_ma25_support / bank_absorption |
| 期間 | イントラ2戦略 2024-05〜 / 日足2戦略 2021-05〜 / 共通期間 2024-11〜2026-05 |
| 戦略ロジック | [`20260511_strategy_validation_jquants`](../20260511_strategy_validation_jquants/) に準拠 |
| コスト | 片側2bps×往復 (per-trade控除済) |

**sleeve方式**: 各戦略=等資金。日々のsleeve収益 = その日アクティブなトレードの
per-day収益 (総リターン÷保有日) の平均。バスケット = sleeve等加重平均。
Sharpe = 日次収益 mean/std × √252。

## 主要発見

### A. 各戦略の日次ポートフォリオSharpe (√252の幻なし)

| 戦略 | headline(√252) | **日次PF Sharpe** | 年率収益% |
|---|---|---|---|
| bank_absorption | 3.94 | **4.21** ※注 | 41.1 |
| vwap_morning_meanrevert | 4.46 | **1.48** | 19.8 |
| lasertec_ma25_support | 2.69 | **1.20** | 10.7 |
| eneos_vwap_trend | 1.81 | **0.95** | 9.6 |

→ 低頻度3戦略 (eneos/lasertec/vwap) は日次PFで 0.95〜1.48。headlineより大きく低下し監査の予測通り。

### B. 等加重バスケット合成 (共通期間 2024-11〜2026-05)

| 構成 | 日次Sharpe | 年率収益% | 年率vol% |
|---|---|---|---|
| **4戦略 等加重** | **5.28** | 27.9 | 5.3 |

**sleeve間相関 ≈ ゼロ** (全ペア 0.05前後):
```
                 eneos  vwap_m  laser  bank
eneos             1.00    0.05   0.05  -0.06
vwap_morning      0.05    1.00   0.02   0.01
lasertec          0.05    0.02   1.00   0.09
bank_absorption  -0.06    0.01   0.09   1.00
```

→ **個別Sharpe平均 2.66 → バスケット 5.28 (+2.62)**。**分散効果がエッジの本体**。

## 解釈

1. **個別戦略の真の日次Sharpeは控えめ** (ex-bank で 0.95〜1.48)。headlineの√252値は
   standalone年率を過大評価していた (監査通り)。

2. **だがバスケットは本物**: 戦略間相関がほぼゼロのため、4戦略を束ねると
   Sharpeが個別平均の約2倍に跳ね上がる。これは数学的に正しい分散効果
   (無相関k戦略の合成Sharpe ≈ 個別×√k)。

3. **「恒久エンジン」の価値は個別戦略でなく低相関ポートフォリオにある**。
   トリガーも時間軸も銘柄も異なる戦略 (銀行出来高/レーザーMA/イントラVWAP×2) を
   組み合わせることで、どれか一つが不調でも全体は安定する。

4. headline個別√252値で「単独2.0」を判定するのは誤り。**バスケット資金曲線で評価すべき**。

## 限界・注意点

- **bank_absorption 4.21 は過大評価寄り**: sleeve内で同時保有数に上限を設けず全アクティブ
  トレードを平均しているため、銀行内分散でvolが過小→Sharpe過大。実運用は最大3銘柄
  (README)。capあり再計算で低下する見込み。**バスケット5.28もこの影響で楽観寄り**。
- 共通期間が約18ヶ月と短い (intraday data が2024-05〜のため)。長期の頑健性は別途。
- sleeve方式 (総リターンを保有日で均等配分) は日次mark-to-marketの近似。
- 決算系2戦略 (earnings_pead 日次Sharpe≈1.1-1.3 / pre_earnings_drift) は fin_summary
  依存で本分析未組込。低相関なら加えてバスケットSharpeはさらに向上の見込み。
- per-tradeコストのみ。スリッページ・空売り調達料は未反映。

## 結論

**既存戦略は「インチキ」ではないが、個別の日次Sharpeは headline(√252) より大幅に低い
(ex-bank 0.95〜1.48)。真の価値は戦略間相関ゼロによる分散効果にあり、4戦略バスケットで
日次Sharpe 5.28 (bank上限なしの楽観値) を得る。恒久エンジンはバスケットとして本物**。
