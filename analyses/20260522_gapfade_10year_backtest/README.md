# 寄付ギャップフェード戦略 10年バックテスト (却下)

**日付**: 2026-05-22
**対象**: 非鉄7銘柄 (5706/5711/5713/5714/5801/5802/5803, JX金属5016除く=2025-3〜のみで短い)
**期間**: 2016-05-10 〜 2026-05-22 (**10年, 2,452営業日**)
**データ**: OMEN PostgreSQL `stocks_daily`

## 1. 動機

前回 [20260522_nonferrous_directional_strategies](../20260522_nonferrous_directional_strategies/) で、13ヶ月データで寄付ギャップフェード (|gap|≥1.5%) が **Sharpe +2.49 / 累積+70.2%** という強い結果を出した。
ただし期間が短いため、長期での妥当性を厳密に検証する必要があった。**戦略が日足だけで完結する**(寄付Open → 引けClose) ので、10年分の日足で再評価可能。

CLAUDE.md にも記載のある教訓:
> マトリクス戦略 (直近6M Sharpe +6.83 → 5年通算 +1.25 → 却下)

直近データのみでの戦略採用は危険。同じ罠を踏まないよう長期検証を実施。

## 4. 解釈・教訓

### 4.1 13ヶ月 vs 10年で結果がここまで違う理由

1. **2025-2026 はAIテーマで電線株がボラ拡大したレジーム** — フジクラ・古河電工が大ギャップを頻発し、その後の振れ戻しも大きかった。これが平均回帰戦略に追い風となった
2. **長期では「ギャップ = 新情報」が支配的** — 通常時の大ギャップは決算・IR・海外マクロのような構造変化の反映で、フェードしない方が多い
3. **コスト前で Sharpe ≈ 0** — シグナル自体に統計的な平均回帰エッジがそもそも無く、たまたま13ヶ月で +0.05% × 200trades = +10% の幸運が乗っただけ

### 4.2 13ヶ月Sharpe = 標準誤差を考えると当然

- 13ヶ月 N=139日, Sharpe +2.49 の標準誤差 SE(Sharpe) ≈ √((1+0.5×2.49²)/139) ≈ 0.16
- **95%信頼区間: +2.17 〜 +2.81** という計算だが、**これは「IIDの仮定下」での値**
- 実際は (a) 期間が特定レジーム、(b) サバイバルバイアス選択 (Top5)、(c) パラメータ事後選択 (thr=1.5%) で過大評価
- 真のSharpeは長期検証の **-1.32** に近い

### 4.3 学びの確認

CLAUDE.md にすでに記載されていた:
> 直近2年限定の現象。昇格基準クリアならず → research段階に据え置き

> パラメータ網羅探索は計算量爆発 — 仮説→検証の順序を守る

今回も同じ罠。**直近データの強いSharpeは、長期検証なしには採用してはいけない**。

## 5. 唯一の例外: 住友電工 (5802)

| 期間 | N | Sharpe | Cum% |
|---|---:|---:|---:|
| 10年全期間 | 519 | +0.90 | +65.9 |
| IS (2016-2022) | 302 | +0.30 | (推定 +9%) |
| OOS (2023-2026) | 217 | **+1.47** | (推定 +57%) |

- **唯一10年でプラス**, 直近でさらに強化
- ただし Sharpe +0.90 (10年) は実用には弱め (基準 +1.5 程度欲しい)
- 銘柄固有のミクロ構造 (出来高プロファイル、自社株買い、信用残推移など) を追加検証する価値あり
- 単独で動かしても DD -49.5% は重い

## 6. 結論

**寄付ギャップフェード戦略 (|gap|≥1.5%, 非鉄7銘柄) は 10年バックテストで完全に却下**。

| 判定項目 | 結果 |
|---|---|
| 採用 | ❌ |
| 直近データの強いSharpe | 2025-2026 限定のレジーム現象 |
| コスト前α | ほぼゼロ (+0.03 Sharpe) |
| パラメータ・銘柄選択感度 | どれを選んでもOOSで負け |
| ストップロス耐性 | 悪化 |
| 例外的に住友電工単独 | +0.90 だが実用には弱い |

## 7. 次のアクション候補

戦略採用の観点では止め、研究の観点で深掘り:

1. **「いつエッジが現れるか」のレジーム研究** — 2025-2026 のように寄付ギャップフェードが効く環境の特定。VIX水準、ボラレジーム、テーマ株偏重度などとの関係
2. **住友電工 (5802) 固有の検証** — 信用残・出来高プロファイル・自社株買い等で「なぜこの銘柄だけ機能するか」を解明
3. **逆ロジック (= ギャップフォロー)** — 10年でフェードが Sharpe -1.32 なら、フォローは Sharpe +1.32 + ノイズ - 取引コスト × 2 で +0.5〜+0.8 程度の可能性。ただしコスト前+0.03なので、コスト後はゼロに近い
4. **異なる対象セクター** — 半導体・銀行・小売など他セクターでの寄付ギャップ挙動。非鉄に固有でない可能性も
