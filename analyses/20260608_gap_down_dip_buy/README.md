# 全面ギャップダウン日の「寄り押し目買い」検証

実施日: 2026-06-08 / きっかけ: 6/8 の半導体・非鉄全面安（米6/5 SOX -10%の巻き戻し）で観測した「寄り底→日中戻し」が、戦略として成立するかの検証。

## 1. 目的・仮説
**仮説**: 市場が広範にギャップダウンして寄り付いた日に、主力半導体/AI＋非鉄を寄り(open)で等金額買うと、当日引け〜翌日にかけてコスト後でもプラスになる（パニック寄り→リバの取り込み）。
**特に検証したいユーザの問い**: 「寄りで買って **翌日まで持つ** とコスト後に勝てるか」。

教訓1に従い、同日の戻りは「同時反応」かもしれないため、**無条件（全日）保有のベースラインと比較して予測上乗せがあるか**で判定する。

## 2. データ概要
- DB: `market_data` / `public.stocks_daily`（日足、寄り・引け使用）
- 期間: 2016-05-10〜2026-06-08（2,460営業日）
- ユニバース: 主力20銘柄
  - 半導体/AI(12): SBG, 東エレ, アドテスト, ディスコ, レーザーテック, ローム, ソシオネクスト, SUMCO, ルネサス, SCREEN, KOKUSAI, 信越化学
  - 非鉄(8): 住友鉱山, 三菱マテリアル, 三井金属, 古河電工, 住友電工, フジクラ, DOWA, 東邦亜鉛
  - ※新光電工はTOB/JICの特殊状況のため除外
- 「全面ギャップダウン日」= 流動株（売買代金>5億円, 100銘柄以上）の**寄りギャップ中央値** ≤ 閾値。閾値は寄りで観測可能 → ルックアヘッドなし。

## 3. 手法・パラメータ
- エントリ: 全面ギャップダウン日の寄り(open)で20銘柄等金額買い
- イグジット3種: ①当日引け ②翌寄り ③翌引け（=「翌日まで持つ」）
- コスト: 往復0.2%を基本（感応度で0.1/0.2/0.3/0.5%）
- 評価: イベント日ごとに等金額バスケット化 → 連結エクイティ。指標は平均/トレード, 勝率, PF, t統計, 年率Sharpe, 累積, MaxDD

## 5. 解釈・示唆
1. **ユーザの仮説「寄りで買って翌日まで持つ」は不成立**。-1.0%/-1.5%閾値ではコスト後マイナス（PF<1）。しかも**ベースライン（ただ持つ）に対して予測上乗せはマイナス(-0.156%/trade)** = ギャップダウンという条件は、翌引け保有では「エッジ」どころか逆に不利。今日見えた日中戻りは大部分が**同時反応（co-movement）であって、翌日まで持てる予測力ではなかった**（教訓1が的中）。
2. **リバの取り込みは「短いほど良い」**。当日引け＞翌寄りが正、特に**翌寄り(オーバーナイトの戻り)が最良**。だが翌日のザラ場でその戻りを吐き出し、翌引けでは消える。戻りエネルギーは寄り〜翌朝に集中し、1日で減衰。
3. **エッジが出るのは「極端な日」だけ**。-2.0%（40日）では全Exitが正、翌寄りはPF1.79/勝率63%/t1.55と魅力的。ただし**t<1.6で統計的に弱く、N=40かつ暴落に集中（クラスター）**のため過信不可。
4. **非鉄は押し目買い厳禁、半導体はマシ**。非鉄は翌引けでPF0.81と明確に負け（落ちるナイフを掴む＝今日のDOWA/三菱マテリアルのジリ売りと整合）。半導体はバウンドするが、ベースライン比のエッジは乏しい。

**結論**: 「全面ギャップダウン→寄り買い→翌日持ち越し」は**買ってはいけない**。もし取るなら ①**極端な日(≤-2%)限定**、②**当日中〜翌寄りで手仕舞い（持ち越さない）**、③**半導体に絞り非鉄は外す** —— だが、それでもt値は弱くコストに脆い。スタンドアロンの優位性としては推奨しない。

## 6. 限界・注意点
- **寄り約定の楽観**: 20銘柄を公式始値で同時約定できる前提。パニック寄りの実スリッページはこれより悪く、結果は高コスト列（より悪化）側に寄る。
- **イベントのクラスター性**: ギャップ日はコロナショック等に集中。実効独立サンプルは表のN・t値より小さく、t統計は過大評価ぎみ。
- **サバイバーシップ/上場時期**: ユニバースは「現在の主力＝この10年で上昇した勝ち組」。だからベースライン平均が+0.063%とプラス。フェアな判定は「ベースライン比の上乗せ」であり、そこで本戦略は負ける。新規上場（ソシオネクスト2022, KOKUSAI2023）は履歴が短い。
- 日足ベース。寄り直後の値動き詳細（ティック/1分足）は別途必要なら `stocks_intraday` で。

## 7. 次のアクション候補
- **翌寄り手仕舞い**を主戦略に、-2.0%閾値で1分足エントリ精緻化（寄り成りでなく寄り後の押し目）。教訓4に沿いティック/板で底打ちタイミングを取れるか。
- 個別の自己ギャップ（self_gap）と市場ギャップの併用フィルタ（市場は崩れたが自分は崩れていない銘柄 vs 連れ安銘柄）でエッジが分離するか。
- VIX急騰・米SOX前日リターンを条件に加えた条件付き検証（今日のような「海外発・円中立」の日に限定すると改善するか）。
