# 日経225 ドローダウン→回復期間・回復後リターンの過去傾向

## 目的・問い
2026年6月末からの日経下落局面で「これだけ落ちた後、過去は回復までどれくらいかかったか／
下落後の先行きは上か下か」を過去傾向から出し、レバレッジ信用ポジションを**キープすべきか**の判断材料にする。
（保有者のレバは50%下落まで耐える水準）

## データ
- `index_daily` の `N225` 日足、2016-05-10〜2026-07-16（2,491営業日）
- **限界**: JQuants由来で履歴は約10年。**この期間は日経16,000→72,000の構造的強気相場**で、
  1990バブル崩壊(回復に約34年)・2000-03のような**恒久的弱気相場を含まない**。
  「必ず回復した／押し目買いが常に有利だった」は**強気レジーム限定の結論**（生存バイアス）。深いDDのNも少数。

## 解釈・示唆（ポジション判断）
1. **深さの評価**: 今の-7.6%は過去10年で見れば「浅い調整」。margin耐性50%は、
   このサンプル最悪のコロナ-32%でも追証にならない水準＝**サンプル内のどの下落でも生存可能**。
2. **回復時間**: -7%級は中央値約4ヶ月。ただし2018型なら8ヶ月、深化して-20%級に入れば半年〜2年。
   レバは生存できても**回復までの時間＝金利コストと含み損ストレス**は覚悟が要る。
3. **先行きの偏り**: -7%下落後の平均は上向き（保有・押し目有利）。ただしこれは**強気相場限定**。
4. **⚠️ 最大の注意 — 個別ポートフォリオはβが違う**: 保有が非鉄・半導体中心なら日経より高βで、
   実際のDDは指数-7.6%より**深い**（半導体は下げがきつい）。回復もセクター次第。指数の結論を
   そのまま当てはめず、**自分の建玉ベースのDDと耐性**で見る必要がある。

## 結論
- サンプル内では「-7%程度で売らず保有」が有利、レバも生存余地大。**指数だけ見れば保有継続を支持**。
- ただし (a) 履歴が強気相場のみ＝構造的弱気は未表現、(b) 個別建玉は高βでDDが深い可能性、の2点で
  「無条件ホールド」とは言い切れない。次アクション: **保有銘柄ベースのDD・50%耐性までの距離**を実測する。
