# 非鉄金属8銘柄 ロングショート戦略 エッジ探索

**日付**: 2026-05-22
**対象**: 非鉄金属8銘柄 (5706 三井金属 / 5711 三菱マテリアル / 5713 住友金属鉱山 / 5714 DOWA HD / 5016 JX金属 / 5801 古河電工 / 5802 住友電工 / **5803 フジクラ**)
**期間**: 2025-04-01 〜 2026-05-21 (約13ヶ月, 共通273営業日)
**データ**: OMEN PostgreSQL `stocks_intraday` / `stocks_daily` (JQuants由来, JST直接)

## 1. 目的・仮説

非鉄金属セクター8銘柄を使ったマーケットニュートラルなロングショート戦略でエッジが取れるか体系的に検証する。仮説候補:

- **H1**: クロスセクション平均回帰 (寄→引リターンの逆張り)
- **H2**: 寄付ギャップフェード
- **H3**: 前場急進フェード (後場でリバーサル)
- **H4**: 高相関ペアスプレッドZスコア平均回帰

加えて、当初の単純L/S戦略が機能しない場合、**1分足ベースのペアスプレッド戦略** (全28ペア × Zスコア閾値最適化 × マルチペア並列) で再検証する。

## 3. 手法・パラメータ

### Step1: クロスセクション戦略スクリーニング (`02_strategy_screening.py`)
- グループ別 (miner 5 / wire 3) で各日 top1/bottom1 のドルニュートラル L/S
- コスト: 10 bps 片道 (= 20 bps/leg, 40 bps/pair往復)

### Step2: 単純モメンタム L/S 詳細評価 (`03_strategy_momentum_xs.py`)
- 前場リターン (open→11:30) ランクで後場 (12:30→引け) にエントリ・引けクローズ
- コスト感度: 0/5/10/15/20 bps 片道

### Step3: 全28ペア × 1分足 Zスコア戦略 (`04_pair_scan_intraday.py`)
- 各日 朝9:00-10:00 のスプレッド (= log(A) - β·log(B)) で mean/std 算出
- β は過去20日の日次log価格回帰係数 (前日終値で確定)
- 10:00以降に |Z| > entry_z でエントリ、|Z| < exit_z または 15:25 でクローズ
- パラメータ: entry_z=2.0, exit_z=0.5, コスト=8 bps片道

### Step4: マルチペア並列 + Z閾値最適化 (`05_multipair_portfolio.py`)
- z_grid = {(2.0, 0.5), (2.5, 0.5), (3.0, 0.5), (2.5, 0.0), (3.0, 0.0)}
- 各ペアで最良パラメータを選び、Top-K (K=3, 5, 8, 12) を等ウェイト並列
- コスト感度: 3/5/8/10/12/15 bps 片道

## 4. 主要発見

### 4.1 単純なクロスセクション L/S は機能しない
- **前場ランク → 後場リターンのスピアマン相関: ρ=+0.000 (t=0.00, p=0.9995, N=267日)**
- モメンタムもリバーサルも統計的に存在しない
- コスト前で見ても日次エッジは ±0.09%/日と小さく、10 bpsコストで完全に負け

## 5. 解釈・示唆

1. **「強い銘柄は強いまま」の単純モメンタムは効かない** — pre/post 前場リターンに線形な情報は無い (ρ=0)。だがペアスプレッドの平均回帰には明確なエッジがある。これは「銘柄個別の中期トレンド」と「日中の相対値の短期均衡」が別々に動いている証拠。
2. **フジクラを含むペアが圧倒的に有効** — フジクラは2025-2026のAIテーマでセクター内突出株。周辺銘柄との相対値で日中に過剰反応が起きやすく、平均回帰の材料になる。逆に高相関の銅鉱山ペア (57110-57130) は安定相関しすぎて、Zスコアの絶対値が小さく取引コストに負ける。
3. **コストが効く** — 平均保有時間 130-150分、1日1往復程度の頻度では、片道5bps以上で実効リターンが急速に削られる。**機関投資家・大型口座での運用が前提**となる。
4. **2026年2月に最大DD (-12.9%)** — レジーム転換的なドローダウン。直近5月に+7.7%のV字回復。

## 6. 限界・注意点

- **N=253営業日 (約13ヶ月)** は短い。Sharpe推定の標準誤差は約 1/√N ≈ 0.06、すなわち真のSharpeは +0.25 ± 0.12 程度の不確実性。
- **β=20日ローリング**は単純な仮定。共和分検定 (ADF, Johansen) を経ていない。**真にスプレッドが定常か未検証**。
- **執行モデルが甘い**: 1分足の `close` で約定可能と仮定。実際には Bid/Ask スプレッド・部分約定・遅延あり。特にフジクラのVWAPでなく終値で約定する仮定は楽観的。
- **取引コスト 8 bps片道**は「機関投資家ベース・スプレッド込み」前提。個人投資家(手数料数bps + スプレッド5-10bps)では収益化困難。
- **ペアの将来再現性**: フジクラのAIテーマ依存。テーマ終焉でレジーム転換すれば、Zスコア平均回帰の母集団自体が変わる可能性。
