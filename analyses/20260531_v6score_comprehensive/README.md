# V6スコアリング包括的研究

## 分析の目的・仮説

既存の V4 (M+T+0.5S) / V5 スコアは週次(金曜)エントリーを前提に設計されている。
本研究では「日次エントリー」前提で最適なスコアリングを設計することを目的とする。

**仮説**: V4スコアの M (モメンタム) / T (トレンド) / S (需給) は情報量が異なり、
ボラティリティで調整したモメンタム (`r20_adj`) の方が予測力が高いのではないか。

## データ概要

| 項目 | 値 |
|---|---|
| ユニバース | 22銘柄 (半導体14 + 非鉄金属8) |
| 評価期間 | IS: 2022-01-01 〜 2023-12-31 / OOS: 2024-01-01 〜 2026-05-31 |
| サンプル数 | 23,601 (銘柄×評価日) |
| 保有期間 | 20日 (forward return) |
| 評価方法 | クロスセクショナル Spearman IC + Long-only Sharpe + L/S Sharpe |

## 手法・パラメータ

### 追加因子 (V4既存因子との比較)

| 因子 | 定義 |
|---|---|
| `r20_adj` | 20日リターン ÷ 20日年率ボラティリティ (ボラ調整モメンタム) |
| `vol_ratio` | 5日平均出来高 / 20日平均出来高 − 1 |
| `d75` | 現値 / MA75 − 1 (長期トレンド乖離) |
| `r60` | 60日リターン |

### 評価方法
- **IC分析**: 日次クロスセクショナル Spearman IC → ICIR (IC / IC標準偏差 × √252)
- **Long-only Sharpe**: スコア ≥ BUY閾値 のポジション
- **L/S Sharpe**: 上位3銘柄 Long / 下位3銘柄 Short

## 主要発見

### 1. IC分析 (クロスセクショナルアルファ)

| 因子 | 全期間 ICIR | IS ICIR | OOS ICIR |
|---|---|---|---|
| `r20_adj` (ボラ調整r20) | **3.00** | 1.74 | **7.30** |
| `d75` (長期トレンド) | **3.19** | 2.82 | 4.98 |
| `S` (需給スコア) | 3.29 | **4.64** | 1.18 |
| `T` (トレンドスコア) | 2.62 | 1.49 | 6.21 |
| `r60` (60日リターン) | 2.75 | 2.26 | 3.71 |
| `M` (モメンタムスコア) | 2.19 | 0.93 | 5.91 |

**S (需給) はISで強いがOOSで急落** → 信頼性が低い
**r20_adj はOOS ICIRが7.30で最強** → 最も安定したアルファ因子

### 2. スコア別 Long-only Sharpe

| スコア式 | IS Sharpe | OOS Sharpe |
|---|---|---|
| `r20_adj` 単独 | **4.13** | **9.83** |
| `M + vol_ratio` | 4.09 | 7.55 |
| `d75` 単独 | 3.37 | 7.63 |
| `r60` raw | 3.02 | 7.11 |
| V5b (M+0.5S) | 1.71 | 6.97 |
| V4 (M+T+0.5S) | 1.66 | 6.90 |

**r20_adj が IS/OOS 両方で最強** (V4比: IS +2.47, OOS +2.93)

### 3. グリッドサーチ (wM*M + wT*T + wS*S の最適重み)

IS+OOS 合算Sharpe最高:
- **wM=0.5, wT=0.5, wS=0** → IS=3.58, OOS=7.59 (計=11.17)
- **wM=0, wT=1.0, wS=0** → IS=3.58, OOS=7.49 (計=11.07)

→ **S (需給) は不要、T (トレンド) が有効**

### 4. クロスセクショナル L/S (V4スコア, 上位3 Long / 下位3 Short)

| 期間 | L/S Sharpe | Long Sharpe | Short Sharpe |
|---|---|---|---|
| IS(22-23) | **2.78** | 5.13 | 3.19 |
| OOS(24-26) | **5.63** | 7.98 | 3.58 |
| 全期間 | **3.70** | 6.23 | 3.47 |

IS期間でも L/S Sharpe=2.78 → 市場β除去後も純粋なアルファが存在する

### 5. IS/OOS逆転の解釈

- IS (2022-2023): 急落→回復相場、モメンタム戦略が機能しにくい環境
- OOS (2024-2026): AI/半導体ブーム、強い上昇トレンドでモメンタムが機能
- **L/Sで見るとIS Sharpe=2.78** → モメンタムアルファは IS でも存在、Long-onlyの弱さは相場環境によるもの

## V6スコア設計案

### 推奨: r20_adj ベース

```python
# ボラ調整モメンタムを離散スコア化
r20_adj = r20 / vol20  # vol20 = 20日年率ボラティリティ

R = (2 if r20_adj >= 0.15 else
     1 if r20_adj >= 0.05 else
     -2 if r20_adj <= -0.15 else
     -1 if r20_adj <= -0.05 else 0)

# 長期トレンドフィルター (IC安定)
T_filter = 1 if d75 > 0 else -1  # MA75との乖離符号

V6 = R + 0.5 * T_filter
# BUY: V6 >= 1.5
# ゲート: N225(60日) < -3% → V6 > 1 を 1 に抑制
```

### 代替案: 連続値 V6

```python
V6_raw = r20_adj + 0.5 * d75 * 10  # 連続値シグナル
# BUY: V6_raw >= 0.2 (パーセンタイルで調整)
```

## 解釈・示唆

1. **ボラティリティ正規化の効果**: `r20` をボラで割ることで、高ボラ銘柄のノイズを除去できる。半導体銘柄は日常的にボラが高いため特に有効。

2. **T (トレンド) の有効性**: MA25/MA75乖離スコアはICIR=2.62で安定。V4の T 設計は妥当。しかし S (需給) は IS/OOS で挙動が異なり信頼性に疑問。

3. **L/Sの有効性**: Short サイドの Sharpe=3.19 (IS) は、低スコア銘柄がアンダーパフォームする傾向を示す。デイリーのスコアを使ったL/Sポートフォリオが最も市場中立になる。

## 限界・注意点

- ユニバースが22銘柄と小さい → クロスセクショナルL/Sは各サイド3銘柄のみ
- `r20_adj` の IS/OOS パフォーマンス差が大きい → `vol20` が市場全体の変動を含む
- IS期間 (2022) は急落相場で、モメンタム戦略全般が苦しい → 環境バイアスあり
- グリッドサーチは IS で最適化 → OOSへのオーバーフィットリスク
