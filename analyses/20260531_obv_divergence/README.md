# OBVダイバージェンス 定量検証（中小型株）

> **結論: OBVダイバージェンス逆張りシグナルは機能しない。方向は逆で統計的に有意なマイナス。**
> PDFの「中小型株で有効」は実証的に誤り。Bearishシグナル(価格上昇+OBV下落)が実際は続伸。

## 1. 目的

PDF主張の検証: 「価格横ばい/下落中にOBVが上昇=買い集め(Bullish)→後に上昇」
「価格横ばい/上昇中にOBVが下落=分配(Bearish)→後に下落」

中小型株(TOPIX Small 1/2/Mid400) × 流動性1〜500億円 × 2021-2026

## 2. 設計

- **OBV** = cumsum(sign(close変化) × volume)
- **ダイバージェンス観測期間**: 20営業日
- **Bullish**: price_chg_20 < -2% かつ OBV_chg_20 > 0 → Long候補
- **Bearish**: price_chg_20 > +2% かつ OBV_chg_20 < 0 → Short候補
- **L/S**: Bullish群平均 − Bearish群平均、週次集計、コスト20bps後
- ユニバース: 1,543銘柄、Bullish 27,086件、Bearish 25,554件

## 3. 結果

### L/S（Bullish Long − Bearish Short）コスト後

| 保有 | ALL Sharpe | IS Sharpe | OOS Sharpe | t値 |
|---:|---:|---:|---:|---:|
| 5日 | **-1.32** | -1.15 | **-1.69** | -3.06 |
| 10日 | -0.69 | -0.20 | -1.54 | -1.59 |
| 20日 | -0.76 | -0.14 | -1.63 | -1.75 |

**全期間・全保有期間で明確にマイナス**。IS→OOSで悪化（レジーム依存ですらなく構造的に誤り）。

### シグナル別20日後平均リターン（コスト前, TOPIX超過bps）

| シグナル | n | 平均bps | t値 |
|---|---:|---:|---:|
| Bullish (+1) = Long候補 | 23,639 | **+14.1** | 1.79 |
| **Bearish (-1) = Short候補** | 20,899 | **+50.7** | **6.28** |
| NoSignal (0) | 385,298 | +22.7 | 12.36 |

## 4. 主要発見

### Bearishシグナルが最も強い上昇を見せる（逆説的）

PDFが「下落するはず」と予測する **Bearish銘柄（価格上昇中にOBV下落）が+50.7bps、t=6.28で最も強く続伸**。

理由:
- `price_chg_20 > +2%` という条件が**単純な価格モメンタム**（過去20日上昇）を選択している
- OBVが下落していても価格が上昇している銘柄 = **「大口が売っているのに上昇」ではなく、
  「需給より強い買い圧力でOBVが下落に見えるだけのモメンタム株」**
- すなわちOBV成分には独自の情報量がなく、価格変化率の符号だけが効いている

### OBV独自成分はゼロ

Bullish (+14.1bps) と NoSignal (+22.7bps) の差はわずか-8.6bps。
Bullish = 「過去20日価格下落(-2%)銘柄」であり、その後も上昇が弱い = **逆張りは効かない**。

### セクター中立化の効果なし

セクター中立化（ALL_SN）でも結果は全く同一 → 業種ベータの問題ではなく根本的にシグナル方向が誤り。

## 5. 解釈

OBVダイバージェンスは「価格とOBVの乖離が将来の価格修正を予測する」と主張するが:
1. 価格下落+OBV上昇（Bullish想定）→ 現実は続落傾向（価格のモメンタムが優勢）
2. 価格上昇+OBV下落（Bearish想定）→ 現実は続伸（価格のモメンタムが優勢）

**日本の中小型株でもモメンタムはOBVダイバージェンスより強力で、逆張りシグナルとして使うと逆効果。**

もし「Bearish股 = Long」「Bullish株 = Short」という逆方向のモメンタム戦略にすれば
Sharpe +1.32 程度になるが、これは単純な20日リターンモメンタムと等価であり、OBV固有の情報ではない。

## 6. 結論

**第十弾⛔: OBVダイバージェンス逆張りにエッジなし（むしろ有意なマイナス）**

PDFの主張が実証的に誤っていることを確認。
エッジが出るとすれば「Bearish=Long」という順張りモメンタムだが、それはOBV関係なし。
