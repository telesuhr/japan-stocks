# AI半導体サプライチェーン リードラグ分析

**実施日**: 2026-06-03
**対象期間**: 2018-01-04 〜 2026-06-02 (日足 2,050日)
**対象銘柄**: 17銘柄+SBG(18銘柄)を4層に分類
**前回分析**: [20260421_semiconductor_leadlag](../20260421_semiconductor_leadlag/) — 1分足版。同結論の日足追証。

## 分析の目的・仮説

「AI/半導体バリューチェーンで上流(材料・装置)→下流(AI/DC)に資金が順に流れる規則性はあるか?
 SBGを含め上流→下流のリードラグ・循環が日足スケールで存在するか」を検証。

前回(1分足)は「共通因子で全銘柄が同時に動く・リードラグなし」で棄却済み。
前回の"次の候補"として明示された**日足スケール**を今回検証。

## 層構成 (4層 等ウェイト)

| 層 | 銘柄 | 代表ADV |
|---|---|---|
| ①上流(材料・ウェハ・基板) | 信越化学4063・SUMCO3436・東京応化4186・イビデン4062 | 320〜938億 |
| ②製造装置 | 東エレ8035・アドテスト6857・レーザーテック6920・ディスコ6146 | 1,386〜2,537億 |
| ③デバイス・部品 | ルネサス6723・ローム6963・村田6981・TDK6762・京セラ6971 | 156〜503億 |
| ④AI/DC下流 | SBG9984・ソフトバンク9434・NTT9432・KDDI9433・さくら3778 | 71〜3,646億 |

## 手法

- 各層の等ウェイト日次リターンを算出 (|ret|>50%は除外)
- 全ペアのクロス相関を lag=-5〜+5日で計算 (Pearson r)
- 翌日予測力: 今日の層リターン→翌日の別層リターン (Spearman Rank IC, t統計量)
- IS: 2018-2021 / OOS: 2022-2026
- SBG単独クロス相関
- ローリング相関 120日窓 (AI相場前後の変化確認)

## 主要発見

### 1. 日足でもリードラグは存在しない ❌

全層ペアのクロス相関 lag+N ≈ lag-N で完全対称:

| ペア | lag+1 | lag0 | lag-1 |
|---|---|---|---|
| 装置↔上流 | 0.773 | ≈0.773 | 0.773 |
| 装置↔部品 | 0.725 | ≈0.725 | 0.725 |
| 装置↔AI下流 | 0.479 | ≈0.479 | 0.479 |

**lag=+1と lag=-1がほぼ同値** → 一方が他方に先行しているのではなく、
SOX/NASDAQ/USD-JPY などの共通因子が全層を同時に動かしている。

### 2. 翌日予測力ゼロ ❌

全12ペアの Rank IC:

| 先行層 | 後続層 | IC | t値 |
|---|---|---|---|
| 装置 | 部品 | +0.0139 | +0.63 |
| 部品 | AI下流 | +0.0099 | +0.45 |
| 上流 | AI下流 | -0.0191 | -0.87 |
| 上流 | 装置 | -0.0258 | -1.17 |

**全12ペアが有意水準(|t|<2.0)内。|IC|最大0.026 → 予測力ゼロ。**
「装置が強い日の翌日に部品を買う」など上流→下流リレー戦略は機能しない。

### 3. SBGも例外なし ❌

SBGのクロス相関: lag=±2が「★」になるが差異は0.001以下。
lag=0を有意に上回るlagは存在せず、他の半導体層と同じタイミングで動く。

### 4. AI相場(2023-)でも構造は変わらない

| 期間 | 装置↔AI下流 lag0 | lag+1 |
|---|---|---|
| IS 2018-2021 | +0.498 | +0.498 |
| OOS 2022-2026 | +0.467 | +0.467 |
| AI相場以前 2018-2022 | +0.492 | +0.492 |
| AI相場 2023-2026 | +0.466 | +0.466 |

lag0≈lag+1 の構造はAI相場前後で不変。相関水準は若干低下しているが同時動作の性質は維持。

## 解釈・示唆

**AI半導体バリューチェーンはサプライチェーン上下ではなく「AIテーマ」という共通因子で一塊で動く。**

- 個別銘柄レベルでの「装置が動いたから次は部品を買う」リレートレードは日足でも不可
- SBGも例外でなく、Armを通じて同じAIテーマに乗っている
- AI相場開始で変化したのは相関水準ではなく相関の密度(より強連動になった感はない)

**利確タイミングの含意**:
リードラグを使った先回りは不可。「電機・精密セクター全体」のモメンタムが崩れたとき
(=trailing-3m相対強さがtop-3から脱落したとき)が乗換シグナル。
→ 先行する個別銘柄を観測するのではなく、**セクター全体のRS順位を監視する**のが正解
(20260603_sector_rotation_17 で検証済みの「上位3業種保有・順位陥落で乗換」ルールと整合)

## 限界・注意点

- 等ウェイト層リターンのため流動性格差(SBG3,646億 vs さくら71億)が混在
- SBGはAI/DC下流に分類したが厳密には投資持株会社(Arm保有)。装置層に近い行動かも
- クロス相関の「対称性」はautocorrelationが別の理由で生じている可能性もある (但し翌日IC=0が独立確認)
- 月次・四半期スケールでのサイクルは未検証 (日足では消えている可能性)
