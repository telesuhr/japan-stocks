# PTS引け買い戦略検証

## 目的・仮説
PTSは引け値より高値で取引される傾向があるため、
「引けで買い → PTSで close+α%の指値を差しておく → 刺されば利確」戦略が成立するか検証する。

実績: イビデン(4062)で日々1〜2%程度安定して抜くことに成功（ユーザー実績）。
仮説: 各時刻の最終約定値(pts_last)でなく「その日のPTSピーク」が閾値を超えた確率（ヒット率）が
      コストを上回るエッジを持つ銘柄が存在するか。

## データ
- テーブル: `aukabu.pts_quotes`
- 期間: 2026-06-19 〜 2026-07-03（10営業日）
- 銘柄: 主要50銘柄（プライム売買代金上位）
- edge_pct = (pts_last - close) / close × 100

## 手法
1. 時間帯別（17:00〜23:00）の edge_pct 分布を集計
2. 17:00スナップでの日別勝率・平均リターンを算出
3. 往復コスト0.2%を控除してネットP&Lを評価

**発見**: PTS+2%超の急騰日は翌朝に反落する傾向（米国先取り→反落）。最適指値は+1〜1.5%。

### イビデン持ち越し日の実績
3回の持ち越し全て翌朝ギャップダウン（平均-3.89%）。
高ベータ銘柄は「PTSが上がらない日=グローバルリスクオフ」と連動するため非対称リスクが大きい。

## 所見・結論

### ✅ 戦略は成立（初期分析の誤り訂正）

**戦略の本質（初回分析の誤りを訂正）**
- 誤: 17:00の市場価格で売却 → エッジなし
- 正: 引けで買い・PTSで close+α%の指値を差す → ヒット率64〜80%でエッジあり

1. **指値+1%のヒット率**: KOKUSAI 80%、村田 70%、イビデン 64%
2. **持ち越しリスクの非対称性**: PTSが弱い日は翌朝も弱い（高ベータ銘柄ほど顕著）
3. **最適指値帯**: +1〜1.5%（+2%超は翌朝反落リスクが高い）
4. **推奨銘柄**: 村田(安定・流動性大) > KOKUSAI(ヒット率最高・流動性十分) > イビデン(高収益だが持越しリスク大)
5. **株式分割汚染**: 分割日のedge_pctに-75〜90%の外れ値あり（5801/5802/3110）。分析前に `edge_pct BETWEEN -10 AND 20` でフィルタ必須

### 運用上の注意
- 持ち越し時はPTSで引け値-1%等のストップを設定してリスク管理
- サンプル期間10日のみ。米国株急落局面（VIX急騰期）での挙動は未検証
- pts_lastは30分スナップのため実際のPTS高値はさらに高い可能性（ヒット率は保守的推定）

## 参考クエリ

```sql
-- 時間帯別分布
SELECT snap_hm,
       ROUND(AVG(edge_pct)::numeric,2) as avg,
       ROUND(PERCENTILE_CONT(0.5) WITHIN GROUP (ORDER BY edge_pct)::numeric,2) as median,
       ROUND(100.0*SUM(CASE WHEN edge_pct>0 THEN 1 ELSE 0 END)/COUNT(*),1) as pct_pos
FROM aukabu.pts_quotes
WHERE pts_last IS NOT NULL AND edge_pct IS NOT NULL
GROUP BY snap_hm ORDER BY snap_hm;

-- 株式分割汚染の除外例
WHERE edge_pct BETWEEN -10 AND 20
```
