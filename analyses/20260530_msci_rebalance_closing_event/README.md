# MSCIリバランス「引けイベント」と採用銘柄の公表→発効リターン検証

> **結論（暫定・要サンプル拡充）:**
> 1. 「公表後に採用銘柄を買って発効で売る」は TOPIX比で大負け（9銘柄平均−7.6%、勝率33%）
> 2. エッジは完全に**公表"前"**に集中（公表10日前まで100%上昇、+16.5%超過）。「噂で買い事実で売る」
> 3. **だがこの公表前ドリフトは選択バイアス**（上がった銘柄が採用される）＝採用リストが事後確定の
>    ため、そのままでは取引不能。本当のエッジにするには「採用候補を市場より早く予測」が必須
> 4. 5/29引けジャンプ現象は実在・検出可能だが翌日リターンにエッジ無し（勝率48%）
> n=9と少なく統計的確証は無い。「MSCI採用は素朴には取れない、候補事前予測が唯一の道」が要点。

## 1. 着想

2026-05-29 のMSCIリバランスで、イビデン/キオクシアが大引け(15:30 クロージングオークション)で
巨大出来高を伴い跳ねた（イビデン 15:24→15:30で +4.5%、引け1本で461億円）。
「毎度こうなるのか、事前に取れるのか」を検証する。

## 2. 二段構えの検証

### 段階A: 代理シグナル（引け出来高スパイク）でリバランス痕跡を全期間検出
- 各(code,date)で close_pct = 引け(15:30)出来高 / 当日総出来高
- close_pct≥8% かつ 過去中央値比≥4倍 を「イベント」とし、流動性≥10億円で抽出
- データ: stocks_intraday 1分足 2024/05〜2026/05（集計 142万 code-day）

### 段階B: Web収集した実採用銘柄で「公表→発効」リターンを直接検証
- MSCIスタンダード指数の新規採用を複数ソースで裏取り（announce=公表/effective=発効）:
  - 2026-05 (5/12→5/29): 古河電工5801, 三井金属5706
  - 2025-11 (11/06→11/21): 荏原6361, JX金属5016, キオクシア285A, 西武HD9024
  - 2025-08 (08/08→08/26): 川崎重工7012, 良品計画7453
  - 2025-02 (02/11→02/28): 東京メトロ9023
  - ※レゾナック4004はDBデータ整合性の都合で除外、計9銘柄
- 全てTOPIX超過リターン（個別 − TOPIX）で計測

## 3. 主要発見

### 段階A: リバランス現象は実在し、検出できる
- イベントは **MSCIリバランス月(2/5/8/11月)に明確に集中**（5月87件/2月73件 vs 6月25件/7月23件）
- 件数最多日は 2026-05-29（35件）。現象は毎回起きている
- **だが翌日リターンにエッジは無い**: 引け上昇イベントの翌日寄→引は勝率48.6%（コイン以下）、
  大ジャンプ>200bpsは2年で2件のみ。平均値は数件の外れ値に依存し、安定エッジではない

### 段階B: 採用銘柄の公表→発効リターン（TOPIX超過, n=9）

| 計測 | 平均 | 中央 | 勝率 |
|---|---:|---:|---:|
| R1 公表ドリフト（公表翌寄→発効前日引） | **−6.5%** | −8.6% | 22% |
| R2 公表→発効引け | **−8.1%** | −7.5% | 22% |
| R3 発効当日（寄→引） | +0.6% | +0.9% | 56% |
| R4 発効翌日（引→翌引） | −0.3% | −0.5% | 43% |

- **「公表後に買って発効で売る」は逆に大負け**。9銘柄中7銘柄がTOPIX下回り
- 古河電工は公表(5/12)前日5/11に+16%、当日+15%と**公表前に織り込み済み**→公表後は失速
- 唯一順方向は R3「発効当日 寄→引」（勝率56%, +0.6%）。引けパッシブ買いの当日先回りは
  わずかにプラスだが小さい

## 4. 解釈・示唆

1. **MSCI採用は「噂で買って事実で売る」の典型**: 採用予想は大手証券が事前公表し（株探等）、
   公表時点では織り込み済み。公表をシグナルに買うのは出遅れで、むしろ高値掴み。
2. **5/29引けジャンプの正体**: あれはMSCIの買いではなく、発効日当日のクロージング
   オークションに集まった需給の一時的攪乱。翌日には平均回帰し、事前に方向を取れない。
3. **発効当日の寄→引(R3)だけが微かに順方向**: パッシブの引け買いを当日ザラ場で先回りする
   動き。ただし+0.6%では執行コスト・スリッページで消える水準。
4. これは**「MSCIリバランスは個人が事前に取れる甘い需給イベントではない」**ことを示す。
   機関の先回りが効率的で、公表時点では旨味が抜けている。

## 5. 限界・注意点（結論は暫定）

- **n=9は致命的に少ない**: 統計的確証は無い。t検定も無意味な水準。方向性の示唆のみ。
- **採用リストが直近4回・スタンダード指数のみ**: 過去5-10年分、除外銘柄、small cap指数
  への昇格/降格まで集めて初めて本検証になる。
- **公表日の厳密性**: 公表は日本時間早朝（前営業日深夜）。「公表翌営業日寄り」で入る前提だが、
  実際は公表当日にギャップで動く分を取り逃している可能性（=R1がさらに悪化する方向）。
- **段階Aの代理シグナルとBの実採用が未接続**: 引けスパイク検出銘柄が実際にMSCI採用/除外
  だったかの照合をしていない（采用リストが少なすぎて統計にならないため）。
- 生存者バイアス・指数の種類（ACWI/Standard/Small）混在の可能性も残る。

## 5b. 追加検証: 公表「前」の予想織り込みドリフト（重要）

「公表後に買うのが負けなら、エッジは公表"前"にあるのでは」という仮説を、各採用銘柄の
**正式公表日の前N営業日→公表日**のTOPIX超過リターンで検証した（予想織り込み局面）。

| 局面 | 平均 | 中央 | 勝率 |
|---|---:|---:|---:|
| **公表20営業日前 → 公表** | **+28.7%** | +9.4% | 89% |
| **公表10営業日前 → 公表** | **+16.5%** | +12.7% | **100% (9/9)** |
| 公表後 → 発効前日 | −7.6% | −8.6% | 33% |
| 公表 → 発効引け | −7.6% | −7.5% | 33% |

- **エッジは完全に公表前に集中**。公表10日前まで9銘柄全てがTOPIXを上回り(+16.5%)、
  公表後は全て失速。キオクシアは公表前20日で+114%超過と極端
- きれいな反転（公表前＋・公表後−）は「噂で買って事実で売る」を定量的に裏づけ

### ⚠️ ただし致命的な選択バイアス（これが結論）

この公表前ドリフトは **そのままでは取引できない**。MSCIは「浮動株時価総額が閾値を超えた
＝株価が上昇した」銘柄を採用する。つまり **「上がったから採用された」のであって、
「採用されるから上がった」のではない**。採用銘柄リストは事後的にしか確定せず、
「公表前に上がっている」のは選択バイアスそのもの（survivorship/look-ahead）。

**本当のエッジにする条件**: 「どの銘柄が次に採用されるか」を市場・ブローカーより早く
予測できること。MSCIの採用は浮動株時価総額の閾値ルールなので、候補を毎月スクリーニング
して先回りできれば、この+16.5%の一部を取れる可能性がある。これが唯一の道筋。

## 6. 次のアクション候補

- ✅ **MSCI採用候補の事前スクリーニング（本命）**: 浮動株時価総額をDB(stocks_daily×発行株数)で
  推定し、MSCI採用閾値(おおよそ大型株カットオフ)に接近している銘柄を毎月リストアップ。
  「市場が予想する前」に候補を保有できれば +16.5%ドリフトの一部が取れる。これが唯一の本筋。
  ただし浮動株比率データ(symbol_masterに無い)の入手が課題。
- 🔍 採用/除外リストを過去5-10年Web収集してn拡充（現状n=9で暫定）。除外銘柄のshort side も
- 🔍 発効当日 寄→引(R3, 唯一の事後順方向+0.6%)を分足で深掘り（引け前エントリーの執行性）
- ❌ 「公表後に買って発効で売る」素朴な戦略は見送り（TOPIX比 −7.6%）
- ❌ 「公表前ドリフトをそのまま買う」も不可（選択バイアス＝採用が事後確定のため取引不能）
