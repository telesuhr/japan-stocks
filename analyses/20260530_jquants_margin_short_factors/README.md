# JQuants信用残ファクターのクロスセクション検証

> **結論: 今セッション初の、ベータ中立で生き残ったエッジ。** 信用倍率(買残/売残)の低い銘柄を
> Long・高い銘柄をShortする週次LSスプレッドが **年率Sharpe ~1.6（コスト40bps/週控除後）、IS +1.4 /
> OOS +1.9 で一貫**。経済的意味も明快=「信用買いの重し（margin overhang）」効果。ただし5ファクターは
> 相関しており実質1-2エッジ、サイズ/セクター中立化は未実施。昇格には追加検証が必要だが筋は良い。

## 1. 目的

板シグナル⛔・ブレイク⛔・平均回帰⛔（いずれも単純価格テクニカル）の3連敗を受け、
**価格以外の構造的エッジ**=JQuants固有データ（信用需給）を検証する。前段の教訓
（生Sharpeは市場ベータの幻）を踏まえ、**最初からロングショート分位スプレッド＝構造的
ベータ中立**で測る。

## 2. データ・手法

- データ: `public.jquants_margin_interest`（週次・信用残・全銘柄, 2021-01〜2026-05, 110万行）
  + `stocks_daily`（フォワードリターン・流動性）
- ユニバース: 普通株・流動性≥10億円/日 → **746銘柄・283週**
- カラム: `long_vol`(信用買い残), `shrt_vol`(信用売り残)
- 検証ファクター（週次クロスセクション）:
  - `margin_ratio` = long_vol/shrt_vol（信用倍率）
  - `long_chg` / `short_chg` = 各残高の前週比
  - `short_ratio` = shrt_vol/(long+shrt)
  - `net_chg` = long_chg − short_chg
- 評価: 各週10分位 → 翌週(5営業日)リターン。**Q10−Q1のLSスプレッド**週次系列の年率Sharpe。
  コスト週40bps（両サイド往復）控除。IS(2021-23)/OOS(2024-26)分割
- 空売り残報告(short_sale_report)は0.5%超義務の疎データで全銘柄網羅せず → 本検証では除外

## 3. 主要発見

LS = Q10(高ファクター値)−Q1(低ファクター値)。**全ファクターでマイナス → 符号反転が実行方向**。

### 実行方向（低分位Long/高分位Short）の年率Sharpe（コスト後）

| ファクター | 週次bps | **ALL** | IS(21-23) | OOS(24-26) | LS勝率 |
|---|---:|---:|---:|---:|---:|
| margin_ratio（信用倍率） | +61.6 | **+1.61** | +1.39 | **+1.85** | 67% |
| long_chg（信用買増） | +58.2 | +1.50 | +1.31 | +1.78 | 64% |
| net_chg（需給変化） | +50.6 | +1.40 | +1.20 | +1.83 | 61% |
| short_ratio（売残比率） | +43.6 | +1.17 | +0.95 | +1.55 | 67% |
| short_chg（信用売増） | +32.6 | +1.13 | +0.93 | +1.43 | 64% |

（LS勝率は元のマイナススプレッドが負ける率=実行方向の勝率）

## 4. 解釈・示唆

1. **「信用買いの重し」効果が本物**: 信用買い残が積み上がった銘柄（高margin_ratio）は、
   将来の反対売買（決済売り）が上値を抑え劣後。信用売りが厚い銘柄は踏み上げ期待で優越。
   日本の個人信用取引の構造（6ヶ月期日・追証）に根ざした需給効果で、消えにくい性質。
2. **IS/OOS一貫、しかもOOSで強化**: これまでの戦略（OOS偏在・レジーム依存）と決定的に違う。
   2024-26で +1.85 と最も強い。直近で効いているのは実運用上ありがたい。
3. **構造的ベータ中立**: LS設計なので市場ベータはゼロ。前段で平均回帰が陥った「ベータの幻」
   を最初から回避している。純粋なクロスセクションα。
4. **方向転換の成功**: 「単純価格テクニカルではなく、構造的需給データにエッジがある」という
   仮説が当たった。既存昇格戦略（決算イベント・信用需給系）と整合的。

## 5. 限界・注意点（過信しない）

- **5ファクターは独立でない**: margin_ratio / long_chg / net_chg は全て信用買い側の積み上がりを
  測っており、相関が高い。**実質的には1〜2個のエッジ**（「信用買い overhang」が主因）。
- **サイズ/セクター中立化が未実施**: margin_ratio が小型株や特定セクターに偏っている可能性。
  Sharpe1.6 の一部がサイズ/セクタープレミアムの可能性 → 次段で中立化必須。
- **コスト感応度未検証**: 週40bps固定。信用倍率の極端な銘柄は流動性が薄く実効コストが高い恐れ。
  20bps刻みでコスト感応度を見る必要。
- **週次リバランス前提**: margin_interest は週次更新（金曜基準・翌週公表のラグ）。公表ラグを
  正確に織り込めているか（merge_asof backward 7日許容）は要精査。look-ahead の最終確認が必要。
- **746銘柄に限定**: 流動性10億ゲートで中大型中心。小型まで広げると効果が変わる可能性。
- これは**エッジ所在の確認**。昇格には(6)の追加検証クリアが条件。

## 6. 次のアクション候補（昇格への道筋）

- ✅ **サイズ・セクター中立化**: margin_ratio LS を時価総額・33業種で中立化し、純粋αが残るか確認。
  これが最優先（Sharpe1.6が本物のαか、size/sectorの混入かを切り分け）
- ✅ **公表ラグの厳密化**: margin_interest の実際の公表日（翌週第2営業日頃）を確認し、
  look-aheadを完全排除して再検証
- 🔍 コスト感応度（20/40/60bps）と、保有期間（1週/2週/4週）の感度分析
- 🔍 単一ベスト（margin_ratio）で日次ポートフォリオ化 → 実Sharpe・MaxDD・回転率
- 🔍 既存の信用系昇格戦略（bank_absorption）との相関 → 組み合わせで分散効果が出るか
- これがクリアすれば **strategies/ 昇格の最有力候補**（今セッション唯一の生存エッジ）
