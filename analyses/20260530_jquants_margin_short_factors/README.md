# JQuants信用残ファクターのクロスセクション検証

> **結論: 信用残ファクターにも実用的エッジは無い。** 週次LS分位スプレッドはコスト前ですら
> 最大Sharpe 0.41（margin_ratio）、週次の生スプレッドは僅か+12bps程度。週次リバランスの
> コスト40bps（両サイド）を払うと全ファクターで確実にマイナス。今セッション4戦略目も⛔。
>
> ※注記: 初版READMEで「Sharpe+1.6のエッジ」と誤記した。これはコスト控除後の負値を符号反転し
>   コストを引き直さなかった二重カウントの誤りで、本版で訂正した（下記「検証の教訓」参照）。

## 1. 目的

板シグナル⛔・ブレイク⛔・平均回帰⛔（いずれも単純価格テクニカル）の3連敗を受け、
**価格以外の構造的エッジ**=JQuants固有データ（信用需給）を検証する。前段の教訓
（生Sharpeは市場ベータの幻）を踏まえ、**最初からロングショート分位スプレッド＝構造的
ベータ中立**で測る。

## 2. データ・手法

- データ: `public.jquants_margin_interest`（週次・信用残・全銘柄, 2021-01〜2026-05, 110万行）
  + `stocks_daily`（フォワードリターン・流動性）
- ユニバース: 普通株・流動性≥10億円/日 → **1,170銘柄・256週**（factor行 122,720）
- カラム: `long_vol`(信用買い残), `shrt_vol`(信用売り残)
- 検証ファクター（週次クロスセクション）:
  - `margin_ratio` = long_vol/shrt_vol（信用倍率）
  - `long_chg` / `short_chg` = 各残高の前週比
  - `short_ratio` = shrt_vol/(long+shrt)
  - `net_chg` = long_chg − short_chg
- 評価: 各週10分位 → 翌週(5営業日)リターン。**Q10−Q1のLSスプレッド**週次系列のSharpe。
  IS(2021-23)/OOS(2024-26)分割。**コスト前と週40bps控除後の両方**を見る
- 空売り残報告(short_sale_report)は0.5%超義務の疎データで全銘柄網羅せず → 本検証では除外

## 3. 主要発見

LS = Q10(高ファクター値)−Q1(低ファクター値)。**コスト前のスプレッドが本質**。

| ファクター | コスト前 LS平均(bps/週) | **コスト前 Sharpe** | コスト40bps後 Sharpe(実行方向) |
|---|---:|---:|---:|
| margin_ratio（信用倍率） | +12.3 | **0.41** | −0.91 |
| long_chg（信用買増） | +6.9 | 0.37 | −1.77 |
| net_chg（需給変化） | +4.6 | 0.21 | −1.64 |
| short_chg（信用売増） | +0.9 | 0.04 | −1.68 |
| short_ratio（売残比率） | −15.9 | −0.44 | −0.66 |

- **コスト前ですら最大 Sharpe 0.41**。最良の margin_ratio でも週+12bpsの生スプレッドしかない
- 週次リバランス（毎週Q1とQ10を入れ替え＝両サイド往復）のコスト40bpsを払うと、どの方向でも
  確実にマイナス。**実行不可能**

## 4. 解釈・示唆

1. **弱いシグナルはあるが、コストに勝てない**: margin_ratio のコスト前Sharpe0.41は、信用倍率に
   ごく弱い予測力があることを示す（信用買いの重し効果は方向としては存在）。だが週12bpsでは
   週次入替コストに全く足りない。
2. **保有期間を伸ばせば可能性はある**: 週次リバランスが高コストの主因。月次（4週保有）にすれば
   コストが1/4になり、生Sharpe0.41が残るなら実行可能域に入るかもしれない → 次段の検証候補。
3. **4戦略目の⛔だが、これまでと質が違う**: 板/ブレイク/平均回帰は「方向予測力ゼロ or ベータの幻」
   だったが、信用残は「弱い予測力はあるがコストで消える」。**コスト構造を変えれば生きる余地**がある。
4. 単純な週次クロスセクションでは昇格基準（Sharpe2.0）に遠く及ばない。

## 5. 限界・注意点

- **週次リバランス前提が最大の制約**: コスト40bps/週は年率約20%の摩擦。月次・隔週なら大幅減。
- **コスト前0.41も低い**: 保有期間を伸ばしてもSharpe2.0には届かない見込み。過度な期待は禁物。
- **公表ラグ未精査**: margin_interest は週次（金曜基準・翌週公表のラグ）。merge_asof backward 7日
  許容で結合したが、実際の公表日を厳密に織り込めているかは未確認（楽観side=過大評価リスク）。
- **サイズ/セクター中立化未実施**: 弱いシグナルがサイズ/セクター由来の可能性も残る。
- 生存者バイアス（symbol_masterに上場廃止銘柄なし）も依然として存在。

## 6. 検証の教訓（初版の誤りについて）

初版READMEは LS_sharpe = −0.91 を「符号反転すれば実行方向は+0.91、さらに強い」と誤読し、
Sharpe+1.6 と記載した。これは **(1)コスト控除後の値を符号反転し (2)反転後にコストを引き直さ
なかった** 二重の誤り。正しくは「コスト前スプレッドの符号と大きさ」を見るべきで、それは
+12bps/週（Sharpe0.41）に過ぎなかった。
**教訓**: LS検証では必ず「コスト前の生スプレッド」を一次情報として確認し、コストは実行方向に
一度だけ引く。集計関数の符号と単位を出力段階で人間が検算する。

## 7. 次のアクション候補

- 🔍 **保有期間の延長（月次・隔週）でコストを下げて再検証**: margin_ratio のコスト前0.41が
  月次リバランスで実行可能域に残るか。これが信用残エッジ復活の唯一の道筋
- 🔍 サイズ/セクター中立化で margin_ratio の弱シグナルが純αか確認
- ❌ 週次リバランスの信用残LSは見送り（コストで確実にマイナス）
- ✅ **より強いシグナル源を探す**: 信用残は方向はあるが弱い。決算イベント系（既存昇格の
   earnings_pead/pre_earnings_drift系）の拡張など、コスト前Sharpeがもっと高い源泉に注力すべき
