# S高の翌ギャップは「市場が下げて始まる日」でも残るか

**結論: ✗✗ 残らない。前週の「S高は翌営業日の寄りで売る」は無条件では誤りで、市場ギャップ ≤ −1.5% の日には完全に反転する（翌ギャップ 平均 −1.43% / 中央値 −2.97% / 勝率21%、超過ギャップ t=+0.61 ＝プレミアム消滅）。さらにその日は寄→引が +1.67%（超過 +2.25%, t=3.77, 勝率65%）＝寄りが安値で日中戻す。⭐⭐ 副産物として「S高当日の出来高比」が翌ギャップの極めて強い説明変数（気配張り付き <0.5x で +8.03% vs 大商い >5x で +1.83%、単調、差 t=17.3）。**

## 目的・背景

2026-07-31 に日経が +4.03% 急騰し、キオクシア・太陽誘電・SBG・村田・アドバンテスト・イビデン・SUMCO 等
22銘柄（ADV≥3億）が S高引け。前日の [#20260731](../20260731_rebound_day_followthrough/) では
「S高銘柄は当日引けで投げるのでなく、**持ち越して翌営業日の寄りで売る**のが最良」
（翌ギャップ +3.66%、超大型 +3.79%、勝率66%）と結論していた。

ところがその晩、**CME 日経先物は 62,925 と現物 64,299 に対し −2.14%**。
前回のベースレートは**無条件平均**であり、市場全体が大きく下げて始まる日に外挿してよいか未検証だった。
「寄りで売る」という執行判断が、まさにその条件下で反転しないかを事前に検算する。

## 解釈

S高は「値幅制限で価格発見が打ち切られた状態」であり、翌ギャップはその未実現分の解放。
その解放量は (a) **未消化需要の大きさ**（＝出来高比、H3）と
(b) **翌朝のリスク許容度**（＝市場ギャップ）の積で決まる。

市場が −1.5% 以上下げて始まる朝は、寄付の板に**個別材料と無関係な換金売り・追証売り**が集中する。
S高銘柄は前日に急騰しているぶん「利が乗っていて売りやすい」ので、この換金売りの標的になりやすく、
未消化需要を食い尽くして寄値を押し下げる。その売りは寄付に集中する一過性のフローなので、
日中に個別材料へ価格が戻る（寄→引 超過 +2.25%）——という筋書きと整合する。

これは [#20260731](../20260731_rebound_day_followthrough/) の H3
「SOX急騰翌日は上げがギャップに集約し寄→引はマイナス」と**矛盾しない**。
あちらは市場が上げて始まる日の話で、本分析はその条件を外した場合の裏面にあたる。

## 限界・注意点

1. **市場 ≤ −1.5% は n=145（全体の2.3%）**。10年で年14回程度の稀事象で、寄→引 +1.67% の t=2.69 は
   頑健とまでは言えない。IS/OOS 分割は行っていない（層のnが割れて意味を成さないため）。
2. **TOPIX ギャップを市場ベンチにした**。日経225ギャップとは乖離しうる（2026-07-31 がまさに
   日経 +4.03% / TOPIX +1.29% と極端に乖離した日）。日経寄与度の高い値がさ株では誤差が出る。
3. **S高の翌寄りが必ず約定する保証はない**。翌日も買い気配で始まれば寄成売りは高値で約定するし、
   逆にストップ安気配なら売れない。本分析は `adj_open` が付いた日のみを対象にしている。
4. 市場ギャップは**翌朝にならないと確定しない**。前夜のCME先物は代理指標にすぎず、
   先物 −2.14% が現物ギャップ −1.5% 以下を保証しない（金曜引け値からの乖離・寄り直前の変動）。
5. 出来高比 <0.5x の層は**小型株に偏っている可能性**があり、サイズ中立化を行っていない。
   H3 を単独シグナルに昇格させるにはサイズ層別が必須。
6. S高翌日を対象にしているため、**S高が連続する銘柄**（2日連続S高）が層を跨いで重複計上される。
