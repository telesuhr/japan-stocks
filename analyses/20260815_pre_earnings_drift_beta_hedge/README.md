# pre_earnings_drift の market-neutral（1306等額ショート）版・10年検証

## 背景
姉妹分析 `20260815_pre_earnings_drift_q1_inclusion/` で、pre_earnings_drift(base=FY/2Q/3Q) は
**ロングオンリーで直近レジーム依存**（IS 2016-21 累積−63%/MDD−70%、OOS 2022-26 +127%/MDD−32.5%、
2018/19/22は明確な負け年）と判明。負け年・大DDの主因は**相場β**の疑いが濃い。
→ 決算前ドリフトの銘柄固有αだけを取り出すため、**保有中に 1306 TOPIX ETF を等額ショート**して
β中立化し、(1)MDD圧縮 (2)負け年(2018/19/22)の改善 を10年で測る。

## 目的・仮説（教訓5）

| ID | 仮説 | 予想 | 棄却条件 |
|----|------|------|----------|
| H1 | β中立化で最大DDが大幅圧縮される | MDDがロングオンリー(−70%IS/−30%OOS)より明確に縮小 | MDDがほぼ不変 or 悪化 |
| H2 | 負け年(2018/2019/2022)が改善する（βの往復が主因） | 3年の少なくとも2年で年次リターンが改善 | 3年とも不変 or 悪化 |
| H3 | β中立版はロングオンリーより日次PF Sharpeが高い（同等リターンで低ボラ） | 全期間 or IS/OOSでSharpe改善 | Sharpeが低下 |

補助: αが直近レジーム限定でなく**通期でプラス**なら、決算前ドリフトは相場依存でなく本物のイベントα。

## データ
- ロング: base(FY/2Q/3Q) 決算前ドリフト（`fin_summary`発表日・プライム・turnover≥5億・医薬/陸運除外）。姉妹分析と同一。
- ヘッジ: `stocks_daily` の **1306 (13060) TOPIX ETF** を等額(β=1)ショート。2016-05〜2026-08フル。
- 期間: 2016-2026。IS=2016-2021 / OOS=2022-2026。

## 手法
- 日次EWポートフォリオ収益系列で評価（per-trade×√252の誇張を排除）。
- 各保有日: 銘柄リターン − 1306リターン（entry日=寄→引、以降=前引→引）。
- コスト: L/S往復8bps（entry/exit各4bps＝ロング2+ショート2）。1-3日保有のため借入コストは無視可(<1bp)。
- 比較対象: ロングオンリー版（姉妹分析と同一ロジック）。

## 所見・次アクション

**判定（3仮説すべて棄却）:**
- **H1（MDD圧縮）→ ✗棄却**。OOS −32.5%→−30.1%（ほぼ不変）、IS −70%→−73%（悪化）。**大DDはβ由来ではなかった**。
- **H2（負け年改善）→ ✗ほぼ棄却**。2018(−35→−24.5)/2021(−40→−38)/2022(−13.5→−12.2)はわずかに改善するが依然大敗、
  一方で**勝ち年を大きく削る**（2020 +12→+1、2023 +17→+4、2025 +70→+44、2026 +32→+19）。差し引き明確にマイナス。
- **H3（Sharpe改善）→ ✗棄却**。全セグメントで低下（OOS 1.13→0.67、ALL 0.03→−0.30）。

**結論（重要）:**
1. **β中立化は不採用**。ヘッジはリターンを削るだけで、DDも負け年もほとんど直らない。
2. **pre_earnings_drift のリターンは大半が"相場β"であり、銘柄固有αではない**ことが確定。
   ＝「決算前に流動性の高い大型株をロングする＝強気相場で儲かるβ賭け」。姉妹分析のレジーム依存
   （2017/2020/2024-26で勝ち・2018/2019/2021/2022で負け）とも完全に整合。ヘッジで儲けが消えたのが動かぬ証拠。
3. **正しい打ち手は「β消し」でなく「β乗り分けのタイミング制御」**＝レジーム/ドローダウンガード
   （弱気・連敗局面でオフ）。この戦略はαオーバーレイでなく**β方向性オーバーレイ**として位置づけるのが正しい。
4. **low-touch核への含意**: 稼ぎ頭は「市場中立の安定α」ではなく「相場連動エンジン」。低タッチの
   市場中立αが欲しいなら、pre_earnings_drift を捏ね回すより、設計上L/Sの候補
   （#12 GapReversal・#13 6MモメンタムLS）に取りにいく方が筋が良い。

限界: ヘッジはβ=1等額（1306）固定。銘柄別β推定版なら数字は動くが、大型株中心でβ≈1・結果が全セグメントで
一貫して悪化のため結論は覆りにくい。次: レジームガードの効果検証（別分析）。
