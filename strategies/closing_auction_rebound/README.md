# closing_auction_rebound — 引け板寄せ下落リバウンド戦略

> **ステータス: 昇格候補 / ペーパートレード段階** ⚠️
> 実約定にはプレクロージング(15:25-30)の気配（指標値）監視が必須。
> EOD日足だけで完結する既存スイング戦略と異なり、**リアルタイム執行の検証が昇格の最終関門**。

---

## 戦略概要

2024-11-05導入のクロージング・オークション制度下で、引けの板寄せ(15:30)に向けた
パッシブファンドのMOC売り・インデックス除外・損出し・追証等の**強制的な売りインバランス**で
人為的に押された銘柄が、翌朝に反発する現象を捕捉する。

| 項目 | 内容 |
|---|---|
| 方向 | Long-only (空売り不要) |
| シグナル | close_jump = 引値(15:30板寄せ) / 15:24連続最終値 − 1 ≤ **−50bps** |
| エントリー | 当日 引け 成行引け(MOC)買い → 板寄せ価格(close30)で約定 |
| エグジット | 翌営業日 09:00〜09:15 に決済 (指値/VWAP可、寄成強制でない) |
| ユニバース | 流動性上位銘柄 (大型株。中小型は板寄せ流動性難) |
| 保有 | 1泊 (オーバーナイト) |

**非対称性**: 上昇側(buy imbalanceで押し上げ)はShortしても機能しない(実需で継続)。
**下落側のみ**反発する。経済的に妥当 (強制売り=一時的、買い=実需)。

## ⚠️ 実約定の前提条件 (昇格の最終関門)

バックテストは「jump≤-50bpsの銘柄をclose30で買う」が、**jumpの確定は15:30板寄せ後**。
MOC注文は15:25前に出す必要があり、実際は:

1. **プレクロージング(15:25-15:30)の気配（指標値/想定約定値）を監視**
2. 15:29時点で指標値が15:24比 ≤−50bps の銘柄を検出
3. その銘柄に **買いMOC(成行引け)** を投入 → 板寄せ価格で約定
4. 翌朝 09:00-09:15 に決済

→ **執行ビークル = auKabuリアルタイム板監視デーモン (50銘柄、5秒スナップショット)**。
プレクロージング気配の監視機能を拡張すれば、auKabu 50銘柄で実装可能。
広い200銘柄ユニバースには、より広範なリアルタイム気配フィードが必要。

`signal_check.py` は**引け後の事後判定**(日中足15:24/15:30から)で、ペーパートレード記録・
検証用。**ライブ執行には上記プレクロージング監視が必須**。

## 限界・リスク

- 期間18ヶ月のみ (新制度2024-11〜)。レジーム頑健性は継続監視 (OOSモニタ追加推奨)。
- 板寄せ約定価格(close30)取得前提。自己MOC追加で価格を僅かに押し上げ→大サイズで自己希釈。
- 中小型は板寄せ流動性・スプレッドが悪い。大型限定。
- 翌朝の急落リスク (オーバーナイトで地政学・決算等)。1泊保有のイベントリスク。
