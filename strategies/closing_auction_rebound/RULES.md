# 意思決定フローチャート — 引け板寄せ下落リバウンド戦略

> ステータス: 候補/ペーパートレード段階。ライブ執行はプレクロージング気配監視が前提。

---

## 🟢 Day N 15:25-15:30 — プレクロージング (ライブ執行の本番)

```
START (Day N 15:25 プレクロージング開始)
  │
  ▼
① リアルタイム板/気配で各銘柄の「想定約定値(指標値)」を監視
   (auKabuデーモン or 証券会社の気配表示)
  │
  ▼
② 15:29時点で 指標値 / 15:24連続最終値 − 1 ≤ −50bps の銘柄を抽出
  │
  ├── 該当なし → SKIP (ノートレード)
  │
  └── 該当あり ▼

③ 戦略一時停止フラグ? (OOSモニタで直近Sharpe<0.5)
  │
  ├── Yes → SKIP
  └── No  ▼

④ 該当銘柄に翌営業日の決算発表・重大イベントを含むか?
  │
  ├── Yes → 該当銘柄除外 (オーバーナイトのイベントリスク回避)
  └── No  ▼

⑤ 地合い: 市場全体が大幅安 (TOPIX当日−2%超) で発火銘柄が異常に多い(>30)か?
  │
  ├── Yes → 下落幅上位のみ採択 or サイズ縮小 (市場βの過剰集中を回避)
  └── No  ▼

⑥ 採択銘柄に 買いMOC(成行引け) を投入 → 15:30板寄せ価格で約定
   (各銘柄均等配分)
```

---

## 🔴 Day N+1 09:00-09:15 — エグジット

```
START (Day N+1 09:00 寄り付き)
  │
  ▼
① 保有全銘柄を 09:00-09:15 に決済
   - 寄成 or 寄り直後の指値/VWAP (寄成強制ではない、15分窓あり)
   - 減衰カーブ: 09:00-09:15でSharpe2.9-3.9維持、10:00以降減衰
  │
  ▼
② 09:15までに未約定なら成行で手仕舞い (遅延ほどエッジ減衰)
```

```
→ 実際のMOC約定値・翌朝決済値と照合し、気配判断の精度を検証
```

## サイズ・リスク管理

- 1銘柄あたり均等配分。同時保有数は地合いで変動 (大幅安日は多数発火)。
- 大幅安日の過剰集中 = 市場βリスク → 発火数>30なら下落幅上位に絞る or 総額上限。
- オーバーナイト保有のイベントリスク (翌朝GD) を許容できる総額に限定。
- 大型株限定 (中小型は板寄せ流動性・スプレッド難)。
- **昇格前提**: プレクロージング気配での実約定検証 (auKabu) + 2-4週ペーパー追跡。
